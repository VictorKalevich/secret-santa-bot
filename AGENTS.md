# Инструкции для работы с secret-santa-bot

## Формат команд выката

Когда пользователь просит команды для выката, дай один блок `powershell` с командами для последовательного выполнения в `C:\ClaudeProjects\secret-santa-bot`. Перед каждой группой команд добавь короткий нумерованный комментарий `# 1. …` на русском.

Включи переход на `main` и получение свежего кода, установку зависимостей, `npx wrangler deployments list` для записи текущего Version ID, список ожидающих миграций и экспорт рабочей D1 в `backup-$(Get-Date -Format yyyy-MM-dd-HHmm).sql` перед изменениями. Укажи ожидаемые имена миграций, ответы на подтверждения и проверку версии схемы или результата очистки. Сверяй порядок миграции и выката с конкретным обновлением. Для `0014_remove_profile_badges.sql` выкат нового Worker идёт перед очисткой значков.
