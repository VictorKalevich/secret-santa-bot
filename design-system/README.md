# Дизайн-система «Тайный Санта»

Версия 1.7.0. Единый источник цветов, текста, отступов и компонентов для всего интерфейса проекта
(сейчас — мини-приложение Telegram: части `src/app/`, склейка — `src/app-page.js`). Правило из Конституции (принцип IV): **интерфейс
собирается только из этой дизайн-системы**.

| Файл | Что внутри |
|---|---|
| `tokens.css` | токены `--ds-*`: цвета, типографика, отступы, радиусы, размеры, тени, анимация, слои |
| `components.css` | компоненты `.ds-*`, используют только токены |
| `clearable-input.js.txt` | общая кнопка очистки для мини-приложения, формы настройки и витрины |
| `preview.html` | витрина всех компонентов в светлой и тёмной теме — откройте в браузере |

## Очистка однострочных полей

Для редактируемой однострочной строки поместите `input.ds-input` в `span.ds-clearable` и вызовите
`bindClearableInput(обёртка, названиеПоля)`. В мини-приложении используйте `field(подпись, input)`
или `clearable(input, названиеПоля)` для поля без видимой подписи. Крестик появляется у заполненной строки.
Зона нажатия 44 × 44, тексту отведён отдельный правый отступ. Очистка возвращает фокус и вызывает событие `input`.

## Принципы

1. **Тема Telegram — основа.** Базовые цвета берутся из `--tg-theme-*`, поэтому светлая и тёмная тема
   работают сами. Запасные значения — для открытия в обычном браузере.
2. **Праздничный акцент — дозированно.** Красный градиент только для главного действия (жеребьёвка),
   значка в шапке и карточки подопечного.
3. **Шкала отступов 4 px.** Только `--ds-space-*`; других отступов нет.
4. **Тайна видна в интерфейсе.** Имя подопечного скрыто размытием до нажатия; содержимое чужих писем — только
   в отдельной шторке после подтверждения.
5. **Крупные цели для пальца.** Высота интерактивных элементов ≥ 34 px (`--ds-size-control-sm`),
   основные кнопки — 44 px (`--ds-size-control`).

## Токены

**Цвета (тема)**: `bg` (фон страницы), `surface` (карточки), `text`, `text-muted`, `link`, `accent` и `on-accent`
(основная кнопка), `danger`, `section-title`, `separator`, `fill` (поля, вторичные кнопки), `overlay`.
**Схема**: `--ds-color-scheme` — `light`/`dark` из темы Telegram (`--tg-color-scheme`), без Telegram — системная;
по ней браузер рисует системные элементы: раскрытый список, календарь, флажки, полосы прокрутки.
**Бренд**: `festive-light`, `festive`, `festive-mid`, `festive-deep`, `on-festive*`, `--ds-gradient-festive`,
`--ds-gradient-ward`. **Статусы**: `success(-soft)`, `warning(-soft)`, `diff-add`, `diff-del`.

**Текст**: `--ds-text-xs` 12 · `sm` 13 · `md` 14.5 · `base` 16 · `lg` 18 · `xl` 21 · `2xl` 28;
насыщенность `regular` 400 · `medium` 500 · `semibold` 600 · `bold` 750; интерлиньяж `tight` 1.15 · `base` 1.45 ·
`relaxed` 1.55.

**Отступы**: `--ds-space-0` 0 · `px` 1 · `0-5` 2 · `1` 4 · `1-5` 6 · `2` 8 · `3` 12 · `4` 16 · `5` 20 · `6` 24 ·
`8` 32 · `10` 40 · `15` 60. Поля страницы — `--ds-page-gutter` (12).

**Радиусы**: `xs` 3 · `sm` 6 · `md` 10 · `control` 11 · `badge` 13 · `lg` 14 · `xl` 18 · `pill` · `round`.

**Открытки (038)**: по умолчанию `--ds-postcard-frame|paper|ink|mark`, у каждой темы — `--ds-postcard-<id>-frame` (узор
только градиентами CSS — картинки и `data:` запрещены политикой страницы), `-paper`, `-ink`; размеры `--ds-postcard-frame-w`
(14, у мини — `-mini` 7), `--ds-postcard-tilt` (наклон наклейки), `--ds-size-choice` (48), `--ds-size-choice-card` (96).
Новая открытка — строка `POSTCARDS`, три токена, тема в `components.css` и плитка в `preview.html` (тест `looks`).

## Правила (проверяет `tests/design-system.test.mjs`)

- В `components.css` нет «сырых» цветов (`#…`, `rgb()`, `hsl()`) и значений в `px` — только `var(--ds-*)`.
- Базовые стили элементов (`button`, `input`, …) задаются только через `:where()` — у них нулевая специфичность,
  поэтому они никогда не перебивают цвета и размеры компонентов. (Ошибка v1.0: `.ds-root button { color: inherit }`
  делал текст выбранной вкладки и кнопок чёрным в светлой теме.)
- Каждый `var(--ds-*)` определён в `tokens.css`.
- В частях мини-приложения (`src/app/`) нет своего CSS, атрибутов `style` и классов вне `ds-*`; каждый используемый
  класс описан в `components.css`. Тест проверяет склейку частей целиком — ту же страницу, что отдаёт Worker.
- Каждый компонент показан в `preview.html`.
- Системные элементы — в схеме темы: `color-scheme: var(--ds-color-scheme)` на корне и в `.ds-theme`, пункты
  `<option>` — цвета `surface`/`text`. (Ошибка до 1.4: в тёмной теме раскрытый список был белым с белым текстом.)
- Выпадающий список (`select.ds-input`) — своя «галочка» (`--ds-select-arrow`): системная прижата к краю и не
  слушает `padding`.
- Поле даты (`input[type="date"].ds-input`) — рисунок календаря на `--ds-space-3` от края (у значка Chromium свой
  `padding` и поля внутри рисунка — `--ds-date-icon-bleed`), без внутренних отступов Chromium, на iOS/Android — без
  отступа значения справа и без центровки. В приложении поля даты — только через `ui.date`: «Сбросить» системного
  календаря закрывает календарь. Свой календарь (027) — `ui.datePick`: там, где дата сама включает действие
  (автожеребьёвка), — системный календарь iOS выделяет сегодня и подставляет его по «Готово», свой — нет.
- Шторка блокирует прокрутку страницы (`ds-root--locked`), `.ds-sheet` и `.ds-chat` — `overscroll-behavior: contain`.
- У каждой шторки — драгер (033): полоса `ds-sheet__handle` первой в шторке (`ds-sheet--handle`), свайп вниз за неё
  закрывает шторку так же, как ✕ (с тем же вопросом о несохранённом), короткий — возвращает. В приложении шторку
  открывает только `openSheet` — он и ставит драгер (`sheetHandle`) и на время шторки выключает жест Telegram «свайп вниз
  сворачивает приложение»; своя разметка шторки, свой или второй драгер — нарушение. Полоса прилипает к верху
  прокручиваемой шторки (`position: sticky`, фон шторки); у шторки на весь экран свой `padding-top` не задаётся. В
  `preview.html` каждая шторка — с полосой.

## Как добавить новый элемент

1. Нужен новый цвет/размер → добавить токен в `tokens.css` (с понятным именем).
2. Описать компонент в `components.css` (БЭМ: `.ds-блок__элемент--модификатор`), только через токены.
3. Показать его в `preview.html` (в обеих темах он появится автоматически).
4. Добавить строку в таблицу компонентов выше.
5. Использовать в приложении. Запустить `npm test`.

Как подключается: сервер (`src/index.js`) встраивает `tokens.css` и `components.css` в `<style>` страницы
мини-приложения вместо плейсхолдера `/*@design-system*/`, поэтому сборщик не нужен.
