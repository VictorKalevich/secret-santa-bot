# Дизайн-система «Тайный Санта»

Версия 1.1.0. Единый источник цветов, текста, отступов и компонентов для всего интерфейса проекта
(сейчас — мини-приложение Telegram `src/app.html`). Правило из Конституции (принцип IV): **интерфейс
собирается только из этой дизайн-системы**.

| Файл | Что внутри |
|---|---|
| `tokens.css` | токены `--ds-*`: цвета, типографика, отступы, радиусы, размеры, тени, анимация, слои |
| `components.css` | компоненты `.ds-*`, используют только токены |
| `preview.html` | витрина всех компонентов в светлой и тёмной теме — откройте в браузере |

## Принципы

1. **Тема Telegram — основа.** Базовые цвета берутся из `--tg-theme-*`, поэтому светлая и тёмная тема
   работают сами. Запасные значения — для открытия в обычном браузере.
2. **Праздничный акцент — дозированно.** Красный градиент только для главного действия (жеребьёвка),
   значка в шапке и карточки подопечного.
3. **Шкала отступов 4 px.** Только `--ds-space-*`; других отступов нет.
4. **Тайна видна в интерфейсе.** Имя подопечного скрыто размытием до нажатия; содержимое чужих писем — только
   в отдельной шторке после подтверждения.
5. **Крупные цели для пальца.** Высота интерактивных элементов ≥ 34 px (`--ds-size-control-sm`),
   основные кнопки — 44 px (`--ds-size-control`).

## Токены

**Цвета (тема)**: `bg` (фон страницы), `surface` (карточки), `text`, `text-muted`, `link`, `accent` и `on-accent`
(основная кнопка), `danger`, `section-title`, `separator`, `fill` (поля, вторичные кнопки), `overlay`.
**Бренд**: `festive-light`, `festive`, `festive-mid`, `festive-deep`, `on-festive*`, `--ds-gradient-festive`,
`--ds-gradient-ward`. **Статусы**: `success(-soft)`, `warning(-soft)`, `diff-add`, `diff-del`.

**Текст**: `--ds-text-xs` 12 · `sm` 13 · `md` 14.5 · `base` 16 · `lg` 18 · `xl` 21 · `2xl` 28;
насыщенность `regular` 400 · `medium` 500 · `semibold` 600 · `bold` 750; интерлиньяж `tight` 1.15 · `base` 1.45 ·
`relaxed` 1.55.

**Отступы**: `--ds-space-0` 0 · `px` 1 · `0-5` 2 · `1` 4 · `1-5` 6 · `2` 8 · `3` 12 · `4` 16 · `5` 20 · `6` 24 ·
`8` 32 · `10` 40 · `15` 60. Поля страницы — `--ds-page-gutter` (12).

**Радиусы**: `xs` 3 · `sm` 6 · `md` 10 · `control` 11 · `badge` 13 · `lg` 14 · `xl` 18 · `pill` · `round`.

## Компоненты

| Компонент | Классы | Когда использовать |
|---|---|---|
| Корень страницы | `ds-root` | на `<body>`: фон, шрифт, отступ под «домашнюю» полосу |
| Область темы | `ds-theme` | блок с собственными `--tg-theme-*` (например, тёмная колонка витрины) — токены пересчитываются внутри |
| Раскладка | `ds-page`, `ds-stack` (12), `ds-stack--sm` (8), `ds-row` (+`--between`, `--wrap`, `--tight`), `ds-grow`, `ds-divided` | вертикальные/горизонтальные группы с отступами из шкалы |
| Текст | `ds-text-muted`, `ds-text-sm`, `ds-text-strong`, `ds-text-regular`, `ds-text-pre`, `ds-hint` (+`--inset`), `ds-bullets` | подсказки, акценты, списки |
| Шапка | `ds-hero`, `__badge`, `__title`, `__subtitle` | верх экрана |
| Вкладки | `ds-tabs`, `ds-tab` (+`--active`), `ds-tab__icon`, `ds-tab__label`, `ds-tab__dot` | 2–4 равные вкладки «иконка + короткая подпись»; точка — несохранённые изменения |
| Секция и карточка | `ds-section-title`, `ds-card` (+`--flush`) | группировка содержимого |
| Кнопки | `ds-btn` (+`--block`, `--secondary`, `--danger`, `--festive`, `--on-festive`, `--sm`), `ds-icon-btn` | одно основное действие на карточку; `festive` — только жеребьёвка |
| Поля | `ds-input` (+`--letter`), `ds-field`, `ds-field__label`, `ds-check`, `ds-counter` (+`--over`) | ввод текста, выбор, флажки, счётчик слов |
| Список | `ds-list-item` (+`--sub`), `ds-list-item__title` | участники, исключения (внутри `ds-card--flush`) |
| Метки | `ds-chips`, `ds-chip` (+`--success`, `--warning`) | статусы участников |
| Переключатель | `ds-switch` + `input` + `ds-switch__track` | вкл/выкл настройки |
| Сегменты | `ds-segmented`, `ds-segmented__item` (+`--on`) | выбор одного из 2–4 вариантов |
| Подопечный | `ds-ward-card`, `__label`, `__name` (+`--hidden`) | главный экран Санты |
| Письмо | `ds-letter`, `ds-diff-add`, `ds-diff-del` | текст письма и подсветка изменений |
| Пустое состояние | `ds-empty`, `__icon`, `__title`, `__action` | нет данных / ошибка |
| Сведения | `ds-info-grid` (на `<dl>`) | пары «название — значение» |
| Плашки | `ds-notice` (+`--error`) | пояснения, ошибки |
| Всплывающие | `ds-toast` (+`--visible`), `ds-sheet-backdrop`, `ds-sheet`, `ds-sheet__title` | короткие сообщения, шторка с подробностями |
| Загрузка | `ds-loader`, `ds-spinner` | ожидание ответа сервера |

## Правила (проверяет `tests/design-system.test.mjs`)

- В `components.css` нет «сырых» цветов (`#…`, `rgb()`, `hsl()`) и значений в `px` — только `var(--ds-*)`.
- Базовые стили элементов (`button`, `input`, …) задаются только через `:where()` — у них нулевая специфичность,
  поэтому они никогда не перебивают цвета и размеры компонентов. (Ошибка v1.0: `.ds-root button { color: inherit }`
  делал текст выбранной вкладки и кнопок чёрным в светлой теме.)
- Каждый `var(--ds-*)` определён в `tokens.css`.
- В `src/app.html` нет своего CSS, атрибутов `style` и классов вне `ds-*`; каждый используемый класс описан
  в `components.css`.
- Каждый компонент показан в `preview.html`.

## Как добавить новый элемент

1. Нужен новый цвет/размер → добавить токен в `tokens.css` (с понятным именем).
2. Описать компонент в `components.css` (БЭМ: `.ds-блок__элемент--модификатор`), только через токены.
3. Показать его в `preview.html` (в обеих темах он появится автоматически).
4. Добавить строку в таблицу компонентов выше.
5. Использовать в приложении. Запустить `npm test`.

Как подключается: сервер (`src/index.js`) встраивает `tokens.css` и `components.css` в `<style>` страницы
мини-приложения вместо плейсхолдера `/*@design-system*/`, поэтому сборщик не нужен.
