# 🎅 Тайный Санта — Telegram-бот

Закрытый бот для игры в Тайного Санту в своей компании. Работает на телефонах (iOS, Android) и компьютерах через
Telegram, ничего устанавливать не нужно.

- вход без паролей, регистрация только по пригласительной ссылке;
- **эвенты**: несколько игр параллельно для разных компаний, у каждой своя ссылка, письма и жеребьёвка;
  прошлые эвенты остаются в истории — на следующий год можно открыть свои старые записи;
- письмо Санте до 4000 символов (столько помещается в одно сообщение Telegram) — менять можно до завершения эвента;
- исключения «кто кому не может достаться» и жеребьёвка одной кнопкой; **кольцевая жеребьёвка** (по умолчанию):
  если A дарит Б, то Б не дарит A;
- Санта в любой момент видит письмо подопечного (изменения подсвечены) и получает уведомление, когда тот его правит;
- никто, включая организатора, не видит, кто кому дарит;
- переписка Санты и подопечного прямо в приложении (Санта остаётся анонимным) с уведомлениями в Telegram;
- напоминания, «подарок готов», раскрытие Сант после праздника.

Хостинг — бесплатный тариф Cloudflare (без банковской карты). Требования и решения — в [`specs/`](specs/)
(начало — [`001`](specs/001-secret-santa-bot/spec.md), эвенты и история — [`005`](specs/005-events-history/spec.md)).

## Запуск (≈ 20 минут, Windows)

Все команды выполняются в **PowerShell** в папке проекта:

```powershell
cd C:\ClaudeProjects\secret-santa-bot
```

### 1. Установите Node.js

Скачайте LTS-версию с [nodejs.org](https://nodejs.org) и установите. Проверка: `node -v` (нужна 20 или новее).

### 2. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте название (например, «Тайный Санта 2026») и имя пользователя, оканчивающееся на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA…`. Никому его не показывайте.

### 3. Создайте аккаунт Cloudflare

Зарегистрируйтесь на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) (нужна только почта)
и подтвердите адрес.

### 4. Установите зависимости и войдите в Cloudflare

```powershell
npm install
npx wrangler login
```

Откроется браузер — нажмите «Allow».

### 5. Создайте базу данных

```powershell
npx wrangler d1 create secret-santa-db
```

Если Wrangler предложит сам добавить настройки в конфигурацию — откажитесь и сделайте вручную:
скопируйте из ответа значение `database_id` и вставьте его в `wrangler.toml` вместо `REPLACE_WITH_DATABASE_ID`.

### 6. Опубликуйте бота

```powershell
npm run deploy
```

При первом запуске Cloudflare попросит выбрать имя поддомена `workers.dev` — введите любое. В конце появится адрес
вида `https://secret-santa-bot.<ваш-поддомен>.workers.dev` — запишите его.

### 7. Добавьте секреты

```powershell
npx wrangler secret put BOT_TOKEN
npx wrangler secret put ADMIN_SECRET
```

На первый вопрос вставьте токен от BotFather, на второй — придумайте пароль администратора (от 8 символов,
латиница и цифры). Он нужен только для страницы настройки.

### 8. Настройте бота

Откройте в браузере:

```
https://secret-santa-bot.<ваш-поддомен>.workers.dev/setup?key=<ваш ADMIN_SECRET>
```

Все пункты должны быть с ✔. На странице будет **ссылка владельца** — откройте её в своём Telegram и **никому не
пересылайте**. Пригласительных ссылок на этой странице нет: у каждого эвента своя, она появляется в приложении.

### 9. Создайте эвент и начинайте игру

1. Перейдите по ссылке владельца и напишите боту своё имя.
2. Нажмите «🎁 Санта» (кнопка у поля ввода) → «＋ Новый эвент» → название, например «Новый год 2026 — семья».
3. Откроется вкладка «Админ» эвента: включите «Я участвую», если играете сами, и заполните бюджет, даты и место
   (раздел «Параметры эвента»).
4. Отправьте пригласительную ссылку эвента в общий чат (кнопка «📤 Отправить в чат»).
5. Когда все зарегистрируются — добавьте исключения и нажмите «🎲 Провести жеребьёвку».
6. После праздника — «🎅 Раскрыть Сант» (по желанию) и «🏁 Завершить эвент».

## Как играть

Приложение открывается кнопкой «🎁 Санта». На главном экране — **список эвентов**: «Мои эвенты» (где вы участник,
включая завершённые) и у админов «Другие эвенты» (где вы не участвуете). Если вы участник единственного эвента,
он откроется сразу. Внутри эвента — вкладки:

| Кто | Что делает |
|---|---|
| Участник | «Письмо» — пишет и правит письмо (до 4000 символов), кнопка «💬 Написать Санте»; «Подопечный» — кому дарит, его письмо, кнопка «💬 Написать подопечному», отметка «подарок готов»; «Инфо» — бюджет, даты, место |
| Организатор | «Админ» — ссылка-приглашение, «Я участвую», участники и статусы писем (действия с участником — кнопка «⋯»), исключения, кольцевая жеребьёвка, жеребьёвка, напоминания, раскрытие Сант, завершение эвента, параметры; у владельца — сброс и удаление эвента |

Чужое письмо организатор может открыть только через «⋯» → «👁 Открыть письмо» с подтверждением. Пар «кто кому дарит» он
не видит вообще — ни в текущих эвентах, ни в истории.

### Эвенты и история

- **Новый эвент** — главный экран → «＋ Новый эвент» (владелец и админы). У эвента свои участники, пригласительная
  ссылка, письма, исключения, жеребьёвка и переписка. Эвентов может идти несколько одновременно — для разных компаний.
  Один человек может участвовать в нескольких: имя вводится один раз, дальше достаточно перейти по ссылке эвента.
- **Пригласить ту же компанию на следующий год** — «Админ» нового эвента → «Пригласить участников прошлого эвента» →
  выберите эвент → «📨 Пригласить участников». Каждый получит в Telegram сообщение с кнопкой вступления.
- **«Не повторять пары прошлого эвента»** (раздел «Жеребьёвка», включено по умолчанию) — бот постарается не повторить пары прошлого эвента,
  где больше всего тех же людей. Если иначе не получается, он предупредит и проведёт жеребьёвку без этого правила.
- **Кольцевая жеребьёвка** (раздел «Жеребьёвка», включена по умолчанию) — если A дарит Б, то Б не дарит A. Меняется только
  до жеребьёвки, только админом. Для неё нужно минимум 3 участника; если исключения не оставляют вариантов без взаимных
  пар, бот подскажет — уберите часть исключений или выключите кольцевую.
- **Завершить эвент** — «Админ» → «🏁 Завершить эвент» после праздника. Отменить нельзя. После завершения письма и отметки
  «подарок готов» только для чтения, регистрация закрыта; переписка открыта ещё **7 дней**, потом — только чтение.
  Эвент остаётся в истории: участники в любой момент откроют своё письмо, письмо подопечного и переписку.
- Админы и владелец видят все эвенты, даже где не участвуют (вкладки «Инфо» и «Админ»), но пары и чужую переписку — нет.

### Участники: удаление, перенос, сброс и удаление эвента

- **Удалить участника из эвента** — «Админ» → «⋯» у участника → «🗑 Удалить из эвента». Работает и для недорегистрированных
  записей («регистрируется…»). После жеребьёвки бот поменяет подопечного только у Санты удалённого (с кольцевой — у 2–3
  человек, чтобы не появилась взаимная пара). В других эвентах человек остаётся.
- **Человек потерял доступ к аккаунту и зарегистрировался заново** — не удаляйте старую запись, а перенесите её:
  откройте регистрацию (если закрыта), пусть человек зайдёт по пригласительной ссылке с нового аккаунта; затем
  «⋯» у старой записи → «🔁 Перенести на новый аккаунт» → выберите новую запись. Перенос действует **во всех эвентах**:
  новый аккаунт получит письма, подопечных, своих Сант, переписку и историю; пары остальных не изменятся.
- **Полный сброс эвента** (только владелец, «Опасная зона») — удаляет из этого эвента всех, кроме владельца, письма, пары,
  исключения, переписку и параметры; создаёт новую пригласительную ссылку (старая перестаёт работать). Другие эвенты не
  затрагиваются. Подтверждение — слово «СБРОС». Завершённый эвент сбросить нельзя — только удалить.
- **Удалить эвент** (только владелец, «Опасная зона») — эвент пропадает целиком, в том числе из истории у всех участников.
  Подтверждение — слово «УДАЛИТЬ». Удобно после тестового прогона.

### Переписка Санты и подопечного

- Санта: вкладка «Подопечный» → «💬 Написать подопечному». Подопечный: вкладка «Письмо» → «💬 Написать Санте».
- Подопечный видит Санту только как «Тайный Санта». Санта знает, кому пишет.
- Каждое сообщение приходит в Telegram от бота с кнопками «↩️ Ответить» (ответить прямо в чате с ботом) и
  «💬 Вся переписка» (открыть историю в приложении). Число непрочитанных видно на кнопке, точка — на вкладке.
- Сообщение — до 4000 символов. Переписку видят только эти двое; организатор её не видит.
- Если у Санты сменился подопечный (кто-то выбыл), старая переписка этой пары удаляется.
- Переписка у каждого эвента своя. После завершения эвента писать можно ещё 7 дней, потом — только читать.

### Роли

| Роль | Как получить | Что может |
|---|---|---|
| 👑 Владелец (один) | ссылка владельца со страницы `/setup` или передача прав от текущего владельца | всё, что админ, плюс назначать и снимать админов, передавать права владельца, удалять и переносить админов, сброс и удаление эвентов |
| 🛠 Админ | назначает владелец: главный экран → «Администраторы» → «Назначить админом» | создавать и вести эвенты: приглашения, участники (удаление, перенос на новый аккаунт), исключения, кольцевая, жеребьёвка, напоминания, завершение |
| Участник | пригласительная ссылка эвента | письмо, подопечный, переписка с Сантой и подопечным; история своих эвентов |

Роли общие для всего бота, а не для одного эвента.

Владельца нельзя удалить или лишить прав из приложения — только передать права (👑 у админа в списке). Если владелец
потерял доступ, хозяин `ADMIN_SECRET` открывает `/setup` и снова переходит по ссылке владельца: права вернутся к нему,
прежний владелец получит предупреждение.

Бот сам напоминает (в 10:00 по Минску) в каждом идущем эвенте: за 2 дня до срока письма — тем, у кого оно пустое;
за 2 дня и в день вручения — Сантам без отметки «подарок готов». Во всех сообщениях бота указано название эвента.

## Если что-то не так

| Проблема | Решение |
|---|---|
| PowerShell: «выполнение сценариев отключено» | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте `npx.cmd` вместо `npx` |
| На `/setup` пункт с ✘ | проверьте `BOT_TOKEN` (`npx wrangler secret put BOT_TOKEN` ещё раз) и откройте `/setup` снова |
| Бот не отвечает | откройте `/setup` ещё раз; посмотрите логи: `npx wrangler tail` |
| «Не удалось проверить вход» в приложении | закройте приложение и откройте снова из чата с ботом |
| Пригласительная ссылка ушла не туда | «Админ» эвента → «🔄 Новая ссылка» (старая перестанет работать) |
| Человек пишет, что ссылка «закрыта» | регистрация в эвенте выключена или эвент завершён: «Админ» → «Регистрация открыта» |
| «Для кольцевой жеребьёвки нужно минимум 3 участника» | добавьте участников или выключите «🔁 Кольцевая жеребьёвка» в разделе «Жеребьёвка» |
| Кто-то выбыл после жеребьёвки | «Админ» → «⋯» у участника → «🗑 Удалить из эвента»: бот поменяет подопечного только у его Санты |
| Человек потерял аккаунт и зарегистрировался заново | «⋯» у старой записи → «🔁 Перенести на новый аккаунт» (см. «Участники» выше) |
| Тестовый прогон перед настоящей игрой | создайте отдельный тестовый эвент, после проверки — «Опасная зона» → «🗑 Удалить эвент» |
| Ссылка владельца попала не туда | перейдите по ней сами (права вернутся), затем `npx wrangler secret put ADMIN_SECRET` с новым паролем |

**О тайне.** Бот никому не показывает пары. Технически владелец аккаунта Cloudflare может открыть базу данных
в панели Cloudflare — просто не делайте этого 🙂

**Бесплатные лимиты** Cloudflare: 100 000 запросов в сутки — для компании до ~40 человек с огромным запасом.

## Для разработки

```powershell
npm test               # юнит-тесты жеребьёвки + правила дизайн-системы
npm run test:e2e       # полный сценарий (эвенты, жеребьёвка, переписка, история) на локальном Worker с имитацией Telegram
npm run screenshots    # скриншоты мини-приложения в test-results/ (нужен Google Chrome)
npm run dev            # локальный Worker на http://127.0.0.1:8787
```

Витрина интерфейса: откройте `design-system/preview.html` в браузере.

### Структура

```text
src/             код Worker: бот, API, мини-приложение (app.html), жеребьёвка, cron
design-system/   дизайн-система: токены, компоненты, витрина, правила
tests/           юнит-, e2e-тесты, скриншоты
specs/           спецификации Spec Kit (требования, план, задачи) — источник истины
.specify/        Spec Kit: конституция проекта, шаблоны, скрипты PowerShell
.claude/skills/  команды Spec Kit для Claude Code (/speckit-*)
```

### Как менять проект

Проект ведётся по [Spec Kit](https://github.com/github/spec-kit): сначала требования, потом код. В Claude Code
в этой папке:

1. `/speckit-specify <что нужно изменить>` — новая спецификация и ветка `NNN-имя`;
2. `/speckit-clarify` (по желанию) → `/speckit-plan` → `/speckit-tasks`;
3. `/speckit-implement` — реализация по задачам;
4. `npm test` и `npm run test:e2e`, затем `npm run deploy`.

Правила проекта — в [`.specify/memory/constitution.md`](.specify/memory/constitution.md), подсказки для агента — в [`CLAUDE.md`](CLAUDE.md).
