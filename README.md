# 🎅 Тайный Санта — Telegram-бот

Закрытый бот для игры в Тайного Санту в своей компании. Работает на телефонах (iOS, Android) и компьютерах через
Telegram, ничего устанавливать не нужно.

- вход без паролей, регистрация только по пригласительной ссылке;
- письмо Санте до 4000 символов (столько помещается в одно сообщение Telegram) — менять можно в любой момент;
- исключения «кто кому не может достаться» и жеребьёвка одной кнопкой;
- Санта в любой момент видит письмо подопечного (изменения подсвечены) и получает уведомление, когда тот его правит;
- никто, включая организатора, не видит, кто кому дарит;
- переписка Санты и подопечного прямо в приложении (Санта остаётся анонимным) с уведомлениями в Telegram;
- напоминания, «подарок готов», раскрытие Сант после праздника.

Хостинг — бесплатный тариф Cloudflare (без банковской карты). Требования и решения — в [`specs/001-secret-santa-bot/`](specs/001-secret-santa-bot/spec.md).

## Запуск (≈ 20 минут, Windows)

Все команды выполняются в **PowerShell** в папке проекта:

```powershell
cd C:\ClaudeProjects\secret-santa-bot
```

### 1. Установите Node.js

Скачайте LTS-версию с [nodejs.org](https://nodejs.org) и установите. Проверка: `node -v` (нужна 20 или новее).

### 2. Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Придумайте название (например, «Тайный Санта 2026») и имя пользователя, оканчивающееся на `bot`.
3. BotFather пришлёт **токен** вида `1234567890:AA…`. Никому его не показывайте.

### 3. Создайте аккаунт Cloudflare

Зарегистрируйтесь на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) (нужна только почта)
и подтвердите адрес.

### 4. Установите зависимости и войдите в Cloudflare

```powershell
npm install
npx wrangler login
```

Откроется браузер — нажмите «Allow».

### 5. Создайте базу данных

```powershell
npx wrangler d1 create secret-santa-db
```

Если Wrangler предложит сам добавить настройки в конфигурацию — откажитесь и сделайте вручную:
скопируйте из ответа значение `database_id` и вставьте его в `wrangler.toml` вместо `REPLACE_WITH_DATABASE_ID`.

### 6. Опубликуйте бота

```powershell
npm run deploy
```

При первом запуске Cloudflare попросит выбрать имя поддомена `workers.dev` — введите любое. В конце появится адрес
вида `https://secret-santa-bot.<ваш-поддомен>.workers.dev` — запишите его.

### 7. Добавьте секреты

```powershell
npx wrangler secret put BOT_TOKEN
npx wrangler secret put ADMIN_SECRET
```

На первый вопрос вставьте токен от BotFather, на второй — придумайте пароль администратора (от 8 символов,
латиница и цифры). Он нужен только для страницы настройки.

### 8. Настройте бота

Откройте в браузере:

```
https://secret-santa-bot.<ваш-поддомен>.workers.dev/setup?key=<ваш ADMIN_SECRET>
```

Все пункты должны быть с ✔. На странице будут две ссылки:

- **ссылка владельца** — откройте её в своём Telegram и **никому не пересылайте**;
- **пригласительная ссылка** — для участников.

### 9. Начинайте игру

1. Перейдите по ссылке владельца, напишите боту имя и выберите «Участвую» или «Только организую».
2. Нажмите «🎁 Санта» (кнопка у поля ввода) → вкладка «Админ» → заполните бюджет, даты и место.
3. Отправьте пригласительную ссылку в общий чат (кнопка «📤 Отправить в чат»).
4. Когда все зарегистрируются — добавьте исключения и нажмите «🎲 Провести жеребьёвку».

## Как играть

| Кто | Что делает |
|---|---|
| Участник | вкладка «Письмо» — пишет и правит письмо (до 4000 символов), кнопка «💬 Написать Санте»; «Подопечный» — кому дарит, его письмо, кнопка «💬 Написать подопечному», отметка «подарок готов» |
| Организатор | вкладка «Админ» — ссылка-приглашение, участники и статусы писем, исключения, жеребьёвка, напоминания, раскрытие Сант, новая игра |

Чужое письмо организатор может открыть только кнопкой 👁 с подтверждением. Пар «кто кому дарит» он не видит вообще.

### Переписка Санты и подопечного

- Санта: вкладка «Подопечный» → «💬 Написать подопечному». Подопечный: вкладка «Письмо» → «💬 Написать Санте».
- Подопечный видит Санту только как «Тайный Санта». Санта знает, кому пишет.
- Каждое сообщение приходит в Telegram от бота с кнопками «↩️ Ответить» (ответить прямо в чате с ботом) и
  «💬 Вся переписка» (открыть историю в приложении). Число непрочитанных видно на кнопке, точка — на вкладке.
- Сообщение — до 4000 символов. Переписку видят только эти двое; организатор её не видит.
- Если у Санты сменился подопечный (кто-то выбыл) или начата новая игра, старая переписка удаляется.

### Роли

| Роль | Как получить | Что может |
|---|---|---|
| 👑 Владелец (один) | ссылка владельца со страницы `/setup` или передача прав от текущего владельца | всё, что админ, плюс назначать и снимать админов, передавать права владельца, удалять админов |
| 🛠 Админ | назначает владелец: «Админ» → «Администраторы» → «Назначить админом» | вести игру: приглашения, участники, исключения, жеребьёвка, напоминания |
| Участник | пригласительная ссылка | письмо, подопечный, переписка с Сантой и подопечным |

Владельца нельзя удалить или лишить прав из приложения — только передать права (👑 у админа в списке). Если владелец
потерял доступ, хозяин `ADMIN_SECRET` открывает `/setup` и снова переходит по ссылке владельца: права вернутся к нему,
прежний владелец получит предупреждение.

Бот сам напоминает (в 10:00 по Минску): за 2 дня до срока письма — тем, у кого оно пустое; за 2 дня и в день
вручения — Сантам без отметки «подарок готов».

## Если что-то не так

| Проблема | Решение |
|---|---|
| PowerShell: «выполнение сценариев отключено» | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или используйте `npx.cmd` вместо `npx` |
| На `/setup` пункт с ✘ | проверьте `BOT_TOKEN` (`npx wrangler secret put BOT_TOKEN` ещё раз) и откройте `/setup` снова |
| Бот не отвечает | откройте `/setup` ещё раз; посмотрите логи: `npx wrangler tail` |
| «Не удалось проверить вход» в приложении | закройте приложение и откройте снова из чата с ботом |
| Пригласительная ссылка ушла не туда | «Админ» → «🔄 Новая ссылка» (старая перестанет работать) |
| Кто-то выбыл после жеребьёвки | «Админ» → 🗑 у участника: бот поменяет подопечного только у его Санты |
| Ссылка владельца попала не туда | перейдите по ней сами (права вернутся), затем `npx wrangler secret put ADMIN_SECRET` с новым паролем |

**О тайне.** Бот никому не показывает пары. Технически владелец аккаунта Cloudflare может открыть базу данных
в панели Cloudflare — просто не делайте этого 🙂

**Бесплатные лимиты** Cloudflare: 100 000 запросов в сутки — для компании до ~40 человек с огромным запасом.

## Для разработки

```powershell
npm test               # юнит-тесты жеребьёвки + правила дизайн-системы
npm run test:e2e       # полный сценарий игры на локальном Worker с имитацией Telegram
npm run screenshots    # скриншоты мини-приложения в test-results/ (нужен Google Chrome)
npm run dev            # локальный Worker на http://127.0.0.1:8787
```

Витрина интерфейса: откройте `design-system/preview.html` в браузере.

### Структура

```text
src/             код Worker: бот, API, мини-приложение (app.html), жеребьёвка, cron
design-system/   дизайн-система: токены, компоненты, витрина, правила
tests/           юнит-, e2e-тесты, скриншоты
specs/           спецификации Spec Kit (требования, план, задачи) — источник истины
.specify/        Spec Kit: конституция проекта, шаблоны, скрипты PowerShell
.claude/skills/  команды Spec Kit для Claude Code (/speckit-*)
```

### Как менять проект

Проект ведётся по [Spec Kit](https://github.com/github/spec-kit): сначала требования, потом код. В Claude Code
в этой папке:

1. `/speckit-specify <что нужно изменить>` — новая спецификация и ветка `NNN-имя`;
2. `/speckit-clarify` (по желанию) → `/speckit-plan` → `/speckit-tasks`;
3. `/speckit-implement` — реализация по задачам;
4. `npm test` и `npm run test:e2e`, затем `npm run deploy`.

Правила проекта — в [`.specify/memory/constitution.md`](.specify/memory/constitution.md), подсказки для агента — в [`CLAUDE.md`](CLAUDE.md).
