# Quickstart: проверка закреплённых пар (014)

## Автотесты

```powershell
npm test            # юнит: pairRules, planDraw с закреплёнными парами (сотни прогонов), замены не ломают пары
npm run test:e2e    # блок «014: закреплённые пары» + владелец ⊇ админ (admin.fixed.* — отказ админу)
npm run screenshots # панель «Админ» владельца с блоком «Закреплённые пары» → test-results/
```

## Вручную (локально: `npm run dev` или выкаченный бот)

1. Перед выкатом примените миграцию: `npx wrangler d1 migrations apply secret-santa-db --remote` (появится
   `0007_fixed_pairs.sql`).
2. Владелец: событие из 4+ человек → «Админ» → под «Исключениями» блок «Закреплённые пары». Кольцевая включена — флажка
   «и наоборот» нет. Закрепите «А → Б»; попробуйте «Б → А» — отказ про одну сторону.
3. Выключите кольцевую — появился флажок; закрепите «В ↔ Г» в обе стороны — одна строка «В и Г дарят друг другу».
4. Включите кольцевую снова — в блоке предупреждение с именами В и Г; «Провести жеребьёвку» → причина без имён.
   Уберите пару «В и Г» (✕).
5. Админ (не владелец) открывает ту же панель — блока нет; журнал события — «📌 Пара закреплена» без имён.
6. Проведите жеребьёвку; в служебном просмотре владельца («ОТКРЫТЬ») — А дарит Б. Блок — только для чтения.
7. Удалите из события другого участника — пара А → Б сохранилась.

Результаты: все проверки из `spec.md` (US1–US4) выполняются, `budget exceeded` в журнале Worker нет.
