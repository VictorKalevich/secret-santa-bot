# Quickstart 039: проверка и выкат

## Локально

```powershell
npm test              # names, looks, queries, api-doc и остальные
npm run screenshots   # checkLooks (порядок «имя значок»), checkNames, checkKeyboard → test-results/
npm run test:e2e
```

Ожидается: всё зелёное; в выводе `screenshots` — строки «✔ имена и значки (039)» и «✔ клавиатура (039)».

## Выкат

Миграций нет, схема прежняя (13). `npm run deploy`. Откат — выкат прежнего кода (`main` до слияния 039), база не
меняется.

## На iPhone (Telegram iOS) после выката

1. «Письмо»: тап в поле письма — клавиатура; тап по заголовку «Письмо Тайному Санте» или по пустому месту — клавиатура
   спряталась, текст на месте. Прокрутка с открытой клавиатурой — клавиатура остаётся.
2. То же в адресе, «Профиль» → «Изменить имя», в переписке (тап по ленте сообщений) и в обращении.
3. Тап по «Сохранить» с открытой клавиатурой — письмо сохраняется (нажатие не «съедено»).
4. «Профиль» → «Значок у имени» → 🦊: «Профиль» — «<имя> 🦊», приветствие — «Привет, <имя> 🦊!», у организатора — строка в
   «Администраторах» сразу со значком, прокрутка на месте.
5. Обращение участника со значком: в панели «Обращения», в шторке обращения и у участника на «Инфо» имена — со значками.
6. У подопечного в переписке с Сантой — «Твой Тайный Санта», значка Санты нигде нет.
