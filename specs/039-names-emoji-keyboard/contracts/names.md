# Контракт 039: имя и значок, обращения, главный экран, клавиатура

## Имя и значок (приложение)

- `withEmoji(name, emoji)` (`02-core`) — единственное место, где имя соединяется со значком: `emoji ? name + ' ' + emoji
  : name`. `emojiName(u, name = u.name)` = `withEmoji(name, u.emoji)`.
- Места со значком: «Профиль», приветствие «Привет, <имя значок>!», «Администраторы», «Организаторы» и список участников
  на «Инфо» (`personTitle`), списки панели (участники, заявки, удалённые — «Аня 🦊  @anya»), имя подопечного у Санты
  (внутри скрытого `ds-ward-card__name`), обращения (ниже).
- Без значка: переписка Санты и подопечного (`openChat`: ни `emoji`, ни `withEmoji`/`emojiName`), семьи, исключения,
  закреплённые пары, шторка участника в панели, «Письмо: …», служебный просмотр, выпадающие списки, окна подтверждения,
  бот, журнал.
- Подсказка шторки «Значок у имени»: «Значок стоит после твоего имени в списках участников, у организаторов и в
  обращениях. В переписке Санты и подопечного значков нет.»

## Обращения (сервер, `src/support.js`)

Значок — `users.emoji` человека, `''` — без значка; имена — прежние строки.

| Ответ | Новые поля |
|---|---|
| `event.get` → `support` (участнику) | `assignee_emoji` — у ответственного открытого обращения |
| `support.get` → `threads[]` | `assignee_emoji`; `messages[]` → `author_emoji` (у ответов организаторов, у своих — `''`) |
| `admin.state` → `support.threads[]` | `emoji` (автор), `assignee_emoji` |
| `admin.support.get` → `thread` | `emoji` (автор), `assignee_emoji`, `closed_by_emoji`; `messages[]` → `author_emoji` |
| `admin.support.send` → `message` | `author_emoji` |

`admins` (кому передать) — без значков. Сообщения бота и журнал — без значков (как раньше).

## Обращения (приложение)

- Панель, «Обращения» (`adminSupport`): заголовок строки — `withEmoji(t.name, t.emoji)`; метка «🙋 ведёт <withEmoji>».
- Шторка обращения (`openSupportThread`): «Обращение: <автор>», «Обращение ведёт <ответственный>», «Обращение закрыто …
  — <кто>», подписи сообщений «<автор> · время» — через `withEmoji`.
- «Инфо» (`04-event`): «Твоё обращение ведёт <ответственный>»; «Организатору»: «Обращение ведёт <ответственный>»,
  подписи ответов — через `withEmoji`.

## Главный экран (`03-home`)

- Приветствие — `'Привет, ' + emojiName(me) + '!'`.
- После «Сохранить» в «Твоё имя» и выбора в «Значок у имени» (ответ сервера уже в `state.me`): «Профиль» и приветствие —
  из `state.me`; разделы «Администраторы» и «Семьи» (у организатора) перечитывают свои данные (`load`) и заменяют
  содержимое, когда ответ пришёл, — без загрузчика. Только если главный экран тот же (`state.nav` прежний).

## Тап мимо поля (`02-core`)

- Один обработчик на документе: `pointerdown` (основной указатель) запоминает точку; `pointercancel` — сброс;
  `pointerup` того же указателя со сдвигом ≤ `TAP_SLOP` (10 px) — тап.
- На тап: если фокус в `input` или `textarea`, а цель тапа — не внутри `input, textarea, select, button, a, label,
  [role="button"], [contenteditable]` — `blur()` поля.
- Действует на всех экранах и в шторках; прокрутка (сдвиг, `pointercancel`) фокус не снимает.
