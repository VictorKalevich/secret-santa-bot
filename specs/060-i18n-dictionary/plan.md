# Implementation Plan: Тексты — из словаря (шаг 1 локализации)

**Branch**: `060-i18n-dictionary` | **Date**: 2026-11-25 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/060-i18n-dictionary/spec.md`

## Summary

Все тексты для людей (≈ 1100 строк вне комментариев: ≈ 500 в модулях сервера, ≈ 620 в частях приложения) переезжают
в словарь русского языка `src/i18n/ru/` — файл на модуль сервера и на часть приложения (R1); код берёт их по ключу — `ctx.t` на языке
вызывающего, отложенный текст `tx` в сообщениях очереди и подробностях журнала (R2–R5). Язык человека — новая колонка
`users.lang` (пусто — русский, миграция 0021, R3); очередь собирает сообщение на языке получателя при отправке
(подзапрос в операторе захвата, R4); приложение получает словарь своего языка в ответе `me`, до ответа — набор
`app.boot.*`, вставленный сервером в страницу (R6). Формы числа — `Intl.PluralRules`, месяцы — списки словаря (R7);
таблицы (`ACTIONS`, `EVENT_PARAMS`, открытки, маски, правила, причины) хранят ключи (R8). Для людей всё побайтно
прежнее — эталоны не меняются (R11); новый тест `i18n` следит за полнотой и целостностью словаря (R9), псевдоязык
проверяет, что язык берётся у вызова и получателя (R10).

## Technical Context

**Language/Version**: JavaScript ES2022, ES-модули (Cloudflare Workers, workerd)

**Primary Dependencies**: нет рантайм-зависимостей; `Intl.PluralRules` — встроенный (workerd, Node 22, WebKit iOS 13+)

**Storage**: D1 — `users.lang` (миграция `0021_user_lang.sql`, схема 21); `outbox.payload` — отложенные тексты (формат
JSON, без миграции)

**Testing**: `node:test` — новый `tests/i18n.test.mjs` (R9, R10), строгий «мир» (`i18n:` → исключение),
`tests/support/pseudo.mjs`; адаптация проверок исходного кода (R11); эталон отказов, `queries`, e2e, Chrome — без
изменения ожиданий; `checkPseudo` в `tests/screenshots.mjs`

**Target Platform**: Cloudflare Workers + Telegram Bot API + Telegram Mini App (iOS WebKit)

**Project Type**: веб-сервис (Worker) + мини-приложение (`src/app/`)

**Performance Goals**: число запросов к базе и Telegram — прежнее (язык читается в уже существующих запросах); CPU —
словари и их JSON готовятся раз на экземпляр, сборка строки — поиск по объекту и замена подстановок

**Constraints**: тексты для людей побайтно прежние (FR-6002); CSP страницы — правило прежнее (один встроенный скрипт,
отпечаток по отдаваемой странице); `me` — ≈ +40 КБ JSON только в первом вызове сеанса; лимит 4096 символов сообщений
и `CONFIRM_MAX` не задеты (тексты те же)

**Scale/Scope**: ≈ 35 файлов `src/` (все модули с текстами и 9 частей приложения), `design-system/clearable-input.js.txt`,
словари (≈ 1300 ключей), ≈ 15 тестовых файлов с проверками исходного кода, `docs/api.md`, `CLAUDE.md`, README,
Конституция 3.2.0

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

| Принцип | Проверка | Итог |
|---|---|---|
| I. Тайна по умолчанию | Тексты те же; отложенный текст несёт те же подстановки, что готовый (без имён подопечных и писем в уведомлениях); словарь приложения — общие тексты, без данных людей; язык человека не раскрывает ничего о парах. | ✅ |
| II. Проще некуда для участника | Для людей ничего не меняется; «интерфейс на русском» — прежний (меняет шаг 2). | ✅ |
| III. Спецификация до кода | spec → plan → tasks; контракт кода — `contracts/i18n.md`. | ✅ |
| IV. Только дизайн-система | Разметка и классы прежние; тексты — `textContent`/`h()`, значения словаря приложения без HTML. | ✅ |
| V. Бесплатно и без своего сервера | Запросов не прибавляется (R3, R4, R6); CPU — подготовка раз на экземпляр; без внешних зависимостей. | ✅ |
| VI. Проверено до выката | Эталоны и e2e без изменения ожиданий, новый тест словаря «от противного», псевдоязык в быстрых тестах и Chrome. | ✅ |
| VII. Владелец — максимальные права | Права не меняются; конвейер `ACTIONS` прежний, меняется только вид текстов в строках таблицы. | ✅ |

├── looks.js             # без title — ключи looks.card.<id>, looks.mask.<id>

**Structure Decision**: словари — в `src/i18n/` рядом с кодом (Wrangler собирает импорты, сборщик не нужен); файл
словаря повторяет файл кода, файлы `app-*` — граница «что уходит приложению» (R1). Скрипт поля с крестиком встраивается в страницу — его подпись
приходит из словаря приложения.
