# Data Model: Тексты — из словаря (060)

## Язык человека — `users.lang`

| Поле | Тип | Значение |
|---|---|---|
| `lang` | `TEXT NOT NULL DEFAULT ''` | код языка из списка `LANGUAGES` (`src/i18n/index.js`); `''` или неизвестный код — `DEFAULT_LANG` (`ru`) |

- Миграция `migrations/0021_user_lang.sql`: колонка и `settings.schema = 21`; `REQUIRED_SCHEMA = 21` (`src/db.js`).
  Применяется до выката кода: прежний код колонку не читает.
- В шаге 1 значение ставят только тесты. `REGISTRY` (018): колонка не ссылается на человека — описание `users` прежнее;
  перенос участия (010) язык не переносит: у нового аккаунта — свой.
- Читается без новых запросов: `userQuery` — `SELECT *` первого пакета контекста; язык получателя очереди — подзапрос в
  операторе захвата `flushOutbox`.

## Словарь языка — `src/i18n/<язык>/server.js`, `src/i18n/<язык>/app.js`

`export default { [ключ]: значение }`.

| Значение | Вид | Пример |
|---|---|---|
| строка | текст с подстановками `{имя}` | `'pairs.removed': 'Тебя удалили из события {title}. …'` |
| формы числа | `{ one, few, many, other }` — категории `Intl.PluralRules` языка; выбор по `params.n` | `'app.admin.drawConfirm': { one: '…{n} участника…', few: '…', many: '…' }` |
| список | массив строк | `'common.monthsGen': ['января', …]` |

Правила:
- ключ — `<область>.<имя>` (имя — латиница, цифры, точки); область сервера — имя модуля `src/<модуль>.js` или
  `common`/`setup`/`looks`/`audit`; область приложения — `app.<часть>` (`boot`, `core`, `home`, `companies`, `event`,
  `admin`, `vault`, `sheet`);
- ключи `app.*` — только в `app.js`, остальные — только в `server.js`; один ключ — один раз в языке;
- подстановки: данные людей вставляются уже экранированными там, где сейчас (`q(ev)`, `escapeHtml`); HTML-разметка
  сообщений бота — часть значения;
- в шаге 1 язык один — `ru`; служебный `xx` добавляют только тесты (R10).

## Отложенный текст — в `outbox.payload`

JSON, где на месте строки может стоять:

| Вид | Форма | Собирается в |
|---|---|---|
| текст | `{ "$t": ключ, "$p": { имя: значение } }` (`$p` можно опустить) | `t(lang, ключ, собранные $p)` |
| дата | `{ "$d": "YYYY-MM-DD" }` или `{ "$d": ms, "$o": часы }` | `formatDate` / `formatMs` языка |
| склейка | `{ "$j": [части], "$s": разделитель }` | части через разделитель |

Значение подстановки — строка, число или снова отложенный текст. Строки (в том числе сообщения, поставленные прежней
версией) — как есть. Где стоит: `text` сообщения и `text` кнопок (`reply_markup`). Подробность журнала — тот же вид,
собирается на `DEFAULT_LANG` при записи (R5).

## Ответ `me` — поля словаря

| Поле | Когда | Значение |
|---|---|---|
| запрос `texts` | всегда, кроме первого вызова сеанса | версия словаря, который уже есть у приложения |
| `lang` | всегда | язык вызывающего (`langOf(me)`) |
| `texts_version` | всегда | `<язык>:<FNV-1a 32 JSON словаря, hex>` |
| `texts` | запрос без `texts` или с другой версией | словарь `app.*` языка: `{ ключ: значение }` |

Поля есть и в ответе незарегистрированному (`registered: false`).

## Набор до ответа сервера — `app.boot.*`

Ключи `app.boot.*` словаря приложения; сервер вставляет `{ ключ: значение }` русского языка в страницу на место
`/*@boot-texts*/null` (шаг 2 — словари `app.boot.*` всех языков).
