# Quickstart 060: проверка и выкат

## Локально

```powershell
npm test            # в т.ч. tests/i18n.test.mjs, эталон отказов, wording, migrations (0021), queries
npm run screenshots # Chrome: прежние проверки + checkPseudo (человек с псевдоязыком — без кириллицы на экранах)
npm run test:all    # перед слиянием: npm test и e2e
```

Что доказывает прохождение:
- **Для людей ничего не изменилось** (US1): эталон отказов `tests/fixtures/api-refusals.json` не менялся и совпадает
  побайтно; ожидаемые тексты сообщений, экранов и e2e — прежние (в диффе ветки нет правок ожидаемых строк тестов, кроме
  проверок исходного кода — список в `research.md`, R11).
- **Всё — из словаря** (US2): `i18n` — 0 строк с кириллицей вне `src/i18n/`, ключи есть и используются, семейства
  полны, подстановки и формы числа сходятся; правила «от противного» падают.
- **Язык у вызова и получателя** (US3): псевдоязык `xx` у одного человека — он видит только `⟪…⟫` без кириллицы, другие
  — прежний русский; в Chrome — то же на экранах приложения.

Ручная проверка (по желанию): `npm run dev`, открыть `/app` в Telegram-заглушке скриншотов — первый `me` несёт `texts`,
повторный (переход «‹» → главный экран) — без `texts`.

## Выкат (по команде владельца)

Миграция `0021` добавляет `users.lang` и поднимает схему до 21 — её применяют **в обе базы до выката кода** (новый код
без неё не запустится: «схема не готова»; прежний код с ней работает). Порядок — как в CLAUDE.md, раздел «Боты»;
«оба» — сначала второй.

1. Второй бот:
   - `npx wrangler deployments list --env second` — записать текущий Version ID (точка отката);
   - копия базы: `npx wrangler d1 export secret-santa-db-2 --env second --remote --output "backup-secret-santa-db-2-<дата>.sql"`;
   - `npx wrangler d1 migrations apply secret-santa-db-2 --env second --remote`;
   - `npx wrangler d1 execute secret-santa-db-2 --env second --remote --command "SELECT value FROM settings WHERE key = 'schema'"` → `21`;
   - `npm run deploy:second`; `/app` отвечает 200.
2. Первый бот — то же без `--env second` (`--env=""` в Bash), база `secret-santa-db`.

## После выката

- На iPhone: открыть приложение — экраны, подписи, даты, формы числа как раньше; закрыть и открыть снова.
- Бот: `/start`, нажатие кнопки, сообщение от бота (например, объявление организатора) — тексты прежние.
- Логи (`npx wrangler tail <env>`) — нет `i18n:` и `cron step failed`.

## Откат

Код — `npx wrangler rollback <прежний Version ID> <env> -m "откат"` (база не меняется; прежний код колонку `lang` не
читает). Сообщения, которые новая версия поставила в очередь и не успела отправить, прежняя отправить не сможет (Telegram
ответит 400, сообщение удалится): перед откатом подождать минуту после последних действий людей, чтобы cron отправил
очередь. Колонку удалять не нужно.
