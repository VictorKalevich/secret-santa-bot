# Quickstart: проверка «комнаты» (059)

## Автотесты

```powershell
npm test            # правило слов (wording), слово «комната» (app-companies), эталон отказов, тексты сценариев
npm run test:e2e    # сквозной сценарий — новые подписи
npm run screenshots # Chrome: checkCompanies, checkOpenBot — «🚪 Создать комнату», экран «Комнаты»
```

Ожидается: всё зелёное, в `test-results/` на экранах открытого бота — «Комнаты», «🚪 Создать комнату», «Комната 1».

## Выкат

Миграций нет: `npx wrangler deployments list <env>` (точка отката) → `npm run deploy:second` → проверка → `npm run
deploy`. Откат кода — `npx wrangler rollback <Version ID> <env>`; база не меняется, откат безопасен в любую сторону.

Краткое описание бота в Telegram («🎄 Тайный Санта для друзей, семьи и коллег») ставит `/setup`, а после использования
ссылки владельца страница заблокирована (423) до смены `ADMIN_SECRET`. Поэтому в уже настроенных ботах прежнее описание
(«…для своей компании») меняет владелец сам: @BotFather → `/setabouttext` → бот → новый текст. Новые установки получают
его из `/setup`.

## На iPhone (второй бот, открытый)

1. Новый аккаунт (или без событий): «Запустить» → имя → «Открыть» — экран «Комнаты», «Комнат пока нет. Создай свою — или
   попроси пригласительную ссылку на событие.», кнопка «🚪 Создать комнату».
2. «🚪 Создать комнату» → шторка «Новая комната», поле «Название комнаты» → «🚪 Комната создана».
3. «‹» → «⚙️» у комнаты → «🗑 Удалить комнату» → слово «УДАЛИТЬ» → «Комната удалена».
4. Создать третью при двух своих — «Вести можно не больше двух своих комнат — передай или удали одну из них.»
5. В меню бота без событий — «…Создай свою комнату в приложении…».

Нигде нет слова «компания».
