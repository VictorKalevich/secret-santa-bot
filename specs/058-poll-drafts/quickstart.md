# Quickstart 058: проверка и выкат

## Локально

```powershell
npm test                              # в т.ч. tests/poll-drafts.test.mjs (расписания и опрос по склейке)
node --test tests/poll-drafts.ui.mjs  # Chrome: запросы опроса и черновика (Playwright clock, заглушка SDK)
node --test tests/letter-drafts.ui.mjs  # Chrome: сценарий 041 — как раньше
npm run test:all                      # перед слиянием: npm test и e2e
```

`poll-drafts.ui.mjs` (Chrome или `CHROME_PATH`) проверяет:

- открытый бот, открытая переписка без новых сообщений: за 5 минут — не больше 9 запросов `chat.get`, следующие 5 минут —
  ни одного, касание шторки — запрос сразу; свёрнутое приложение (событие `deactivated` заглушки SDK) — ни одного запроса,
  `activated` — запрос сразу;
- закрытый бот: 10 запросов в минуту, свёрнутое — ни одного;
- черновик: набор 20 секунд — не больше 5 сохранений; свернули — сохранение сразу; ушли на «Инфо» — сохранение сразу и
  без вопроса; вернулись во время сохранения и дописали — без ошибки «Письмо или настройки изменились».

## Выкат (по команде владельца)

Миграций нет, сервер не меняется — обычный выкат: «оба» — сначала второй, проверка, потом первый (CLAUDE.md, «Боты»).
`npx wrangler deployments list <env>` — точка отката; `npm run deploy:second` / `npm run deploy`; `/app` отвечает 200.

## Проверка на iPhone (владелец)

1. Открыть переписку, свернуть Telegram или мини-приложение на минуту, вернуться — шторка сразу обновилась.
2. Открытый бот: переписка открыта 5 минут без сообщений, собеседник пишет — сообщение в чате бота; коснуться шторки
   или вернуться в приложение — сообщение появилось.
3. Событие с черновиками: напечатать абзац, сразу свернуть приложение, открыть письмо на ПК — текст на месте.
4. Напечатать и сразу нажать «Инфо» — без вопроса; вернуться на «Письмо» — текст и статус «Черновик» на месте.

## Откат

`npx wrangler rollback <прежний Version ID> <env> -m "откат"`; база не меняется.
