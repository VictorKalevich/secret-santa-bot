# План 045

В дизайн-системе добавить компонент с исходным input и соседней кнопкой type="button". Видимость связать с состоянием самого поля, чтобы присваивание value, автозаполнение и сброс формы отражались сразу. Подписи формы связать с исходными полями. Обработчик очистки возвращает фокус и посылает всплывающее событие input.

Подключить общий компонент к формам мини-приложения, ключу настройки и витрине. Использовать существующие токены темы и размера контрола. Проверить на узком экране, мышью, касанием и клавиатурой.

## Проверка Конституции

I, VII. Изменение локально для формы. Доступ к данным и права прежние.
II, IV. Для очистки значения нужен один жест. Размер и вид задаёт дизайн-система.
III, VI. Спецификация задаёт сценарии до реализации, тесты проверяют их до слияния.
V. Очистку выполняет браузер без запросов к Worker и D1.

## Приёмка

Запустить `npm test`, `npm run test:e2e`, `npm run screenshots` и `node --test tests/clearable-inputs.ui.mjs tests/shipment.ui.mjs`. Слить проверенный коммит в main.
