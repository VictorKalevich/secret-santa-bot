# Исследование 053

## R1. Как открыть ссылку во внешнем браузере

- **Decision**: `Telegram.WebApp.openLink(url)` по нажатию на кнопку; без SDK (страница вне Telegram) —
  `window.open(url, '_blank', 'noopener')`. Помощник `openWebLink(url)` в `02-core` рядом с `openTgLink`.
- **Rationale**: `openLink` (Bot API 6.1+) — штатный способ Telegram открыть внешнюю ссылку, не закрывая мини-приложение;
  SDK сам переходит на `window.open` у старых клиентов. Telegram требует, чтобы вызов шёл из обработчика нажатия — так и
  есть. На iPhone браузер выбирает Telegram по настройке пользователя (Safari или встроенный).
- **Alternatives considered**: `<a href target="_blank">` — внутри Telegram ведёт себя по-разному на платформах и может
  открыть страницу во вьюере поверх приложения; `openTgLink` — только для `t.me`; `openLink(url, { try_instant_view })` —
  Instant View для страницы сбора не нужен.

## R2. Где хранить ссылку и как показать блок только во втором боте

- **Decision**: константа `DONATE_URL = 'https://dalink.to/trivial_no'` в `05-event`; блок строится, только если
  `state.open` (из `me.open`, сервер отдаёт его только открытому боту — 052).
- **Rationale**: сервер, API, `docs/api.md` и эталоны не меняются; ссылка постоянная, её смена — правка одной строки и
  выкат (так же было бы и с переменной окружения: `vars` меняются выкатом).
- **Alternatives considered**: переменная `DONATE_URL` в `[env.second.vars]` и поле в `me` — гибче (включить в первом
  боте без кода), но это новое поле API, раздел `docs/api.md`, эталоны отказов и правило «признак — только `openBot(env)`»;
  владелец просил только второй бот.

## R3. Вид: компонент дизайн-системы

- **Decision**: токены `--ds-color-donate: #ed8224` и `--ds-color-on-donate: #ffffff` (рядом с праздничным брендом),
  вариант кнопки `.ds-btn--donate`, карточка `.ds-donate` (на `ds-card`: колонка по центру, `__icon` — `--ds-text-icon`,
  `__title` — `lg`/`bold`, `__text` — `md`/приглушённый, `__note` — `sm`/приглушённый, кнопка с отступом сверху).
  Цвет взят из образца владельца (замер пикселя кнопки `123.jpg` — `#ED8224`). Сердце — ❤️, как в образце.
- **Rationale**: принцип IV — новый элемент сначала в дизайн-системе; повтор `ds-empty` не подходит по смыслу
  («нет данных») и отступам (32 px сверху и снизу).
- **Alternatives considered**: `ds-empty` в карточке — см. выше; вторичная кнопка темы (первый макет) — владелец выбрал
  оранжевую.
- **Контраст**: белый на `#ED8224` ≈ 2.7 : 1 (ниже 4.5 : 1 для обычного текста). Решение владельца — фирменный вид
  DonationAlerts; подпись полужирная 16 px, рядом пояснение и заголовок карточки обычного контраста.

## R4. Место на «Инфо»

- **Decision**: `nodes.push(...donateSection())` сразу после строки подсказки неучастнику в `renderInfo` — то есть после
  «Нужна помощь?» (участнику, если есть кому писать), после подсказки «Ты не участвуешь…» (неучастнику), иначе после
  участников/объявлений; всегда перед «Как это работает».
- **Rationale**: «Нужна помощь?» и подсказка неучастнику взаимоисключающие (первое — только `state.member`), поэтому одна
  точка вставки даёт место из FR-002 во всех случаях.
