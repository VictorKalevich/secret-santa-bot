```powershell
npm run screenshots                   # checkDonate: «✔ поддержка проекта …», снимки test-results/53-donate*.png

```

`checkDonate` (Chrome, ширина 390 и 320):

1. Открытый бот (мир с `OPEN_BOT = 1`): участник с «Нужна помощь?» — разделы «Нужна помощь?» → «Нравится бот?» →
   «Как это работает»; в карточке ☕, заголовок, текст, кнопка, строка благодарности; нажатие вызывает
   `Telegram.WebApp.openLink('https://dalink.to/trivial_no')` (заглушка SDK), запросов `/api/*` при нажатии нет.
2. Владелец-организатор того же события и завершённое событие — блок есть, стоит перед «Как это работает».
3. Кнопка оранжевая `rgb(237, 130, 36)` с белым текстом в светлой и тёмной теме.
4. Ширина 320: нет горизонтальной прокрутки, подпись кнопки не обрезана.
5. Закрытый бот (основной мир): на «Инфо» нет «Нравится бот?» и `.ds-donate`.

## Выкат (только второй бот, по команде владельца)

Миграций нет, сервер не менялся — выкат только кода:

```powershell
npx wrangler deployments list --env second        # запомнить текущий Version ID (откат)
npm run deploy:second
```

После выката: `/app` второго бота отвечает 200; на iPhone — «Инфо» любого события: блок под «Нужна помощь?», нажатие
открывает страницу DonationAlerts в браузере, приложение остаётся открытым. Первый бот выкатывать не нужно (блока там
нет), но и вреда не будет: код один, в закрытом боте `me.open` нет.

Откат: `npx wrangler rollback <прежний Version ID> --env second -m "откат"` (база не менялась).
