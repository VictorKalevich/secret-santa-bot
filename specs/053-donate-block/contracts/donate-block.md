# Контракт 053: блок «Нравится бот?» на «Инфо»

## 1. Когда показан

- Только при `state.open === true` (ответ `me` открытого бота, 052). В закрытом боте блока нет ни у кого.
- В идущих и завершённых событиях, у любой роли (участник, организатор-участник, организатор-неучастник, владелец бота).

## 2. Место

В `renderInfo` (`src/app/05-event.js.txt`) — сразу после «Нужна помощь?» / подсказки неучастнику, перед «Как это
работает». Порядок заголовков разделов на «Инфо» (те, что показаны):

`О событии` → `Участники · N` → `Объявления` → `Нужна помощь?` → **`Нравится бот?`** → `Как это работает` →
`Выход из события`.

## 3. Разметка (только классы дизайн-системы)

```text
div.ds-section-title                     «Нравится бот?»
div.ds-card.ds-donate
  div.ds-donate__icon                    «☕»
  div.ds-donate__title                   «Поддержать проект»
  div.ds-donate__text                    «Бот полностью бесплатный. Если он оказался вам полезен, вы можете поддержать его развитие и дальнейшее улучшение.»
  button.ds-btn.ds-btn--donate.ds-btn--block   «❤️ Поддержать через DonationAlerts»
  div.ds-donate__note                    «Любая сумма имеет значение. Спасибо!»
```

Тексты — дословно. Кликабельна только кнопка.

## 4. Поведение кнопки

- Нажатие → `openWebLink(DONATE_URL)`, `DONATE_URL = 'https://dalink.to/trivial_no'`.
- `openWebLink(url)` (`02-core`): есть SDK (`tg`) — `tg.openLink(url)`; нет — `window.open(url, '_blank', 'noopener')`.
- Запросов к Worker нет; `busy` не нужен (повторное нажатие — повторное открытие ссылки).

## 5. Дизайн-система

| Что | Значение |
|---|---|
| `--ds-color-donate` | `#ed8224` — фирменный оранжевый DonationAlerts, одинаковый в обеих темах |
| `--ds-color-on-donate` | `#ffffff` |
| `.ds-btn--donate` | фон `--ds-color-donate`, текст `--ds-color-on-donate`; только кнопка поддержки проекта |
| `.ds-donate` | карточка-колонка по центру: `__icon` (`--ds-text-icon`), `__title` (`lg`, `bold`), `__text` (`md`, приглушённый), `__note` (`sm`, приглушённый); кнопка — на всю ширину, отступ сверху |

## 6. Правила кода (тест `donate`)

1. Адрес `https://dalink.to/trivial_no` встречается в склейке один раз — в `DONATE_URL`.
2. `ds-donate` и `ds-btn--donate` строит только `donateSection`; `DONATE_URL` читает только она.
3. `donateSection` возвращает пустой список без `state.open` (первая проверка функции).
4. В `renderInfo` вызов `donateSection()` — после подсказки неучастнику и до раздела «Как это работает».
5. Кнопка открывает ссылку только через `openWebLink`; `openLink(` и `window.open(` с внешним адресом — только в
   `openWebLink` и прежнем `openTgLink`.
6. Дизайн-система: оба токена определены в `tokens.css`, `.ds-btn--donate` берёт их, витрина показывает `ds-donate` и
   `ds-btn--donate`, README их описывает.

У каждого правила — проверка «от противного» (испорченная склейка находится).
