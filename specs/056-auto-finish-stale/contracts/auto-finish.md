# Контракт 056: автозавершение брошенных событий (открытый бот)

Действует только при `openBot(env)` (052). Закрытый бот: правила не проверяются, отметка не ставится, сообщений нет.

## Когда

Ежедневный шаг cron (`dailyStep`, `src/cron.js`), с `REMINDER_HOUR` по местному времени, для идущего события, у
которого `last_daily != сегодня` и нет автодействия расписания. Порядок решений для такого события:

1. Подходит под правило и `finish_warned != ''` и `finish_warned + 7 дней ≤ сегодня` → кандидат «завершение»
   (`finishEvent(ctx, ev, 0)`).
2. Иначе ежедневное напоминание (как было) → кандидат.
3. Иначе подходит под правило и `finish_warned = ''` → кандидат «предупреждение».
4. Иначе не подходит и `finish_warned != ''` → отметка снимается (`finish_warned = ''`, `last_daily = сегодня`), без
   сообщений и журнала.
5. Иначе — «тихое» (`last_daily = сегодня`), как было.

За запуск выполняется один кандидат (автодействия расписания, напоминания, предупреждения и завершения — общий список,
выбор по минуте суток, как было). Правила — `data-model.md`; пороги — `STALE` в `src/stale.js`.

## Предупреждение

Атомарно (`atomic`, вид «по прежнему состоянию»): условие — событие идёт и `finish_warned = ''`; перед захватом —
сообщения и запись журнала; захват — `finish_warned = сегодня`, `last_daily = сегодня`. Из одновременных — одно.

Получатели — `adminRecipients(users)` компании события (зарегистрированные администраторы компании; владелец бота — если
он человек компании). Сообщение (HTML, `msg`), `<дата>` — `formatDate(сегодня + 7)`, кнопка
`appKeyboard(settings, '⚙️ Открыть событие', { event: <id> })`:

| Причина | Текст |
|---|---|
| А | `⏳ <b>Событие «<название>» завершится автоматически <дата>.</b>\nДата вручения (<event_date>) уже прошла.\n\nЕсли событие ещё нужно — перенеси дату вручения: «Управление» → «Параметры».` |
| Г | `⏳ <b>Событие «<название>» завершится автоматически <дата>.</b>\nВ него пока никто не вступил, кроме владельца и администраторов.\n\nЕсли событие ещё нужно — пригласи участников или укажи дату вручения: «Управление» → «Параметры».` |
| Б | `⏳ <b>Событие «<название>» завершится автоматически <дата>.</b>\nУ него нет даты вручения, а создано оно больше трёх месяцев назад.\n\nЕсли событие ещё нужно — укажи дату вручения: «Управление» → «Параметры».` |

`<название>` — `escapeHtml`; `<event_date>` — `formatDate`. Имён, пар, писем, названия компании нет. Роли — словами 044
(«владелец», «администратор»), вкладка — «Управление».

Журнал события: `finish.warn`, автор 0 (бот), подробности — `дата вручения прошла; завершится <дата>` |
`никто не вступил, кроме владельца и администраторов; завершится <дата>` | `нет даты вручения; завершится <дата>`. Подпись в
приложении — `⏳ Предупреждение об автозавершении`.

## Завершение

`finishEvent(ctx, ev, 0)` без изменений: участникам — прежнее «🏁 Событие … завершено», переписка ещё 7 дней, журнал
`finish` от бота. Пары не раскрываются.

## Сброс и образец

Полный сброс (`EVENT_STATE_RESET`) ставит `finish_warned = ''`; создание по образцу колонку не копирует; ответы API её
не содержат.

## Запросы

Ежедневный шаг читает события одним запросом `dailyEventsQuery` (идущие, индекс `events_active`) с колонкой `outsiders`:
число участников, которые не администраторы компании события (`company_members.is_admin = 1`; владелец компании —
всегда её администратор, инвариант I3) и не владелец бота; считается только при `open` и только для событий без даты, без жеребьёвки, созданных не позже 22 дней
назад и ещё не проверенных сегодня (иначе `-1`). Обычная минута — 3 запроса (уведомления, события, очередь).
