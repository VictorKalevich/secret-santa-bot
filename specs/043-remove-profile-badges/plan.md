# План удаления отдельного значка у имени

## Изменения

- В мини-приложении оставить кнопку изменения имени. Приветствие, списки участников, карточка подопечного и обращения выводят имя напрямую.
- Убрать `emoji.set`, набор профильных значков и соответствующие поля из ответов API. Старая версия клиента получит отказ 404.
- После выката нового Worker применить миграцию `0014_remove_profile_badges.sql`. Она очистит `users.emoji` у всех пользователей. Новый Worker не читает это поле и не записывает в него, поэтому между выкатом и миграцией значки уже скрыты. Колонка остаётся пустой для совместимости схемы при откате. Версия схемы остаётся 16.
- Обновить действующие описания профиля и API. Исторические спецификации 038–040 пометить ссылкой на 043.

## Technical Context

JavaScript, Telegram Mini App, Cloudflare Workers и D1. Проверки через `npm run test:all` и браузерные сценарии профиля, открыток и масок.
