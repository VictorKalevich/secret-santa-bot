# Quickstart: проверка фичи 030

## Локально (до слияния)

```powershell
npm test                                  # всё, в т.ч. новый tests/app-panel.test.mjs
node --test tests/app-panel.test.mjs      # три правила по склейке и «от противного»
npm run test:e2e                          # сквозной сценарий (сервер не менялся — всё как раньше)
npm run screenshots                       # снимки в test-results/ и проверки в Chrome, в т.ч. checkRegistration
```

Ожидается: всё зелёное; в выводе `screenshots` — строка `✔ переключатель регистрации (030): …`, код выхода 0.

Слепки до и после (скрипт вне репозитория: `wrangler dev` + Chrome, разметка `#main` и шторок с состоянием полей; время
«сегодня в …» и код приглашения нормализованы; два прогона одного кода совпадают побайтно). Итог 2026-11-16:

- 16 состояний панели и 65 шторок (меню участника, перенос, опасная зона): после разбиения (US2) и после «без копий»
  (US3) — побайтно как до правок; после US1 — отличие только в скрытой подсказке у заявок при открытой регистрации.
- 23 действия в панели (кольцевая, исключения и закреплённые пары формой и ✕, семьи, черновик, сохранение параметров,
  выбор события, переключатели «Удалённые могут вернуться», «Вступление по одобрению», «Регистрация открыта», отклонение
  заявки, «Я участвую»): то же; после US1 — ещё «Регистрация закрыта» показывает недоступную кнопку и обе подсказки.
- Проверка `checkRegistration` на коде до исправления падает (кнопка доступна, подсказки прежние).

## Выкат

Миграций у фичи нет, база не меняется. Боевая версия сейчас — код до 027; вместе с 030 уходят 028 (шторка календаря —
проверка на iPhone по `specs/028-calendar-sheet/quickstart.md`) и 029 (сервер без изменения поведения).


## Проверка на iPhone (Telegram для iOS)

Страница приложения не кэшируется — новая версия открывается сразу; если нет — закройте мини-приложение (✕ вверху) и
откройте снова. Нужно событие, где есть прошлое событие (блок «📨 Пригласить участников») — у владельца их несколько.

1. **Подготовка.** Бот → «🎁 Санта» → «🎄 Создать» → название «Проверка 030» → «Создать». Откроется панель события.
2. **Закрыть регистрацию.** В «Из какого события…» выберите любое событие, в «Объявление» наберите «черновик» (не
   отправляйте). Вернитесь к «Приглашение» и выключите «Регистрация открыта». Ожидается сразу: сообщение «Регистрация
   закрыта»; «📨 Пригласить участников» серая; над ней — «Пригласить участников прошлого события можно, когда
   регистрация открыта.»; экран не мигнул загрузкой и не прыгнул; выбранное событие и «черновик» на месте.
3. **Открыть регистрацию.** Включите переключатель. Ожидается: «Регистрация открыта»; кнопка снова синяя, подсказка —
   «…например, ту же компанию на следующий год.»; выбор и черновик на месте.
4. **Заявки** (если есть кому прислать заявку): включите «Вступление по одобрению», попросите кого-нибудь открыть
   ссылку приглашения — в панели (после «Инфо» → «Админ») появится «Заявки · 1». Выключите регистрацию — над списком
   «Регистрация закрыта — принять заявку можно, когда откроешь её. Отклонить можно сейчас.»; включите — надпись исчезла.
   Без второго человека пункт можно пропустить: в Chrome он проверен.
5. **Остальная панель — как раньше.** «🔁 Кольцевая жеребьёвка» выкл/вкл — сообщения те же; «⋯» у себя в «Участники» —
   меню как раньше; «Опасная зона» → «🧨 Полный сброс» — список удаляемого, ✕.
6. **Шторки участника.** В событии с жеребьёвкой: «Подопечный» → «💬 Написать подопечному» → ✕ — вкладка «Подопечный»
   на месте; «Инфо» → «Написать организатору» → ✕ — «Инфо» на месте.
7. **Уборка.** «Проверка 030» → «Опасная зона» → «🗑 Удалить событие» → слово УДАЛИТЬ → «🗑 Удалить навсегда» → OK.

Что-то выглядит или работает иначе, чем раньше (кроме пунктов 2–4), — откат.

## Откат

База не менялась — откатывается только код Worker.

```powershell
npx wrangler rollback                     # к предыдущей версии; спросит подтверждение
# или к конкретной версии из `deployments list`:
npx wrangler rollback <Version ID> -m "откат 030"
```

Проверка: откройте мини-приложение заново — прежний вид (переключатель регистрации снова не меняет кнопку до
перехода по вкладкам). Вернуть 030 — `npm run deploy` с `main`.
