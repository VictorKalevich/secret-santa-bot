# Проверка

Из корня репозитория запустить `npm test` и `npm run test:e2e`. Для браузерной проверки запустить `npm run screenshots` с установленным Chrome или указать путь к Chromium в `CHROME_PATH`.

1. На «Инфо» открыть событие с владельцем, администратором и участником. Сверить подписи с главным экраном и списком в «Управлении». Сценарий с единственным владельцем и экраном шириной 320 пикселей включён в `node --test tests/letter-drafts.ui.mjs`.
2. Открыть «Задать вопрос» участником. Ответить в Telegram и проверить подпись сначала администратора, затем владельца. Проверить подсказки до и после жеребьёвки для разных ролей.
3. Проверить, что API и интерфейс по-прежнему ограничивают перенос участия, удаление, сброс и вписывание владельцем. Сверить тексты соответствующих уведомлений.
