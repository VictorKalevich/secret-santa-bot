# Данные ролей

Используются прежние признаки владельца и администратора. Текущий владелец определяется по `settings.owner_id` с существующим запасным правилом. У зарегистрированного владельца есть административный доступ, а в списке людей его роль показывается отдельно.

Участник события в `roster.people` имеет `role` со значением `owner`, `admin` или пустой строкой. В `roster.organizers` владельца определяет `owner: true`. Формы объектов, ключи журнала, структура таблиц и данные пользователей сохраняются.
