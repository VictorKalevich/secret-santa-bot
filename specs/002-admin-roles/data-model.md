# Data Model: изменения в 002

Базовая модель — [001/data-model.md](../001-secret-santa-bot/data-model.md). Таблицы не меняются.

## settings — новый ключ

| Ключ | Значение | Правила |
|---|---|---|
| `owner_id` | Telegram ID владельца | ровно один; пользователь существует и `is_admin = 1`; если не задан/недействителен — вычисляется по FR-109 и сохраняется |

## Роли (вычисляемые)

| Роль | Условие | Может |
|---|---|---|
| Владелец | `tg_id = owner_id` | всё, что админ + назначать/снимать админов, передавать владение, удалять админов |
| Админ | `is_admin = 1` и не владелец | вести игру; удалять только не-админов |
| Участник | `registered = 1`, `is_admin = 0` | как в 001 |

## Переходы

```text
участник ──(владелец: назначить)──▶ админ ──(владелец: снять)──▶ участник
админ/участник ──(владелец: передать владение)──▶ владелец; прежний владелец ──▶ админ
кто угодно ──(ссылка /setup)──▶ владелец; прежний владелец ──▶ админ (+ предупреждение)
```
