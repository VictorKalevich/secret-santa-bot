# Contract: роли — изменения API, чата и сообщений

> **С фичи 005** действия привязаны к эвенту (поле `event`), см. [`specs/005-events-history/contracts/events.md`](../../005-events-history/contracts/events.md).
> Этот контракт описывает поведение внутри одного эвента.


Дополняет контракты [001](../../001-secret-santa-bot/contracts/).

## API мини-приложения

| Action | Кто | Тело | Эффект / ответ | Ошибки |
|---|---|---|---|---|
| `me` | все | — | `me.is_owner` (новое поле) | — |
| `admin.state` | админ | — | `users[].is_owner` (новое поле), `settings.owner_id`, `settings.owner_name`; по-прежнему без пар и текстов | — |
| `admin.role.grant` | владелец | `{id}` | `is_admin = 1`; сообщения: назначенному, тихо — остальным админам | 403 не владелец; 400 не зарегистрирован / уже админ |
| `admin.role.revoke` | владелец | `{id}` | `is_admin = 0`; сообщения: снятому, тихо — остальным админам | 403 не владелец; 400 это владелец / не админ |
| `admin.owner.transfer` | владелец | `{id}` | `owner_id = id`, `is_admin = 1`; прежний владелец остаётся админом; сообщения: новому владельцу, тихо — остальным админам | 403 не владелец; 400 не зарегистрирован / уже владелец |
| `admin.remove` | админ | `{id}` | как в 001, плюс: владельца удалить нельзя; админа — только владелец | 400/403 с объяснением |

## Чат

| Ссылка | Поведение |
|---|---|
| `t.me/<bot>?start=adm_<код>` | Делает пользователя **владельцем** (и админом). Если владельцем был другой — тот остаётся админом и получает предупреждение. |

Меню: строка «👑 Ты владелец игры — …» для владельца, «🛠 Ты администратор — …» для админа.

## Сообщения

| Событие | Кому | Текст (суть) | Звук |
|---|---|---|---|
| Назначен админом | назначенный | «🛠 Владелец назначил тебя администратором игры…» + кнопка приложения | да |
| Сняты права | снятый | «Владелец снял с тебя права администратора.» | да |
| Передано владение | новый владелец | «👑 Тебе переданы права владельца игры…» + кнопка приложения | да |
| Владение по ссылке | прежний владелец | «⚠️ Права владельца перешли к <имя> по ссылке со страницы настройки. Если это не ты — смени ADMIN_SECRET…» | да |
| Изменён состав админов | остальные админы | «ℹ️ <имя> теперь администратор / больше не администратор / владелец игры» | нет |

## Страница `/setup`

«Ссылка администратора» переименована в «Ссылка владельца» с пояснением, что владелец назначает админов, а ссылку нельзя
пересылать.
