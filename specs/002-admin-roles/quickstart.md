# Quickstart: проверка 002

## Автотесты

```powershell
npm test             # включает правило: базовые стили элементов только через :where()
npm run test:e2e     # включает сценарий «роли»: назначение, снятие, передача, защита, ссылка владельца
npm run screenshots  # проверяет вычисленные цвета выбранной вкладки и кнопок в светлой и тёмной теме
```

Ожидаемо: всё зелёное; `npm run screenshots` печатает «✔ цвета вкладок и кнопок соответствуют дизайн-системе».

## Вручную в Telegram (после `npm run deploy`)

1. Перейти по ссылке владельца с `/setup` → в меню «👑 Ты владелец игры».
2. «Админ» → «Администраторы» → выбрать участника → «Назначить админом» → у него появилась вкладка «Админ» и сообщение.
3. Под этим админом: в разделе «Администраторы» нет кнопок управления; у владельца в списке участников нет 🗑.
4. Владелец: «Снять» → у бывшего админа вкладка «Админ» пропала.
5. Светлая тема: на выбранной вкладке и кнопке «Сохранить» текст белый.
