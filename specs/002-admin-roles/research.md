# Research: роли и читаемость

**Feature**: [spec.md](./spec.md) · **Date**: 2026-11-12

## 1. Где хранить владельца

- **Decision**: ключ `settings.owner_id` (Telegram ID); владелец всегда `users.is_admin = 1`.
- **Rationale**: «ровно один владелец» естественно выражается одним значением; не нужна миграция схемы.
- **Alternatives considered**: колонка `users.role` (`owner`/`admin`/`user`) — пришлось бы следить за единственностью
  владельца и мигрировать таблицу.

## 2. Кто становится владельцем без явного назначения

- **Decision**: `resolveOwner`: если `owner_id` не задан или указывает на удалённого — владелец = админ с самым ранним
  `created_at`; найденное значение сохраняется.
- **Rationale**: совместимость с данными версии 1, где были только админы.

## 3. Ссылка со страницы настройки

- **Decision**: та же ссылка `adm_<код>` теперь делает **владельцем**; прежний владелец остаётся админом и получает
  предупреждение (если это другой человек).
- **Rationale**: хозяин `ADMIN_SECRET` контролирует Cloudflare, значит он — корень доверия; ссылка служит и восстановлением
  доступа. Отдельная ссылка «стать админом» убрана: иначе роли снова раздавались бы в обход владельца.

## 4. Права на удаление участников

- **Decision**: владельца удалить нельзя никому; админа может удалить только владелец; остальных участников — любой админ.
- **Rationale**: иначе «удаление из игры» стало бы обходным способом снять админа.

## 5. Почему текст выбранной вкладки был чёрным

- **Причина**: в `components.css` правило `.ds-root button { color: inherit }` имеет специфичность (0,1,1), а
  `.ds-tab--active` и `.ds-btn--*` — (0,1,0). Базовое правило побеждало, и кнопки наследовали цвет текста страницы:
  в тёмной теме это белый (ошибка незаметна), в светлой — чёрный.
- **Decision**: базовые стили элементов писать через `:where()` (нулевая специфичность):
  `:where(.ds-root) :where(button, input, textarea, select) { font: inherit; color: inherit; }`. Тест запрещает
  базовые селекторы элементов вне `:where()`, скриншоты проверяют вычисленные цвета.
- **Дополнительно**: подпись вкладки увеличена с 12 до 13 px для читаемости белого текста на синем.
- **Alternatives considered**: менять цвет выделения — не нужно: синий с белым текстом совпадает с кнопками Telegram
  и автоматически следует теме пользователя.
