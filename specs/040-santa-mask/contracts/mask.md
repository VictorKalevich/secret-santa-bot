# Contract: маска Санты в переписке (040)

## Набор

`MASKS`, `validMask`, `maskLabel` — `src/looks.js` (data-model.md). Приложение получает набор в `me`:
`looks: { emojis, postcards, masks }`.

## Действие

| Действие | Кто | Событие | В завершённом | Запрос | Ответ | Отказы (400) | Журнал |
|---|---|---|---|---|---|---|---|
| `mask.set` | MEMBER | да | нет — «Событие завершено: маску больше не сменить.» | `event`, `mask` (`''` — без маски) | `{ mask }` | «Такой маски нет — выбери из списка.»; «Тайна уже раскрыта — маску больше не сменить.»; «У тебя пока нет подопечного.» | нет |

Порядок проверок обработчика: набор → раскрытие (событие вызова) → `UPDATE … AND тайна не раскрыта` → 0 строк: событие
заново — раскрыта / нет подопечного. Сообщений нет. Повтор и одновременные нажатия — результат последней записи.

## Поля ответов

- `me`: `looks.masks` — `[{ id, emoji, title }]`.
- `event.get`: `member.santa_mask` — маска Санты участника (`''` — нет маски или нет Санты).
- `ward.get` (`state: 'ok'`): `mask` — своя маска в этой паре.
- `chat.get` (`state: 'ok'`): `mask` — маска пары (Санте — своя, подопечному — его Санты).
- Нет маски: `admin.*` (в т.ч. `admin.state`, `admin.audit`, `admin.wishlist`, `admin.users`, `admin.vault.*`),
  `roster`, `support.*`, журнал.

## Бот (`maskLabel(mask)` = «🐉 Дракон»; при `''` — прежний текст)

| Кому | Когда | Текст с маской |
|---|---|---|
| подопечному | Санта пишет (приложение или ответ в боте) | `💬 <b>Твой Тайный Санта «🐉 Дракон» (<название>) пишет:</b>` |
| подопечному | «↩️ Ответить» / «💬 Санте» | `✍️ Напиши сообщение своему Санте «🐉 Дракон» («…») — я передам его. Санта знает, кто ты, а ты его — нет.` |
| Санте | «↩️ Ответить» / «💬 Подопечному» | `✍️ Напиши сообщение подопечному («…») — я передам его <b>анонимно</b>, от имени «Тайного Санты · 🐉 Дракон».` |
| подопечному | раскрытие | `🎅 <b>Тайна раскрыта!</b>\n\nВ событии «…» твой Тайный Санта «🐉 Дракон» — <b>Боря</b>. С праздником! 🎄` |

Санте о сообщении подопечного — прежний текст (маска — не имя собеседника). Все тексты — без прошедшего времени.

## Дизайн-система

- `.ds-choices--labeled` — сетка плиток с подписью (колонка — `--ds-size-choice-card`); `.ds-choice` в ней — столбик:
  эмодзи над подписью, высота не меньше `--ds-size-choice-card`.
- `.ds-choice__label` — подпись плитки (`--ds-text-xs`, цвет текста, перенос по словам).
- Витрина — плитки «Без маски», «🐉 Дракон» (выбрана), «🕵️ Тайный агент»; строка в README дизайн-системы.

## Приложение

- `maskLabel(id)` (`04-event`) — по `state.looks.masks`; единственное место, где из маски получается текст.
- «Подопечный» (`renderWard`), раздел «Переписка с подопечным»: подсказка «Есть вопрос? Напиши подопечному — для него ты
  «Тайный Санта · 🐉 Дракон», имя не раскрывается.» (без маски — «Тайный Санта»); пока можно менять (`!finished()` и
  `!state.ev.revealed`) — кнопка «🎭 Маска: <маска | без маски>» → `openMaskSheet`; иначе, если маска есть, — подсказка
  «Маска в переписке: 🐉 Дракон.»
- `openMaskSheet(current, saved)` — шторка «Маска в переписке»: подсказка «Так подопечный увидит тебя в переписке и в
  сообщениях бота. Кто под маской, он узнает, когда организатор раскроет тайну. Маска своя в каждом событии.», сетка
  `ds-choices ds-choices--labeled` — «Без маски» и 20 масок, выбранная — `ds-choice--selected`; нажатие —
  `busy(плитки)` → `mask.set`, шторка закрывается, сообщение «Маска выбрана» / «Маска снята», `saved(mask)` обновляет
  кнопку и подсказку на месте.
- «Письмо» (`renderMy`), раздел «Переписка с Сантой»: при `member.santa_mask` — строка «Твой Санта — в маске «🐉 Дракон».»
- `openChat` (`07-sheet-chat`): заголовок — узел; подопечному — «Твой Тайный Санта» или «Твой Тайный Санта · 🐉 Дракон»
  (сначала `state.member.santa_mask`, затем `mask` каждого ответа `chat.get`); Санте — «Переписка с подопечным», подсказка
  «Для подопечного ты — «Тайный Санта · 🐉 Дракон», имя не раскрывается.» (из `mask` ответа). Значков у имени в
  переписке по-прежнему нет.
