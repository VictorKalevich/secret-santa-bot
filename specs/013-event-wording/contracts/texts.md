Правила для всех остальных строк — research R1. Ниже — подписи, выбранные владельцем проекта, и образцы сообщений бота.

## Подписи мини-приложения

| Где | Было | Стало |
|---|---|---|
| Главный экран, раздел | Мои эвенты | Мои события |

## Образцы сообщений бота

| Было | Стало |
|---|---|
| 👋 **Имя** присоединяется к эвенту «X» | 👋 **Имя** присоединяется к событию «X» |
| 🎄 **Жеребьёвка в эвенте «X» проведена!** | 🎄 **Жеребьёвка в событии «X» проведена!** |
| 🏁 **Эвент «X» завершён.** | 🏁 **Событие «X» завершено.** |
| 🗑 Эвент «X» удалён организатором | 🗑 Событие «X» удалено организатором |
| 📨 **Приглашение в эвент «X»** | 📨 **Приглашение на событие «X»** |
| 🎉 Тебя приняли в эвент «X»! | 🎉 Заявка одобрена — ты в событии «X»! |
| ⏳ Заявка в эвент «X» отправлена… | ⏳ Заявка на участие в событии «X» отправлена… |
| 🙋 **Имя** просится в эвент «X». | 🙋 **Имя** хочет участвовать в событии «X». |
| Регистрация в эвент «X» закрыта. | Регистрация на событие «X» закрыта. |
| 💬 **Имя** дополняет обращение (эвент «X»): | 💬 **Имя** дополняет обращение («X»): |
| ✅ Заявка принята: **Имя**, эвент «X». | ✅ Заявка принята: **Имя**, «X». |
| ✍️ Напиши сообщение подопечному (эвент «X») — я передам его | ✍️ Напиши сообщение подопечному («X») — я передам его |
| Твои эвенты: | Твои события: |
| Эвент не найден. | Событие не найдено. |

Заголовки переписки («💬 Тебе пишет твой подопечный («X»):», «💬 Твой Тайный Санта («X») пишет:») слова «эвент»
не содержали и не меняются.
