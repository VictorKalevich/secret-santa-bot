# Research: 013 — «событие» вместо «эвент»

## R1. Правила замены

- **Decision**:
  1. Название стоит отдельно — в скобках или через запятую: слово убирается. «(эвент «X»)» → «(«X»)»,
     «…, эвент «X».» → «…, «X».»
  2. Название зависит от предлога или слово — подлежащее/дополнение: «событие» в нужной форме.
     Падежи: эвент → событие, эвента → события, эвенту → событию, эвентом → событием, эвенте → событии; эвенты →
     события, эвентов → событий, эвентам → событиям, эвентами → событиями, эвентах → событиях.
  3. Род — средний: «новый/этот/первый/завершённый эвент» → «новое/это/первое/завершённое событие»; «Эвент не
     найден/завершён/удалён» → «Событие не найдено/завершено/удалено»; «который» → «которое», «он» → «оно».
  4. Подписи из FR-1305 — в форме, выбранной владельцем проекта (часто без слова: «Завершить», «Параметры»,
     «Полный сброс»).
  5. Уведомление о вступлении — «присоединяется к событию «X»» (форма без рода, как раньше).
- **Rationale**: название события — пользовательский текст в кавычках, он не склоняется; без слова «событие» после
  предлогов получилось бы «к «Новый год 2026»». Слово в скобках и после запятой ничего не определяет — его можно убрать.
- **Alternatives**: убрать слово везде (ломает падежи — отклонено владельцем); перестроить сообщения «название
  отдельно» (больше правок без пользы — отклонено владельцем).

## R2. Автотест терминологии

- **Decision**: `tests/wording.test.mjs` (в `npm test`) читает `src/*.js` и `src/app.html`, убирает комментарии
  (`// …` до конца строки вне строк, `/* … */`, `<!-- … -->`) и ищет `/[Ээ]вент/` — любое совпадение с номером строки —
  ошибка. Второй тест: в `src/app.html` нет кнопок, текст которых начинается с «＋» или «+ ».
- **Rationale**: SC-001 проверяется автоматически; новый текст со словом «эвент» не пройдёт `npm test`.
- **Alternatives**: проверять только сообщения в e2e — не покрывает редкие ветки (ошибки, cron).

## R3. Что не меняется

- **Decision**: имена в коде, полях API (`event`), базе (`events`), `callback_data`, ссылках; комментарии в коде;
  спецификации `specs/001`–`012`, Конституция, витрина дизайн-системы; ранее записанные строки журнала и очереди.
  CLAUDE.md — внутренний термин «эвент» остаётся, добавляется правило «в текстах для людей — «событие»».
- **Rationale**: FR-1307 (поведение не меняется), исторические документы не переписываются.
