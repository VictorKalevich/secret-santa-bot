# Quickstart: проверка 013

## Автотесты

```powershell
npm test            # в т.ч. tests/wording.test.mjs: ни одного «эвент» в строках src/, кнопки без «＋»
npm run test:e2e    # сквозной сценарий с новыми текстами, поведение то же
npm run screenshots # test-results/: 00-home, 13-new-event, 06-info, 07-admin-after-draw, 12-danger-zone
```

## Вручную (после `npm run deploy`)

1. Главный экран: «Мои события», кнопка «🎄 Создать» → диалог «Новое событие».
2. Новый участник вступает по ссылке → организатору: «👋 Имя присоединяется к событию «X»».
3. Жеребьёвка → участникам: «Жеребьёвка в событии «X» проведена!».
4. Подопечный пишет Санте → «💬 Тебе пишет твой подопечный («X»):».
5. Панель: «Параметры», «Завершить через 3 дня после вручения», «🏁 Завершить», опасная зона — «Полный сброс»,
   «Удалить событие»; «Новая семья», «Добавить исключение» — без плюсов.
6. «Инфо» → «Как это работает» — «события», «Событие сохранится в истории».
