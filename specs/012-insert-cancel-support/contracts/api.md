# Contract: 012 — изменения API, бота и уведомлений

Все запросы мини-приложения — `POST /api/<действие>` с заголовком `x-init-data`; ответ `{ ok: true, … }` или
`{ ok: false, error }`. Поле `event` — id эвента.

## Изменённые действия

### `admin.insert` `{ event, id }`
- Только владелец: иначе **403** «Вписывать в жеребьёвку после неё может только владелец бота.» Проверка «вписать
  себя» снята (владелец может себя).
- Выбор Санты — по группам (research R1); нет подходящих — 400 «Не получается вписать участника, не нарушив правила:
  подарки уже готовы у всех, кому мог бы смениться подопечный, или мешают исключения. Можно отменить жеребьёвку в
  опасной зоне и провести заново.»; гонка — 400 «Пары изменились одновременно с этим действием — попробуй ещё раз.»

### `admin.participate` `{ event, on }`
- После жеребьёвки: 400 «После жеребьёвки так нельзя. Попроси владельца бота вписать тебя.»

### `admin.state` `{ event }` — добавлено
```json
"support": {
  "threads": [{ "id": 1, "user_id": 5, "name": "Маша", "status": "open", "assignee": 0, "assignee_name": "",
                "created_at": 0, "closed_at": 0, "last_at": 0, "unread": 0, "readable": true }],
  "admins": [{ "id": 7, "name": "Олег" }]
}
```
Открытые — сверху, затем до 20 последних закрытых. `readable` — ничьё, своё или владелец. `unread` — для
ответственного и для ничьих открытых (кроме своего) — непрочитанные сообщения участника. `admins` — кому можно передать.

### `event.get` `{ event }` — добавлено
- Участнику: `support: { available, open, assignee_name, unread }` — `available` = есть админы, кроме него.
- Админу: `support_admin: { waiting, unread }` — ничьи открытые (не свои) и непрочитанные во взятых им.

### `me` — `events[].unread`
- Добавляется: участнику — непрочитанные ответы организаторов; админу — `waiting + unread` (как в `event.get`).

## Новые действия участника (нужно участие в эвенте)

### `support.get` `{ event }`
```json
{ "ok": true, "available": true, "writable": true,
  "threads": [{ "id": 1, "status": "open", "assignee_name": "Олег", "created_at": 0, "closed_at": 0,
                "messages": [{ "id": 3, "mine": false, "author": "Олег", "text": "…", "created_at": 0 }] }] }
```
До 10 последних обращений, старые сначала. Помечает ответы организаторов прочитанными.

Ответ помечает прочитанными сообщения другой стороны в этом обращении (как в переписке Сант): `support.send` —
ответы организаторов, `admin.support.send` — сообщения участника.

### `support.send` `{ event, text }` → `{ ok, thread, message }`
- Пустой — «Пустое сообщение.»; > 4000 — «Слишком длинно: N символов, максимум 4000 (лимит сообщения Telegram).»;
  писать некому — «Сейчас некому написать: в боте нет других организаторов.»; эвент завершён больше 7 дней назад —
  «Эвент завершён больше недели назад: обращения только для чтения.»

### `support.close` `{ event }` → `{ ok }`
- Нет открытого — «Открытого обращения нет.»

## Новые действия админа (`admin.*`, владелец ⊇ админ)

| Действие | Тело | Отказы |
|---|---|---|
| `admin.support.get` | `{ event, thread }` → `{ thread: {…, writable, closed_by_name}, messages: [{ id, mine, from_admin, author, text, created_at }], admins: [{ id, name }] }` | не найдено/другой эвент — 404 «Обращение не найдено.»; чужое — 403 «Обращение ведёт Имя — переписку видят он(а) и владелец.» |
| `admin.support.take` | `{ event, thread }` | своё как автора — «Своё обращение взять нельзя.»; взято — «Обращение уже взял(а) Имя.»; закрыто — «Обращение уже закрыто.» |
| `admin.support.send` | `{ event, thread, text }` → `{ message }` | ничьё — берётся этим ответом; чужое — «Обращение ведёт Имя.»; закрыто; длина; срок |
| `admin.support.pass` | `{ event, thread, to }` | не ответственный и не владелец — 403 «Передать обращение может тот, кто его ведёт, или владелец.»; `to` не админ или автор — «Передать можно другому администратору.»; закрыто |
| `admin.support.close` | `{ event, thread }` | не ответственный и не владелец — 403 «Закрыть обращение может тот, кто его ведёт, или владелец.»; закрыто |
| `admin.draw.cancel.force` | `{ event, confirm: "ОТМЕНА" }` → `{ count }` | не владелец — 403 «Принудительно отменить жеребьёвку может только владелец бота.»; без слова — 400 «Для отмены введи слово ОТМЕНА.»; нет жеребьёвки — «Жеребьёвка не проведена.»; раскрыта — «Тайна уже раскрыта — отменить жеребьёвку нельзя.»; гонка — «Пары изменились одновременно с этим действием — попробуй ещё раз.» |

Завершённый эвент: `admin.support.*` разрешены (чтение — всегда, изменения — пока `chatWritable`).

## Бот

| callback_data | Кто | Действие |
|---|---|---|
| `sup:take:<id>` | админ | взять обращение; ответ на нажатие — «🙋 Обращение твоё» / причина отказа |
| `sup:a:<id>` | админ | режим ответа `sup_a:<id>:<мс>` (ничьё — возьмётся ответом) |
| `sup:u:<эвент>` | участник | режим ответа `sup_u:<эвент>:<мс>` |

Режим ответа живёт час, сбрасывается любой командой и `/cancel`. Ответ админа в закрытое — «❌ Обращение уже закрыто —
сообщение не отправлено.»; в переданное — «❌ Обращение ведёт Имя — сообщение не отправлено.»

Ссылки «💬 Открыть»: участнику — `/app?event=<id>&support=my`, админу — `/app?event=<id>&support=<обращение>`.
