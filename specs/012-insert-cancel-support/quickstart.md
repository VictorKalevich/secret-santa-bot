# Quickstart: проверка 012

```powershell
npm test             # юнит: группы вписывания; правила дизайн-системы (ds-chat__note)
npm run test:e2e     # блок «012» + обновлённые 009/010
npm run screenshots  # test-results/: «Инфо» с «Нужна помощь?», переписка обращения, «Обращения» в панели
```

Локально (`npm run dev`, миграции `npx wrangler d1 migrations apply DB --local`):

1. **Вписывание** (US1): эвент, 4 участника, жеребьёвка; двое открывают «Подопечного», один отмечает «Подарок готов».
   Новичок вступает (регистрацию открыть), владелец → «Вписать в жеребьёвку» → подопечный сменился у того, кто не
   открывал. Админ кнопки не видит — подсказка «Вписать может владелец бота».
2. **Все подарки готовы**: у всех «Подарок готов» → вписать → общий отказ, пары те же.
3. **Принудительная отмена** (US2): владелец → «Опасная зона» → «↩️ Отменить жеребьёвку» → «ОТМЕНА» → пар и переписки
   нет, письма на месте, регистрация открыта, уведомления пришли, в журнале «Жеребьёвка отменена владельцем».
4. **Обращение** (US3): участник → «Инфо» → «💬 Написать организатору» → админы получают «🆘 … Взять»; первый «Взять» —
   его, второй — «уже взял(а)»; переписка через «↩️ Ответить» в чате бота и в приложении; «Передать» другому админу;
   «✅ Вопрос решён»; новое сообщение — новое обращение. Третий админ в списке видит «ведёт Имя», но не текст.

Проверить на iPhone (Telegram iOS): шторка переписки обращения, поле ответа и кнопки, точка на вкладках «Инфо»/«Админ».
