# Quickstart: проверка 049

Контракт — [contracts/swap-marks.md](contracts/swap-marks.md).

## Автоматически

```powershell
npm test             # swap: сообщения только открывшим (и в момент записи), метка и тексты по склейке; atomic
npm run screenshots  # checkSwap: метки при открытии и после обмена; снимок test-results/48-swap-sheet.png
npm run test:e2e     # перед слиянием
```

## Вручную (iPhone, Telegram)

1. Событие после жеребьёвки; участник А открыл вкладку «Подопечный», участник Б — нет.
2. Владелец: «Управление» → «Управление жеребьёвкой» → «🔀 Открыть управление жеребьёвкой».
3. Ожидается: под именем Б — «👀 не открыл подопечного» (как в «Участниках»), у А — нет.
4. Поменять подопечных у А и Б (без нарушений): в окне подтверждения — «Тем, кто уже открыл подопечного, бот напишет…».
5. После «Подопечные поменялись»: метка у обоих; в Telegram сообщение «новый подопечный» пришло только А, Б — ничего.
