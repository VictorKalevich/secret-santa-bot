# План 047. Имя из Telegram при регистрации

**Ветка** `047-telegram-name-signup` · **Спецификация** [spec.md](spec.md)

## Технический контекст

JavaScript ES2022, Cloudflare Worker + D1, Telegram Bot API (webhook). Меняется чат с ботом (`src/bot.js`), одна функция
в `src/membership.js` и одна подсказка мини-приложения (`src/app/08-start.html`). Схема, API мини-приложения, журнал не
меняются; `data-model.md` и `contracts/` не нужны — описание бота живёт в `docs/api.md` (с 022).

## Как сейчас

`/start inv_<код>` новому человеку: `pending = name:<событие>:<код>` (без одобрения — сразу строка `members`), ответ —
«Как тебя зовут? …». Ссылка владельца — `pending = name`, тот же вопрос. Любой текст при `pending = name…` — `onName`:
`updateUser` (имя, `registered = 1`), перечитать пользователя, затем либо «присоединяется» админам (уже участник), либо
`joinByInvite`. Нажатия кнопок человеку без имени — `NOT_REGISTERED`. Запись имени не атомарна: два одновременных имени
(или, после 047, нажатие и имя) разослали бы «присоединяется» дважды.

## Решения

1. **Предложение имени** — `telegramName(from)` (`bot.js`, чистая): `oneLine(first_name + ' ' + last_name)`, если
   подходит под правило имени, иначе `oneLine(first_name)`, иначе `''`. Правило имени одно для ввода и предложения —
   `nameOk` (1–40 символов, не с «/»; прежнее условие `onName`).
2. **Просьба имени** — `c.askName(intro, joining)` в объекте чата: с именем — текст `NAME_OFFER(name)` и две строки
   кнопок `✅ Участвовать как <имя>` / `✅ Продолжить как <имя>` (`callback_data: reg:ok`) и `✏️ Изменить имя`
   (`reg:edit`); без имени — прежний `NAME_PROMPT`. Вызывают: `onInvite` (`joining = true`), `onOwnerLink` (`false`) и
   напоминания (`/start` без ссылки, `/cancel`, незарегистрированный без ожидания имени) — `joining` по `pending`
   (`name:` — после приглашения).
3. **Кнопки регистрации** — до проверки «зарегистрирован» в `handleCallback`: `onSignupButton(cq, env)` открывает тот же
   объект чата, что сообщение (`openChat(env, { from: cq.from })`). Нет пользователя — `NOT_REGISTERED`; имя уже
   сохранено — `NAME_SAVED` всплывающим ответом; `reg:edit` — сообщение `NAME_ASK`, ожидание не меняется; `reg:ok` — имя
   из `cq.from` в момент нажатия (не подходит — `NAME_PROMPT` сообщением). Ответ на нажатие — ровно один.
4. **Одна регистрация** — общий путь `signUp(c, name, saved)` для текста и кнопки: прочитать событие и участие по
   `pending`, затем `register(ctx, name, username, ev)` (`membership.js`) — пакет `atomic` «по прежнему состоянию»
   (020): условие «пользователь ещё не зарегистрирован», «присоединяется» админам (только если человек уже участник `ev`,
   с добавочным условием участия) — перед захватом, захват — `UPDATE users SET name, username, registered = 1,
   pending = ''`. Проигравший ничего не рассылает: кнопке — `NAME_SAVED` всплывающим ответом, тексту — сообщением.
   После победы — `saved()` (у кнопки — ответ на нажатие и снятие клавиатуры `editMessageReplyMarkup`, если у нажатия
   есть `message`), затем прежние сообщения (`hello`, письмо, «устарела», `joinByInvite`, меню). Пользователь после
   записи не перечитывается: в `c.user` подставляются записанные поля (на запрос меньше).
5. **Текст «присоединяется»** — одна функция `joinedNotice(user, ev)` (`membership.js`) для `joinedNoticeStmts`
   (вступление по ссылке) и `register`; `joinedNoticeStmts` больше не экспортируется.
6. **Сброс отметки блокировки** (`blocked_at`) переезжает в `openChat` — им же пользуются кнопки регистрации.
7. **Мини-приложение до регистрации** — «Перейди по пригласительной ссылке события и подтверди в чате с ботом своё
   имя. …» (`08-start.html`); отпечаток CSP сервер считает сам.

Отклонено: запоминать предложенное имя в `pending` или `users.name` до нажатия (меняет смысл незарегистрированной
записи — панель показала бы имя до согласия); имя в `callback_data` (≤ 64 байт — кириллица не помещается); две кнопки в
одной строке (длинное имя обрезается на iPhone).

## Тексты

- `NAME_OFFER(name)`: «Имя в игре — **<имя>**, как в Telegram. Его увидят твой Санта, владелец и администраторы. Хочешь
  другое — нажми «✏️ Изменить имя» или просто напиши его.»
- `NAME_ASK`: «✏️ Напиши имя (и, если нужно, фамилию) одним сообщением — до 40 символов. Так тебя увидят твой Санта,
  владелец и администраторы.»
- `NAME_SAVED`: «Имя уже сохранено. Сменить его можно в приложении: «Профиль» → «✏️ Изменить имя».»
- `NAME_PROMPT` (нет подходящего имени в Telegram) и остальные ответы — прежние.

## Проверка Конституции

- **I. Тайна** — пар и писем не касается; в сообщениях — только имя самого человека, экранированное.
- **II. Проще некуда** — регистрация одним нажатием вместо набора текста; набор текста остаётся.
- **III. Спецификация до кода** — spec/plan/tasks в этой ветке; `docs/api.md` и README — там же.
- **IV. Дизайн-система** — в приложении меняется только текст подсказки (тест `design-system`, `wording`).
- **V. Бесплатный тариф** — нажатие: чтения (пользователь и настройки, событие, участие, пользователи), один пакет записи,
  сообщения как у ввода имени, плюс ответ на нажатие и снятие клавиатуры — далеко до 50; ввод имени текстом — на запрос
  меньше прежнего (нет перечитывания). Сообщения админам — через `outbox` в пакете захвата. Строка нажатия — в
  `tests/queries.test.mjs`.
- **VI. Проверено до выката** — быстрые тесты (новый `signup`, `atomic` +3), e2e с нажатием, `npm run test:all`.
- **VII. Владелец** — ссылка владельца работает так же («Продолжить как …»); права не меняются.

Нарушений нет.
