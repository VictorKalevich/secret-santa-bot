# Quickstart: проверка драгера у шторок (033)

## Локально

```powershell
npm test               # design-system (правило 033), app-tweaks (правило 7), app-ui
npm run screenshots    # ✔ драгер у шторок (033), ✔ правки 027–028; снимки шторок — с полоской сверху
npm run test:e2e       # без изменений поведения сервера
```

Ожидается: все тесты зелёные; в `test-results/` у каждой шторки (письмо, журнал, переписка, обращение, служебный
просмотр, календарь) сверху полоска, заголовок сразу под ней.

## На iPhone (Telegram для iOS) после выката

1. Панель события → «Журнал действий»: сверху полоска. Прокрутить журнал вниз — полоска на месте. Потянуть за неё вниз
   на треть экрана — журнал уехал и закрылся; потянуть немного — вернулся.
2. «Подопечный» → «Написать подопечному»: полоска у верхнего края. Набрать текст, потянуть полоску вниз — вопрос
   «Сообщение не отправлено…»: «Отмена» — переписка на месте, текст в поле; ещё раз и «ОК» — закрыта.
3. Любая другая шторка (меню участника, «Имя участника», «Новое событие») — та же полоска и тот же свайп.
4. Пока открыта шторка, свайп вниз по полоске не сворачивает всё приложение; после закрытия свайп вниз по экрану снова
   сворачивает приложение, как раньше.
5. Календарь автожеребьёвки — как в 028.

Если что-то не так — откат к предыдущей версии: `npx wrangler deployments list`, затем
`npx wrangler rollback <прежний Version ID> -m "откат 033"` (сервер и база не менялись — откат безопасен).
