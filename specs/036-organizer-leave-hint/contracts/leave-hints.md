# Contract: раздел «Выход из события» на «Инфо» (035 + 036)

Раздел — последний на вкладке «Инфо» (`leaveSection`, `src/app/04-event.js.txt`), заголовок «Выход из события».

## Когда раздела нет

- Смотрящий не участник события (`state.member` пусто), или событие завершено (`status = 'finished'`).

## До жеребьёвки (035, без изменений)

Подсказка «Не получается участвовать? Выйти можно, пока не проведена жеребьёвка.» и кнопка «🚪 Выйти из события» (шторка
со словом `ВЫЙТИ`, `typedSheet`) — у всех участников, в том числе у организаторов.

## После жеребьёвки (036)

| Кто (`state.me`) | Санты раскрыты (`state.ev.revealed`) | Подсказка | Кнопка |
|---|---|---|---|
| владелец (`is_owner`) | нет | «Ты владелец бота — удалить тебя из события некому. Выйти можно, только отменив жеребьёвку: «Админ» → «Опасная зона» → «↩️ Отменить жеребьёвку» (пары удалятся у всех, участники получат уведомление). Потом выключи «Я участвую» и проведи жеребьёвку заново.» | нет |
| владелец | да | «Тайна уже раскрыта — жеребьёвку не отменить, поэтому выйти из события нельзя: удалить владельца бота некому.» | нет |
| админ (`is_admin`, не владелец) | любое | «Жеребьёвка уже прошла — удалить из события администратора может только владелец бота. Напиши организатору: обращение увидит и владелец.» | «💬 Написать организатору» |
| участник | любое | «Жеребьёвка уже прошла — выйти можно только через организатора: напиши ему, он уберёт тебя из события.» (035) | «💬 Написать организатору» |

Кнопка «💬 Написать организатору» — только если есть кому написать или обращение уже открыто
(`state.support.available || state.support.open`); открывает обращение участника (`openSupport()`), как в 035.

## Сервер

Не меняется: `event.leave` после жеребьёвки — прежний отказ 400 «Жеребьёвка уже прошла — выйти можно только через
организатора: напиши ему.» (`docs/api.md`).
