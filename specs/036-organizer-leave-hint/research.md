# Research: Подсказка о выходе для организаторов-участников (036)

## R1. Откуда приложение знает роль

- **Decision**: `state.me.is_owner` и `state.me.is_admin` — их уже отдаёт сервер в ответе «мои события»
  (`src/participant.js`, `me: { …, is_admin, is_owner }`); состояние события — `state.ev.draw_done`, `state.ev.revealed`
  (`publicEvent`, `src/status.js`).
- **Rationale**: ни одного нового запроса и поля; те же признаки уже используют главный экран и панель.
- **Alternatives considered**: спрашивать сервер «могу ли выйти» — лишнее действие API ради текста подсказки.

## R2. Что может организатор-участник после жеребьёвки (по коду)

- `event.leave` после жеребьёвки — отказ (035). `admin.participate` с `on: false` после жеребьёвки — отказ «После
  жеребьёвки так нельзя…» (`participate`, `src/membership.js`).
- `admin.remove`: себя — «Нельзя удалить самого себя…»; владельца — «Владельца нельзя удалить из события…»; админа — только
  владелец («Удалить администратора может только владелец бота.»). После раскрытия удаление разрешено, пока событие идёт.
- Отмена жеребьёвки: обычная — пока никто не открыл подопечного (любой организатор); принудительная — только владелец, в
  «Опасной зоне», пока Санты не раскрыты (`forceCancelDraw`, 012). После раскрытия — «Тайна уже раскрыта — отменить
  жеребьёвку нельзя.»
- **Decision**: владельцу — путь «Опасная зона» → «↩️ Отменить жеребьёвку» → «Я участвую» выключить → жеребьёвка заново;
  после раскрытия — «выйти нельзя». Админу — «удалить может только владелец», кнопка обращения (обращение ничьё — его видят
  все организаторы, владелец тоже: `adminRecipients` берёт всех `is_admin`, владелец — тоже админ).
- **Alternatives considered**: подсказать админу обычную отмену жеребьёвки (когда никто не открыл подопечного) — в просьбе
  владельца не было, и админ не знает заранее, доступна ли она; передать владение или перенести участие ради выхода —
  меняет роли, сложно.

## R3. Сервер

- **Decision**: не меняется. Отказ `event.leave` после жеребьёвки остаётся общим («…через организатора: напиши ему.») —
  его видно только в гонке (жеребьёвка прошла, пока открыта шторка выхода), после неё экран показывает подсказку по роли.
- **Rationale**: владелец просил подсказку в приложении; эталон отказов и тесты сервера — без правок.

## R4. Проверка

- **Decision**: поведение — в Chrome (`checkSelfService`, `tests/screenshots.mjs`): владелец-участник, админ-участник и
  участник в одном событии с жеребьёвкой, затем то же после раскрытия; плюс снимок раздела у владельца. В `npm test` —
  прежние проверки склейки (дизайн-система, слова).
- **Rationale**: подсказка — разметка в браузере; правила по тексту склейки здесь ничего не добавили бы к проверке в Chrome.
