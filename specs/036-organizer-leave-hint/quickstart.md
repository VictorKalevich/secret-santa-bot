# Quickstart: 036 — проверка и выкат

## Локально

```powershell
npm test               # склейка: дизайн-система, слова, app-* — без новых нарушений
npm run screenshots    # checkSelfService: строка «✔ имя и выход (035–036): …», снимок 33-leave-owner.png
npm run test:e2e       # сервер прежний — без изменений
```

Ожидается: всё зелёное. Тексты подсказок — `contracts/leave-hints.md`.

## Выкат (владелец)

Только код приложения, миграций нет:

```powershell
git checkout main
git pull
npx wrangler deployments list   # запишите Version ID текущей версии — к ней откат
npm run deploy
```

## Проверка на iPhone

1. Событие, где вы участник и жеребьёвка проведена → «Инфо» → внизу «Выход из события»: подсказка про отмену жеребьёвки
   в «Опасной зоне», кнопок в разделе нет.
2. Событие до жеребьёвки → «Инфо»: кнопка «🚪 Выйти из события», как раньше (выходить не нужно — закройте шторку ✕).

Что-то не так — откат: `npx wrangler rollback <Version ID> -m "откат 036"` (база не менялась).
