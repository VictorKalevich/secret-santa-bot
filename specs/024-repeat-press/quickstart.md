# Quickstart: проверка фичи 024

## 1. До правки кода — новые проверки падают

```powershell
node --test tests/atomic.test.mjs tests/app-buttons.test.mjs
```

Ожидается: блок «повторные нажатия (024)» падает — по два сообщения людям, по две записи журнала, у семьи — 500;
тест кнопок находит 6 вызовов `busy(null`.

## 2. После правки

```powershell
npm test
```

Ожидается: все тесты зелёные; `queries` — числа запросов прежние; эталон отказов, тайна, права, дизайн-система и слова —
без правок ожиданий.

## 3. Сквозной сценарий и вид

```powershell
npm run test:e2e
npm run screenshots
```

Ожидается: e2e — 8 сценариев, все подтесты, нет `budget exceeded`; скриншоты (`test-results/`) — вид экранов прежний.

## 4. На телефоне (владелец)

В приложении на iPhone: нажать «🔕 Тихо» в «Уведомлениях» — кнопки на мгновение приглушаются, режим сохраняется;
удалить исключение «✕» — кнопка приглушается до ответа.
