```powershell

npm run screenshots  # Chrome: checkCompanies
```

## Вручную (локально, `npm run dev` + бот, три аккаунта: владелец бота В, Петя, Аня)

1. В: главный экран прежний, внизу раздел «Компании» → «Создать компанию» → «Офис Пети». Корневой экран — «Компании»,
   две строки.
2. В: «⚙️» у «Офиса Пети» → «Создать ссылку» → отправить Пете.
3. Петя (боту не знаком): переходит по ссылке, «Продолжить как Петя» → бот: «Ты — владелец своей компании…». В получает
   сообщение «Петя — теперь владелец компании «Офис Пети»».
4. Петя: приложение открывается сразу на главном экране (компания одна): создаёт событие, копирует приглашение,
   назначает администратора, после жеребьёвки открывает служебный просмотр. Слова «компания» на его экранах нет; в
   отказах — «владелец», не «владелец бота».
5. Аня (из «Основной») вступает в событие Пети по приглашению → в приложении экран «Компании»: «Компания 1», «Компания 2»
   → «✏️» → «Семья», «Работа». В меню бота у событий — «(Семья)», «(Работа)».
6. В: открывает «Офис Пети» → плашка гостя; видит событие и панель; в журнале компании его действия подписаны его
   именем; сообщений организаторам этой компании он не получает.
7. В: «Вести самому» → Петя получает сообщение, остаётся администратором.
8. В: создаёт пустую компанию и удаляет её словом «УДАЛИТЬ»; компанию с событием удалить нельзя.
9. Человек из «Основной» без второй компании: экраны, тексты и сообщения — как до шага.

## iPhone (Telegram iOS)

Владелец проверяет: экран «Компании» (строки нажимаются целиком, «✏️» и «⚙️» не открывают компанию), шторки с полем
названия (клавиатура прячется тапом мимо поля), «Отправить в чат» со ссылкой владельца, «‹» и системная «Назад» из
события → компания → «Компании».

## Выкат

Миграций нет: `npm run deploy`. Перед выкатом — копия базы (после появления второй компании откат кода на версию до 050
возможен только с восстановлением базы; откат на версию 050 безопасен: она понимает несколько компаний, но не умеет ими
управлять — назначенные владельцы компаний сохраняют права).
