# Quickstart: приёмка фичи 022

Все команды — из корня проекта (PowerShell или Git Bash).

## 1. Тест документа и весь `npm test`

```powershell
node --test tests/api-doc.test.mjs   # документ ↔ ACTIONS и коды журнала, проверки «от противного»
npm test                             # 170 прежних тестов + тест документа — все зелёные
```

Ожидаемо: 0 упавших; в выводе — проверки «от противного» (нет раздела, лишний раздел, неверная роль, неверное «в
завершённом», убран текст отказа не владельцу, лишний код журнала) — каждая находит своё расхождение.

## 2. «От противного» на настоящем документе (вручную, без коммита)

1. Удалить из `docs/api.md` раздел `### \`admin.ring\`` → `node --test tests/api-doc.test.mjs` падает и называет
   `admin.ring`. Вернуть (`git checkout docs/api.md`).
2. В сводной таблице у `admin.insert` написать `админ` вместо `владелец` → тест падает. Вернуть.
3. Дописать в таблицу журнала строку `| \`draw.fake\` | … |` → тест падает. Вернуть.


о синхронизации.

## 5. Выборочная сверка описаний с кодом

Для 6 действий — участника (`ward.get`), с проверкой внутри (`delivery.save`), админа без события (`admin.rename`),
действия события (`admin.state`), владельца со словом (`admin.event.delete`), обращения (`admin.support.get`) — сравнить
раздел документа с обработчиком в `src/api.js` и функцией модуля: поля запроса, поля ответа (ключи объекта ответа),
каждый текст отказа (поиск по тексту в `src/`).
