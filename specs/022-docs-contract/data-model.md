# Data Model: Сводный контракт API и правки документов

Схема базы не меняется. «Данные» фичи — документ `docs/api.md` и то, с чем его сверяет тест.

## Сводный документ (`docs/api.md`)

| Часть | Что в ней | Сверяет тест |
|---|---|---|
| Запрос и ответ | маршрут, заголовок подписи, тело, вид ответа | нет |
| Порядок проверок и общие отказы | шаги конвейера `handleApi`, таблица «код — текст — когда» | нет (тексты сверяет эталон отказов `tests/fixtures/api-refusals.json`) |
| Сводная таблица | строка на действие: имя, кто, событие, в завершённом, условия | да: имена, кто, событие, в завершённом |
| Разделы действий | `### \`имя\``; кто, событие, в завершённом; запрос; ответ; отказы; журнал | да: имена; тексты отказов конвейера из `ACTIONS` |
| Коды журнала | строка на код: код, событие или общий, кто пишет, подробности | да: множество кодов |
| Бот, `pending`, `callback_data`, ссылка `/app`, маршруты | описание | нет |

## Строка сводной таблицы

`| \`имя\` | кто | событие | в завершённом | условия |`

- **имя** — ключ `ACTIONS`, в обратных кавычках; встречается в таблице один раз.
- **кто** — `любой`, `зарегистрированный`, `участник или админ`, `участник`, `админ`, `владелец` ↔ `role`.
- **событие** — `да`, `если передано`, `—` ↔ `event` (`true`, `'given'`, нет).
- **в завершённом** — `нет` ↔ `finished` строка; `да` / `7 суток` / `проверяет обработчик` ↔ `finished: true`;
  `—` ↔ нет `finished` (действие без события).
- **условия** — свободный текст, тест не читает.

## Раздел действия

Заголовок второго уровня вложенности `### \`имя\`` (имя — ключ `ACTIONS`, один раз в документе). Текст раздела — до
следующего заголовка `##` или `###`. Обязательные вхождения (проверяет тест):

- `finished` — строка → этот текст в разделе;
- `owner` есть → этот текст в разделе;
- `confirm` есть → слово (`confirm[0]`) и текст отказа (`confirm[1]`) в разделе.

## Код журнала

Строка таблицы раздела `## Коды журнала`: `| \`код\` | событие или общий | кто пишет | подробности |`. Множество кодов
таблицы = множество кодов, которые пишет `src/*.js` (research R3; на `main` — 42).

## Отношения

```text
ACTIONS (src/api.js) ──имена, role, event, finished, owner, confirm──▶ сводная таблица + разделы (docs/api.md)
src/*.js (вызовы журнала) ──коды──▶ таблица кодов журнала (docs/api.md)
CLAUDE.md, README ──указатель──▶ docs/api.md ◀──указатель── specs/001…014/*/contracts/*.md
```
