# Исследование 064: тексты и упрощение

## R1. Одна фича на весь список

**Decision**: все правки списка владельца 2026-11-25 — фича 064, коммиты по частям (сервер, приложение, словари, тесты,
документы).
**Rationale**: правки связаны (без отметок подарка теряют смысл значки, напоминания, строка прогресса; без кнопки
«Завершить» нужно автозавершение); по отдельности остались бы противоречивые промежуточные состояния.
**Alternatives**: две фичи «тексты» и «удаление функций» — отвергнуто: тексты подсказок о подарках и адресе меняются
вместе с удалением.

## R2. Автозавершение по дате — для всех

**Decision**: `dueAutoAction` (`src/cron.js`) возвращает `'finish'` для любого идущего события с датой D, когда
`addDays(D, 3) <= today`; колонка `finish_auto` не читается (→ `EVENT_RETIRED`). Порядок автодействий прежний
(жеребьёвка → раскрытие → завершение), одно тяжёлое действие за вызов.
**Rationale**: владелец приравнял правило к прежней галочке («это мы уже описали … для всех»); D+3 = «4-й день», считая
день вручения первым.
**Alternatives**: миграция `finish_auto = 1` и умолчание 1 — отвергнуто: колонка стала бы значимой, а галочки нет;
D+4 — отвергнуто (прежняя галочка — D+3).
**Следствие**: при первом ежедневном шаге после выката завершаются все идущие события с D+3 ≤ сегодня (по одному в
минуту) — `quickstart.md`, шаг «до выката».

## R3. «Брошенные» события — оба бота, только без даты

**Decision**: `staleReason`: событие с датой (любой) — `null`; без даты — Г (без жеребьёвки, `outsiders = 0`, 23 дня от
создания) → `'empty'`, иначе Б (`STALE.age = 53`) → `'age'`. `STALE.afterDate` и причина `'date'` убираются. `dailyStep`
вызывает `staleStep` в обоих ботах; `dailyEventsQuery` — без параметра открытого бота (`outsiders` считается только у
кандидатов Г, как раньше в открытом). Предупреждение — `warnStale` без изменений; тексты: `stale.why.age` — «больше семи
недель назад»; `stale.why.date`, `stale.keep.date` удаляются; `stale.logged.date` остаётся (подробности прежних записей
журнала `finish.warn` в `details_tx` — история; ключ входит в семейство `stale.logged.`).
**Rationale**: решение владельца «оба бота, 30 и 60 дней»; событие с датой завершится на D+3 раньше любого правила А
(D+7), поэтому А мёртв.
**Alternatives**: отметка «последнее действие» для настоящего «бездействия» — отвергнуто в обсуждении (новые записи на
каждое действие, решение владельца — от создания).
**Сброс отметки**: событие получило дату после предупреждения — `staleStep` даёт `clear` (как раньше при будущей дате).

## R4. Удаляемые действия и модули

**Decision**: из `ACTIONS` уходят `delivery.save`, `ward.gift`, `ward.received`, `ward.shipment`, `admin.remind.santas` —
вызов отвечает как неизвестное действие (как `mask.set` в 062). Удаляются `saveDelivery`, `setGiftReady`,
`setGiftReceived` (`src/participant.js`), `remindSantas` (`src/events.js`), `src/shipment.js` целиком и словарь области
`shipment` (11 языков, `AREAS`), константа `MARK_CLOSED` и текст `api.markClosed`, тексты `participant.noDelivery`,
`participant.deliveryClosed`, `participant.unmarkSentFirst`, `participant.noSanta` (если больше не используется),
`participant.giftReceived`, `events.remindSantas*`, `cron.wishlistOrDeliveryChanged`.
`admin.event.finish` и `admin.reset.full` остаются (просили убрать кнопки).
**Rationale**: функции убираются целиком; оставленное действие без интерфейса писало бы данные, которые никто не видит.
**Журнал**: `remind.santas` больше не пишется — в `docs/api.md` переходит в «Прежние коды»; подпись
`app.vault.audit.remind.santas` остаётся (история).

## R5. Поля ответов

**Decision**:
- `event.get`: `event` без `delivery_on`, `contacts_on` (`publicEvent`); `member` без `gift_received`, `delivery`,
  `shipment`; `roster.progress` — до жеребьёвки `{ letters, of }`, после — `null` (сумм по подаркам нет,
  `giftTotalsQuery` удаляется).
- `ward.get`: без `ward.delivery`, `gift_ready`, `shipment`, `timezone_offset_hours`.
- `admin.state`: `users[]` без `gift_ready`, `gift_sent`, `gift_received`, `has_delivery` (`panelMembersQuery` без
  `has_delivery`); `settings` без `finish_auto` (и без `delivery_on`, `contacts_on` — через `publicEvent`).
- `admin.vault.person`: без `gift_sent` и `delivery`.
**Rationale**: SC-003 — ни один ответ не содержит адреса, отметок, отправки.
**Вписывание (012)**: `insertRank` по-прежнему читает `gift_ready`/`gift_received` пары — прежние отметки в данных
остаются значимыми, новых не бывает; меняется только текст вопроса (`app.admin.members.insertConfirm`).
**Обмен (048)**: `applyPairsChange` по-прежнему обнуляет отметки новых пар — поведение прежнее.

## R6. Участники на «Инфо»

**Decision**: `rosterView` — `username` у каждого, у кого он есть (людей и организаторов); `contacts_on` не читается.
Приложение: `personRow` без нажатия и шеврона (`app.event.people.openChat` удаляется); `ROSTER_FOLD`, «Показать всех»,
`state.rosterOpen` удаляются; сводка — только `app.event.people.letters` до жеребьёвки (`app.event.people.gifts` удаляется).

## R7. Параметры события

**Decision**: `delivery_on`, `contacts_on`, `finish_auto` переходят из `EVENT_PARAMS` в `EVENT_RETIRED`: не создаются из
образца, не сохраняются `admin.game` (лишние поля тела игнорируются, как и раньше для неизвестных), не сбрасываются,
не отдаются. Новое событие и вступление больше не копируют адрес из прошлых событий (`createEvent`, `joinStmts` в
`src/db.js`). Колонки и данные остаются; удалить — пункт `docs/todo.md` вместе с прежними (062, 063).
**Rationale**: как `families_on` в 062 — откат на 063 безопасен без миграции.

## R8. Тексты: изменить и удалить

**Decision**: таблица `contracts/texts.md`. Изменённые ключи переводятся на 10 языков по глоссариям
`specs/061-i18n-languages/contracts/glossary/`; удалённые ключи убираются из всех 11 словарей (тест `i18n`: ключи
словаря используются). Ключ, текст которого перестал зависеть от подстановки (`app.event.card.button` без `{title}`,
`app.event.chat.wardHint` без `{santa}`, `app.admin.vault.hint` и `app.admin.swap.hint` без `{owner}`,
`app.admin.members.title` без `{n}`), меняется вместе с вызовом.
**Заголовок обращений**: без открытых — новый ключ `app.admin.support.title` «Обращения участников» (раньше —
`app.sheet.support.title` «Обращения», который остаётся у шторки); с открытыми — `app.admin.support.titleCount`
«Обращения участников · {n}».

## R10. Ссылка при закрытой регистрации

**Decision**: в `adminInvite` поле ссылки получает `disabled`, ряд кнопок — `hidden`, пока `s.registration_open` ложно;
синхронизация — `sync()` при построении и `p.watch('registration_open', sync)` (переключатель уже зовёт
`p.set('registration_open', on)`). Вид — новое состояние дизайн-системы `.ds-input:disabled { opacity:
var(--ds-opacity-disabled); }` (как у `.ds-btn:disabled`), витрина `preview.html`, строка README, версия 1.11.0.
`linkInput` без ссылки (`noLink`) — прежний.
**Alternatives**: класс `ds-input--off` — отвергнуто: `disabled` и так нужен (поле не выделяется и не копируется).
