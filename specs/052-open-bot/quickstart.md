# 052. Проверка и выкат

## Локально

```powershell
npm test               # быстрые: open-bot, atomic, api-refusals, api-table, api-doc, migrations, app-companies, queries…
npm run test:e2e       # сквозной сценарий (закрытый бот — без изменений)
npm run screenshots    # Chrome: checkCompanies (владелец бота с одной компанией — «‹»), checkOpenBot (второй мир с OPEN_BOT)
```

Ожидается: всё зелёное, в журнале нет `budget exceeded`, нарушений CSP — 0.

## Выкат (владелец; сначала второй бот)

Порядок — CLAUDE.md, «Боты: выкат, откат, копия, миграции». Миграция `0016` поднимает схему до 18 и нужна в обеих базах
до выката кода (прежний код с ней работает).

1. Точки отката: `npx wrangler deployments list --env second` и `npx wrangler deployments list` — запомнить Version ID.
2. Копии баз:
   - `npx wrangler d1 export secret-santa-db-2 --env second --remote --output "backup-secret-santa-db-2-<дата>.sql"`;
   - `npx wrangler d1 export secret-santa-db --remote --output "backup-secret-santa-db-<дата>.sql"`.
3. Миграции: `npx wrangler d1 migrations apply secret-santa-db-2 --env second --remote`, затем
   `npx wrangler d1 migrations apply secret-santa-db --remote`; в каждой базе
   `SELECT value FROM settings WHERE key = 'schema'` → `18`.
4. `npm run deploy:second`; `/app` по адресу из вывода отвечает 200.
5. Проверка второго бота на iPhone:
   - с аккаунта, которого бот не знает, написать боту без ссылки → просьба имени с «Продолжить как …»; после имени — меню с
     кнопкой приложения;
   - приложение открывается на «Компании» (пусто, «Создать компанию»); создать «Проба» → экран компании, «‹» к списку;
     создать событие → пригласительная ссылка;
   - создать вторую компанию → в списке две; третья — кнопка недоступна, под ней текст лимита;
   - ⚙️ у пустой компании → удаление словом `УДАЛИТЬ` → компании нет, можно создать снова;
   - с другого аккаунта войти по ссылке события → в шапке название «Проба», «‹» → «Компании» → «Создать компанию».
6. `npm run deploy`; проверка первого бота: человек без ссылки получает «закрытый бот»; у владельца бота с одной
   компанией — главный экран со «‹», внизу нет раздела «Компании»; у участника с одной компанией — всё как раньше.

## Откат

Код: `npx wrangler rollback <прежний Version ID> [--env second] -m "откат"` — база не меняется, прежний код колонку
`shared` не читает. Созданные людьми компании остаются: их владельцы сохраняют права, люди видят «Компания N» (правила
051), создавать компании люди не могут.
