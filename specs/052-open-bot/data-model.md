# 052. Модель данных

## Изменение схемы — миграция `0016_open_bot.sql` (схема 18)

```sql
ALTER TABLE companies ADD COLUMN shared INTEGER NOT NULL DEFAULT 0;
UPDATE settings SET value = '18' WHERE key = 'schema';
```

- `companies.shared` — 1: название компании общее (компанию создал человек в открытом боте, `company.create`); его видят
  люди компании и владелец бота. 0 — как в 051: название видит только владелец бота.
- Других таблиц и колонок нет. `REGISTRY` не меняется: `shared` — не колонка человека и не события.
- `REQUIRED_SCHEMA = 18`. Прежний код со схемой 18 работает (колонку не читает), поэтому порядок «миграция → код» и откат
  кода безопасны.

## Компания (дополнение к 051)

| Поле | Создал владелец бота (051) | Создал человек в открытом боте (052) |
|---|---|---|
| `owner_id` | 0 — ведёт владелец бота | создатель |
| `shared` | 0 | 1 |
| `name` | видит только владелец бота | видят люди компании и владелец бота |
| строка создателя в `company_members` | владелец бота, `is_admin = 1` (I2) | создатель, `is_admin = 1` (I3) |
| `users.is_admin` создателя | 1 (владелец бота) | 1 (`adminFlagStmt`, I4) |
| журнал бота | `company.create` «название» | то же |

Состояния компании человека: создана (владелец — создатель) → права можно передать (`admin.owner.transfer`) или вернуть
владельцу бота (`Вести самому`) — `shared` при этом не меняется, название остаётся общим → удаление (пока нет событий):
владелец компании в открытом боте или владелец бота.

## Владение и лимит

- **Владеет** — `companies.owner_id = человек`. Счёт — по строкам компаний (уже в пакете первого чтения `companiesQuery`).
- Лимит `OWN_MAX = 2` проверяет только создание человеком (условие вставки). Передача прав и ссылка владельца не
  ограничены. У владельца бота лимита нет (его компании — `owner_id = 0`, `createCompany`).

## Название компании для человека (`visibleCompanies`)

```
title = владелец бота ? name
      : своё название || (shared ? name : «Компания N»)
named = владелец бота || есть своё название
```

- `company.label.set` у владельца компании с `shared = 1` меняет `companies.name` (1–40, не пусто) и в том же пакете
  стирает его своё название; у остальных людей — только своё (до 40, пустое — сброс), как в 051.
- Общее название не попадает в ответы и сообщения людям вне компании (видимость — FR-5120 051).

## Человек без компании (открытый бот)

Запись `users` с `registered = 1` без строк `company_members` — допустимое состояние открытого бота (до создания своей
компании или вступления по ссылке). В закрытом боте его не возникает: без ссылки бот не регистрирует.

## Инварианты

I1–I8 (050, 051) не меняются; проверяются и для компаний людей (`tests/support/companies.mjs → invariants`).
