# Quickstart: проверка фичи 027

## Локально (до слияния)

```powershell
npm test                                  # всё, в т.ч. новый tests/app-tweaks.test.mjs
node --test tests/app-tweaks.test.mjs     # правила календаря, подсказки и отступа по склейке и «от противного»
npm run test:e2e                          # сквозной сценарий (сервер не менялся — всё как раньше)
npm run screenshots                       # снимки в test-results/ и проверки в Chrome, в т.ч. checkTweaks
```

Ожидается: всё зелёное; в выводе `screenshots` — строки `✔ поля даты: …` и `✔ правки 027: …`, код выхода 0. Новые
снимки — `29-auto-draw-calendar.png` и `29-auto-draw-calendar-dark.png`; `25-support-chat.png` — отступ над «Вопрос
решён»; `13-new-event.png` — подсказка «Новый год 2027 — семья» (в 2026 году).

## Выкат

Миграций у фичи нет, база не меняется.

```powershell
git checkout main
git pull
npm install
npx wrangler d1 migrations list secret-santa-db --remote   # ожидается «No migrations to apply»
npx wrangler deployments list                               # запишите Version ID текущей версии — к ней откат
npm run deploy
```

## Проверка на iPhone (Telegram для iOS)

Страница приложения не кэшируется — новая версия открывается сразу; если нет — закройте мини-приложение (✕ вверху) и
откройте снова.

1. **Подсказка названия.** Бот → «🎁 Санта» → «🎄 Создать». В поле названия серым — «Например: Новый год 2027 —
   семья» (в 2026 году). Введите «Проверка 027» → «Создать».
2. **Календарь без выбора.** В панели «Проверка 027» прокрутите до «Параметры». Поле «Автожеребьёвка» — «Не выбрана».
   Нажмите на него: снизу шторка «Автожеребьёвка», текущий месяц, **ни один день не выделен**, дни до сегодняшнего
   бледные, «Готово» бледная и не нажимается, кнопки «Сбросить» нет. «‹» — бледная (раньше текущего месяца нельзя),
   «›» листает вперёд (через декабрь → январь следующего года), «‹» — обратно.
3. **Закрытие без выбора.** Нажмите любой будущий день — он выделен, «Готово» стала яркой. Закройте ✕ (или кнопкой
   «Назад» Telegram). Поле по-прежнему «Не выбрана».
4. **Выбор.** Откройте снова — снова ничего не выделено. Выберите день → «Готово». Шторка закрылась, в поле — дата
   («20 декабря 2026»). «Сохранить» → «Сохранено». Закройте приложение и откройте панель снова — дата на месте.
5. **Сброс.** Нажмите на поле: календарь на месяце даты, день выделен, «Готово» яркая, есть «Сбросить». «Сбросить» —
   поле «Не выбрана» → «Сохранить» → «Сохранено».
6. **Остальные даты.** «Дата вручения» и «Написать письмо до» — как раньше, системный календарь iOS.
7. **Вопрос решён.** Другим аккаунтом (участник события) — «Инфо» → «💬 Написать организатору» → отправьте сообщение.
   Под полем ввода появилась «✅ Вопрос решён» — с отступом от поля, не вплотную. Нажмите её → OK — обращение закрыто.
8. **Уборка.** «Опасная зона» → «🗑 Удалить событие» → слово УДАЛИТЬ → «🗑 Удалить навсегда» → OK.

Что-то выглядит или работает иначе, чем раньше (кроме пунктов выше), — откат.

## Откат

База не менялась — откатывается только код Worker.

```powershell
npx wrangler rollback                     # к предыдущей версии; спросит подтверждение
# или к конкретной версии из `deployments list`:
npx wrangler rollback <Version ID> -m "откат 027"
```
