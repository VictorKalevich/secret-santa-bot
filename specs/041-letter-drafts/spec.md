# 041. Черновики писем Тайному Санте

Организатор включает «Черновики писем» в параметрах отдельного события. Исходное значение выключено, в том числе при создании по образцу и после полного сброса.

## Что видит участник

1. При выключенной настройке участник открывает привычную вкладку «Письмо». Кнопка «Сохранить» сразу обновляет письмо для Санты.
2. При включении существующее непустое письмо получает статус «Опубликовано». Пока письма нет, подсказка приглашает начать писать. При вводе статус сразу меняется на «Черновик» или «Черновик изменений». Во втором случае можно посмотреть текущую публикацию.
3. Строка состояния видна над текстом при открытии и закреплена при прокрутке редактора. Смысл передаётся словами. Автор видит сбой сохранения и может повторить попытку.
4. Автор продолжает сохранённый черновик при следующем открытии. Изменения становятся доступны Санте по кнопке «Опубликовать письмо» или «Опубликовать изменения». Опубликовать можно непустой текст до 4000 символов.
5. После выключения участник видит публикацию. После повторного включения появляется прежний черновик. Если за это время обычный редактор обновил письмо, открывается новая публикация с возможностью восстановить старый черновик для редактирования.
6. В завершённом событии автор может прочитать свои записи. Изменения и публикация закрыты.

## Критерии приёмки

- Черновик принадлежит автору в конкретном событии. Счётчик писем, напоминания, просмотр организатором, служебный просмотр, уведомления и подсветка изменений у Санты используют опубликованный текст.
- Сохранение черновика, открытие редактора и переключение режима сами по себе ничего не публикуют. Два открытых редактора не затирают более свежую запись. Запрос из старого режима или завершённой игры отклоняется.
- При закрытии сразу после набора локальная копия защищает ввод до ответа сервера, когда хранилище устройства доступно. После подтверждённого автосохранения текст доступен и с другого устройства.
- Удаление участия удаляет серверный черновик. Для новой записи участия старый локальный ввод не подставляется.
- Проверки охватывают оба режима, публикацию, восстановление, права, конфликт редакций и интерфейс при узком экране.
