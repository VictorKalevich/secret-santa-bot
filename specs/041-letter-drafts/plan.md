# План 041

Добавить миграцию D1 с параметром события и полями черновика в строке участия. Публикация остаётся в wishlist. Условная запись проверяет версию, режим и состояние события. Локальная страховочная копия хранится до подтверждения сервера.

Использовать существующие параметры организатора, права участника, дизайн-систему, обработку событий и подсчёт опубликованных писем. При выключенном режиме исполнять прежнюю ветку интерфейса. Проверить изоляцию текста через API и работу редактора в браузере.
