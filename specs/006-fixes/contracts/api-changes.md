# Contract changes: 006-fixes

Базовый контракт — [005 events.md](../../005-events-history/contracts/events.md). Изменения:

## API мини-приложения

| Action | Изменение |
|---|---|
| любой запрос | если у человека стоит отметка `blocked_at`, она снимается |
| `admin.state` | у каждого участника новое поле `blocked: boolean` — Telegram сообщил, что бот заблокирован |
| `admin.transfer` | 400 «Переносить участие на аккаунт администратора нельзя», если `to` — администратор или владелец. После успеха: сообщение прежнему аккаунту `from` и всем администраторам, кроме выполнившего |
| `admin.rename` | 400 «Участник не найден», если `id` нет; 403 «Переименовать администратора может только владелец бота», если цель — админ или владелец, не сам админ и запрос не от владельца |
| `admin.remove` | 400 «Человек не участвует в этом эвенте», если `id` не участник; сообщение не отправляется |
| `admin.exclusion.add` | 400 «Исключение можно задать только между участниками эвента», если кто-то из двух не участник |
| `admin.reveal` | 400 «Тайна уже раскрыта», если раскрытие уже было; рассылки нет |
| `admin.draw` | одновременные запросы: ровно один успешен, остальные — 400 «Жеребьёвка уже проведена» |
| `admin.draw.check`, `admin.draw` | новая причина в `problems`: «Не удалось быстро подобрать распределение — попробуй ещё раз. Если не выйдет, убери часть исключений или выключи кольцевую жеребьёвку.» |

## Бот

| Ввод | Изменение |
|---|---|
| любое сообщение или нажатие | снимает отметку `blocked_at` |
| уведомление о сообщении в переписке | название эвента в заголовке сокращается до 40 символов с «…»; вместе с текстом ≤ 4000 символов — не больше 4096 |

## HTTP

| Путь | Изменение |
|---|---|
| любой, кроме cron | база не подготовлена (нет таблиц или `schema < 6`) → 500, текст «База не подготовлена: примени миграции (см. README)» (для `/api/*` — JSON `{ok:false,error}`) |
| `scheduled` | база не подготовлена → запись в журнал, без действий |
