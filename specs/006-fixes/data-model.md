# Data Model: 006-fixes

Схема 005 ([../005-events-history/data-model.md](../005-events-history/data-model.md)) не меняется по смыслу.
Миграция `0002_fixes.sql` добавляет:

| Таблица | Поле | Тип / по умолчанию | Смысл |
|---|---|---|---|
| `users` | `blocked_at` | `INTEGER NOT NULL DEFAULT 0` | время ответа Telegram 403 на сообщение человеку; `0` — сообщения доходят |
| `outbox` | `locked_until` | `INTEGER NOT NULL DEFAULT 0` | до какого момента (мс) сообщение взято в отправку; `< now` — доступно |
| `events` | `draw_token` | `TEXT NOT NULL DEFAULT ''` | случайный токен успешной жеребьёвки; защищает от двойной |
| индекс | `outbox_chat (chat_id, id)` | — | быстрая проверка «есть ли более старое захваченное сообщение тому же человеку» |
| `settings` | `schema = '6'` | — | код работает только при схеме ≥ 6 |

## Состояния

**Сообщение в очереди**:
- `свободно` (`locked_until < now`) → `захвачено` (`locked_until = now + 60 с`);
- из `захвачено`:
  - отправлено, или отклонено окончательно (400 / 403), или старше 2 суток → `удалено`;
  - временная ошибка, 429 или пропущено из-за более старого сообщения тому же человеку → `свободно` (`locked_until = 0`);
  - обработка оборвалась → через 60 с снова `свободно`.

**Человек**: `blocked_at = 0` ⇄ `blocked_at > 0`.
- Ставится ответом 403 на сообщение из очереди.
- Снимается, когда человек пишет боту, нажимает кнопку или открывает мини-приложение.

**Эвент**: `draw_done = 0, draw_token = ''` → `draw_done = 1, draw_token = <токен>`. Переход возможен ровно один раз;
сброс (004/005) возвращает `draw_token = ''`.

## Миграции

| Файл | Содержимое | Безопасность |
|---|---|---|
| `0001_initial.sql` | схема 005 целиком (`CREATE TABLE/INDEX IF NOT EXISTS`), `schema = '5'` | на пустой базе создаёт всё; на базе, созданной кодом 005, ничего не меняет |
| `0002_fixes.sql` | `ALTER TABLE … ADD COLUMN` ×3, индекс `outbox_chat`, `schema = '6'` | только добавляет поля; данные не трогает |

Правило на будущее: каждая следующая фича, которая меняет схему, добавляет файл `NNNN_<имя>.sql` и повышает
`schema`. Удаление таблиц или полей — только отдельной миграцией, описанной в спецификации фичи.
