# Quickstart: проверка 048

## Быстрые тесты

```powershell
npm test
```

Новое: `tests/swap.test.mjs` (правила, отказы, данные двух пар, сообщения, журнал, ответы без пар и имён, число запросов,
склейка приложения), `tests/atomic.test.mjs` (обмен ×2 в одну миллисекунду, обмен ↔ вписывание, повтор после успеха),
права (48 действий `admin.*`), эталон отказов (ключи «048 …»), `docs/api.md` (68 действий).

## Перед слиянием

```powershell
npm run test:all     # быстрые + e2e («владелец ⊇ админ» по 48 действиям)
npm run screenshots  # Chrome: checkSwap — шторка, выбор двоих, предупреждение с «Подробнее» и галочкой, обмен
```

## Вручную (локально, `npm run dev` + бот)

1. Событие на 4+ человек, жеребьёвка. Владелец: «Управление» → «Управление жеребьёвкой» → «🔀 Открыть управление
   жеребьёвкой».
2. Отметить двоих → «🔀 Поменять подопечных» → окно → «ОК». Двум Сантам пришло «у тебя теперь новый подопечный»; в
   журнале — «🔀 Подопечные поменялись · пар изменено: 2».
3. Добавить исключение (или включить кольцевую до жеребьёвки) так, чтобы обмен нарушал правило → предупреждение,
   «Подробнее» свёрнут, без галочки кнопка недоступна; с галочкой — обмен.
4. Выбрать Санту и его подопечного → «Этих двоих поменять нельзя».
5. Администратором — блока нет.

## iPhone (Telegram iOS)

Владелец проверяет на телефоне: флажки в списке нажимаются по всей строке, «Подробнее» раскрывается касанием и значок
поворачивается, шторка закрывается свайпом за полосу.
