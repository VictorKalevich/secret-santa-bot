# Quickstart: проверка, что всё работает

Пошаговый выкат для владельца — в [README.md](../../README.md). Здесь — как проверить фичу.

## Предварительно

- Node.js 20+ (`node -v`), зависимости: `npm install`
- Для скриншотов: Python 3 + `pip install playwright` + `python -m playwright install chromium`

## 1. Автотесты

```powershell
npm test            # юнит-тесты жеребьёвки + правила дизайн-системы
npm run test:e2e    # локальный Worker + имитация Telegram: полный сценарий игры
```

Ожидаемо: все тесты зелёные. Сквозной тест проверяет сценарии US1–US8 из [spec.md](./spec.md), в том числе:

- регистрация только по приглашению, ввод имени;
- письмо > 1000 слов отклоняется;
- исключения соблюдены, никто не дарит себе, каждый ровно раз Санта и раз подопечный;
- `admin.state` не содержит пар и текстов писем;
- уведомление об изменении письма одно на серию правок и без имени подопечного;
- удаление/вписывание после жеребьёвки меняет минимум пар;
- поддельный `initData` и webhook без секрета отклоняются.

## 2. Визуальная проверка мини-приложения

```powershell
npm run dev                  # в одном окне: локальный Worker на http://127.0.0.1:8787
python tests/screenshots.py  # в другом: скриншоты всех вкладок в test-results/
```

Открыть `design-system/preview.html` в браузере — витрина всех компонентов дизайн-системы в светлой и тёмной теме.

## 3. Проверка в Telegram (после выката по README)

1. Открыть `https://<worker>.workers.dev/setup?key=<ADMIN_SECRET>` → все пункты ✔.
2. Перейти по ссылке администратора → ввести имя → выбрать «Участвую».
3. Отправить пригласительную ссылку 2–3 тестовым аккаунтам, зарегистрироваться, написать письма.
4. Админ: добавить исключение, провести жеребьёвку → всем пришло уведомление.
5. Изменить письмо под одним аккаунтом → через ~10 минут его Санте пришло «📝 Твой подопечный обновил письмо».
