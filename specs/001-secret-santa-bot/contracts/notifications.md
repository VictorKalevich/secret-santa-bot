# Contract: сообщения и уведомления бота

Правило (Конституция, принцип I): в тексте уведомлений нет имени подопечного и текста письма.
Исключения — сообщения, которые человек сам открыл (меню) или которые по смыслу раскрывают тайну («Раскрыть Сант»).

| Событие | Кому | Текст (суть) | Кнопка | Звук |
|---|---|---|---|---|
| Жеребьёвка проведена | всем участникам | «🎄 Жеребьёвка проведена! Загляни во вкладку «Подопечный»» | 🎁 Узнать подопечного | да |
| Подопечный изменил письмо (после паузы 10 мин) | его Санте | «📝 Твой подопечный обновил письмо Санте.» | 👀 Посмотреть | по `notify_mode` |
| Смена подопечного (замена после жеребьёвки) | Санта, у которого сменился подопечный | «🔄 У тебя теперь новый подопечный» | 🎁 Посмотреть | да |
| Вписан в жеребьёвку | новичок | «🎄 Ты в игре! Жеребьёвка для тебя проведена» | 🎁 Посмотреть | да |
| Напоминание о письме (вручную или за 2 дня/1 день/в день срока) | участники без письма | «⏰ Твоё письмо Санте пока пустое…» | ✏️ Написать письмо | да |
| Напоминание о подарке (вручную или за 2 дня/в день вручения) | Санты без «подарок готов» | «🎁 Подарок для подопечного уже готов?» | 🎁 Открыть | да |
| Анонимное сообщение Санты (**изменено в 003**, см. [003/contracts/chat.md](../../003-santa-ward-chat/contracts/chat.md)) | подопечный | «💬 Твой Тайный Санта пишет: …» | ↩️ Ответить · 💬 Вся переписка | да |
| Сообщение подопечного | его Санта | «🎁 Тебе пишет твой подопечный: …» | ↩️ Ответить подопечному | да |
| Новый участник | админы | «👋 Новый участник: <имя>» | — | нет |
| Удалён из игры | удалённый | «Организатор удалил тебя из игры…» | — | да |
| Раскрытие | каждый подопечный | «🎅 Тайна раскрыта! Твой Тайный Санта — <имя>» | — | да |

Ежедневные напоминания — в `REMINDER_HOUR` (10:00) по `TIMEZONE_OFFSET_HOURS` (UTC+3, Минск), не чаще раза в сутки.
