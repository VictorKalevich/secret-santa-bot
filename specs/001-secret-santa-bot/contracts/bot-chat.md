# Contract: чат с ботом

> **С фичи 005** действия привязаны к эвенту (поле `event`), см. [`specs/005-events-history/contracts/events.md`](../../005-events-history/contracts/events.md).
> Этот контракт описывает поведение внутри одного эвента.


Бот работает только в личных чатах. Обрабатываются `message` и `callback_query`.

## Deep-link

| Ссылка | Поведение |
|---|---|
| `t.me/<bot>?start=adm_<код>` | **Изменено в 002:** делает пользователя владельцем игры — см. [002/contracts/roles.md](../../002-admin-roles/contracts/roles.md). В 001: делает пользователя админом. Новичка спрашивает имя, затем «🎁 Участвую / 🛠 Только организую». Код = HMAC(BOT_TOKEN, ADMIN_SECRET), показывается на `/setup`. |
| `t.me/<bot>?start=inv_<invite_code>` | Регистрация участника, если код верный и регистрация открыта; иначе — объяснение. |
| `/start` без кода | Зарегистрированному — меню; остальным — «закрытый бот, нужна ссылка». |

## Команды

| Команда | Поведение |
|---|---|
| `/start` | Главное меню |
| `/cancel` | Отменить ожидаемый ввод (имя / сообщение) |

## Меню

Текст со статусом (письмо заполнено/пусто, жеребьёвка) и кнопки:

- `🎁 Открыть приложение` (web_app) — всегда;
- `✉️ Подопечному` (`msg:ward`) — если есть подопечный;
- `✉️ Своему Санте` (`msg:santa`) — если есть Санта;
- `🔔 Уведомления` (`notify`) — участникам → кнопки `nm:sound`, `nm:silent`, `nm:off`.

Кнопка меню чата (рядом с полем ввода) — `🎁 Санта`, открывает мини-приложение.

## Ожидаемый ввод (`users.pending`)

| Значение | Что ждём | Результат |
|---|---|---|
| `name` | имя 1–40 символов | регистрация завершена, админам — «👋 Новый участник» (без звука) |
| `msg_ward` | текст | подопечный получает «🎅 Сообщение от твоего Тайного Санты» + «↩️ Ответить Санте» |
| `msg_santa` | текст | Санта получает «🎁 Тебе пишет твой подопечный» + «↩️ Ответить подопечному» |

Команда вместо текста отменяет ввод.
