# Quickstart: проверка 010

## Автоматически

```powershell
npm test             # юнит (снимок семей) + дизайн-система
npm run test:e2e     # блок «010» + весь прежний сценарий
npm run screenshots  # служебный просмотр, «Удалённые», переключатель возврата → test-results/
```

## Вручную (локально, `npm run dev`)

1. **Настройка**: открыть `http://127.0.0.1:8787/setup?key=…` → форма, ключ из адреса не принят. Ввести ключ → ссылка
   владельца. Обновить страницу и снова ввести ключ → снова работает (ссылку ещё не использовали).
2. **Ссылка владельца**: перейти по ней в Telegram → владелец. Перейти ещё раз → «Ссылка владельца уже использована…».
   Ввести ключ на `/setup` → «Страница заблокирована», настройка не выполнена. Сменить `ADMIN_SECRET` → `/setup` снова
   выдаёт (новую) ссылку.
3. **Перенос**: админ (не владелец) — в меню участника нет «Перенести»; запрос `admin.transfer` → `403`.
4. **Служебный просмотр**: владелец → панель эвента → «🔐 Служебный просмотр» → ввести «ОТКРЫТЬ» → выбрать участника →
   подопечный, Санта, письмо, адрес, переписка. «Показать все пары» → подтверждение → таблица. В журнале эвента —
   «🔐 Служебный просмотр» и «🔐 Все пары» без пар. У участника «не открыл подопечного» не изменилось.
5. **Закрытая регистрация**: закрыть регистрацию → «Принять» заявку (панель и кнопка в чате) → отказ; «Отклонить» —
   работает; «Пригласить из эвента» → отказ; «Я участвую» → работает.
6. **Возврат удалённых**: выключить «Удалённые могут вернуться по ссылке», удалить участника → он по ссылке получает
   «Организатор удалил тебя…». В панели «Удалённые» → «Разрешить вернуться» → входит по ссылке.
7. **Удаление эвента**: двойное «Удалить» → одно уведомление участникам, одна запись в общем журнале.

Ожидаемо: в журнале `wrangler dev` нет `budget exceeded`.
