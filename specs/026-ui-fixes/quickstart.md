# Quickstart: проверка фичи 026

## Локально (до слияния)

```powershell
npm test                                  # всё, в т.ч. новый tests/app-ui.test.mjs
node --test tests/app-ui.test.mjs         # семь правил по склейке приложения и «от противного»
npm run test:e2e                          # сквозной сценарий (сервер не менялся — всё как раньше)
npm run screenshots                       # снимки в test-results/ и проверки в Chrome, в т.ч. checkUiFixes
```

Ожидается: всё зелёное; в выводе `screenshots` — строка `✔ недочёты интерфейса (026): …`, код выхода 0.

Скриншоты «до» и «после»: снимки кода до правок (коммит перед правками приложения) и после сравниваются попиксельно;
отличия допустимы только в текстах времени («сегодня в 14:03»), остальное совпадает (правила — `spec.md`, FR-013).

## Выкат

Миграций у фичи нет, база не меняется.

```powershell
git checkout main
git pull
npm install
npx wrangler d1 migrations list secret-santa-db --remote   # ожидается «No migrations to apply»
npx wrangler deployments list                               # запишите Version ID текущей версии — к ней откат
npm run deploy
```

## Проверка на iPhone (Telegram для iOS)

Страница приложения не кэшируется (`cache-control: no-store`) — новая версия открывается сразу; если нет — закройте
мини-приложение (✕ вверху) и откройте снова.

1. **Подготовка.** Бот → «🎁 Санта» → «🎄 Создать» → название «Проверка 026» → «Создать». Откроется панель события.
2. **Сохранение параметров (пункт 1).** Прокрутите до «Параметры», замените название на «Проверка 026 — новое»,
   нажмите «Сохранить». Ожидается: «Сохранено»; экран остался у «Параметров» (не прыгнул к началу, загрузка не мигнула);
   вверху — новое название. Ниже: «Опасная зона» → «🗑 Удалить событие» — в списке «событие «Проверка 026 — новое»
   целиком…». Закройте ✕.
3. **Окно подтверждения (пункт 6).** «🏁 Завершить» — окно Telegram с полным текстом до конца «…Вернуть событие в
   «идёт» нельзя.» → «Отмена». Если в событии есть другой участник: «⋯» → «🗑 Удалить из события» — текст с новым
   названием, без обрыва → «Отмена».
4. **Исключения и закреплённые пары (пункт 7).** Блоки «Исключения» и «Закреплённые пары» — как раньше; «Добавить
   исключение» без выбора — «Выбери двух людей». Вкладки «Инфо» ↔ «Админ» — всё загружается, без вечной «Загрузка…».
5. **Переписка и обращения (пункты 3, 4, 7)** — в событии, где уже есть жеребьёвка или обращения:
   - «Подопечный» → «💬 Написать подопечному»: поле ввода и «Отправить» как раньше; ✕ — экран «Подопечный» вернулся.
   - «Админ» → «Обращения» → обращение: заголовок «Обращение: <имя>»; ✕ и сразу «📜 Журнал действий» — заголовок
     «Журнал события» (не «Обращение: …»).
6. **Завершено со стороны (пункт 2).** Откройте панель «Проверка 026 — новое» на iPhone. На компьютере (Telegram
   Desktop) в той же панели — «🏁 Завершить» → OK. На iPhone: «Инфо», затем «Админ». Ожидается: вверху плашка «🏁 Событие
   завершено…», в «Опасной зоне» — только «🗑 Удалить событие» (нет «Полный сброс»).
7. **Уборка.** «Опасная зона» → «🗑 Удалить событие» → слово УДАЛИТЬ → «🗑 Удалить навсегда» → OK.

Что-то выглядит или работает иначе, чем раньше (кроме пунктов выше), — откат.

## Откат

База не менялась — откатывается только код Worker.

```powershell
npx wrangler rollback                     # к предыдущей версии; спросит подтверждение
# или к конкретной версии из `deployments list`:
npx wrangler rollback <Version ID> -m "откат 026"
```

Проверка: откройте мини-приложение заново — прежний вид. Вернуть 026 — `npm run deploy` с `main` (или
`npx wrangler rollback <Version ID 026>`).
