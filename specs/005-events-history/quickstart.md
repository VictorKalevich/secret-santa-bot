# Quickstart: проверка 005

```powershell
npm test             # + юнит-тесты кольцевой жеребьёвки
npm run test:e2e     # параллельные эвенты, кольцевая, завершение и окно переписки, история, права, сброс/удаление/перенос
npm run screenshots  # 00-home, 13-new-event, 16-home-participant — список эвентов; 08b — админ не участник;
                     # 14/15-finished-* — завершённый эвент; прежние вкладки внутри эвента
```

Вручную: главный экран → «＋ Новый эвент» → отправить ссылку → жеребьёвка → «🏁 Завершить эвент» → создать новый,
«📨 Пригласить участников» из прошлого → участники видят оба эвента в списке.
