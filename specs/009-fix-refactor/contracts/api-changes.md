# Contract changes: 009

Базовые контракты: `specs/005-events-history/contracts/events.md`, `specs/006-fixes/contracts/api-changes.md`,
`specs/007-admin-tools/contracts/api.md`, `specs/008-delivery-families-requests/contracts/api.md`. Здесь — только
изменения. Новых действий нет.

## API мини-приложения

| Действие | Изменение |
|---|---|
| `admin.exclusion.add`, `admin.exclusion.del` | при `draw_done` → 400 «После жеребьёвки исключения не меняются: иначе по заменам участников можно было бы вычислить пары. Чтобы поменять исключения, отмени жеребьёвку (пока никто не открыл подопечного).» |
| `admin.family.save`, `admin.family.delete` | 400, если меняется членство человека из идущего эвента с проведённой жеребьёвкой и включёнными семьями: «Состав семьи нельзя менять, пока идёт эвент «…» с проведённой жеребьёвкой: иначе по заменам участников можно было бы вычислить пары. Изменения — после его завершения.» Переименование без смены состава — можно |
| `admin.insert` | `id` = сам админ → 400 «Вписать себя нельзя — попроси другого администратора.»; одновременное изменение пар → 400 «Пары изменились одновременно с этим действием — попробуй ещё раз.» |
| `admin.remove` | после жеребьёвки: одновременное изменение пар → 400 (тот же текст) |
| `admin.draw.check` | ответ без `history_used`, `history_ignored`: `{ possible, count, ring, problems, empty_wishlists }` |
| `admin.draw` | ответ без `history_ignored`: `{ count, single_cycle }`; состав/исключения/параметры изменились во время расчёта → 400 «Состав эвента изменился во время жеребьёвки — попробуй ещё раз.» |
| `admin.reveal` | одновременный повтор → 400 «Тайна уже раскрыта.» (без рассылки) |
| `admin.event.finish` | одновременный повтор → 400 «Эвент уже завершён.» (без рассылки) |
| `admin.game` | без изменений (предупреждение об автодействиях без даты — только в интерфейсе) |
| вступление (`admin.request.decide`, по ссылке) | адрес предзаполняется только при `delivery_on` |
| `admin.transfer` | при слиянии адрес — нового аккаунта, если не пустой |

Текст причины `ring_impossible` (в `problems`): «Похоже, без взаимных пар с такими исключениями не обойтись. Попробуй ещё
раз; если не выйдет — убери часть исключений или выключи кольцевую жеребьёвку.»

## Чат бота

| Ситуация | Ответ бота |
|---|---|
| Приглашение своего эвента, участник уже в нём (любая регистрация/статус) | «🎄 Ты уже участвуешь в эвенте «…».» + меню |
| После ввода имени: человек уже в эвенте | приветствие + «напиши письмо»; админам «присоединяется» |
| После ввода имени: не в эвенте, вступление разрешено | вступает (или заявка при одобрении) — как по ссылке |
| После ввода имени: регистрация закрыта / эвент завершён | «Регистрация в эвент «…» закрыта. Напиши организатору…» + меню |
| После ввода имени: ссылку сменили / эвент удалён | «Эта пригласительная ссылка устарела. Попроси у организатора новую.» + меню |
| Приглашение в эвент с одобрением, заявку отклонили < 24 ч назад | «Организатор не одобрил заявку в эвент «…». Если это ошибка — напиши ему.»; админам ничего |
| Команда (`/…`) в режиме ответа | режим сброшен, команда выполняется как обычно |
| Текст в режиме ответа, прошло > 60 мин | «⌛ Время ответа истекло — сообщение не отправлено. Нажми «↩️ Ответить» ещё раз и пришли его снова.» |
| Текст в режиме ответа, пара сменилась | «🔄 Пара изменилась после нажатия «Ответить» — сообщение не отправлено. Нажми «↩️ Ответить» ещё раз.» |
| Нажатие «↩️ Ответить» отклонено | прежний режим ответа сброшен |

## Уведомления

Без изменений текстов, кроме: дубли раскрытия/завершения при гонке больше не рассылаются.
