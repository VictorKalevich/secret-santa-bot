# Глоссарий: итальянский (it)

Обращение — на *tu*; блок поддержки проекта (`app.event.donate.*`) — на *Lei*. Род по умолчанию — мужской обобщённый;
где можно, причастия с «ты» обходятся (`hai ricevuto`, `ti hanno rimosso`, `entrerai`).
