# Глоссарий: турецкий (tr)

Обращение — на «ты» (*sen*), блок поддержки проекта `app.event.donate.*` — на «вы» (*siz*). Название в кавычках —
«…», как у `q()` сервера. Имена и названия в подстановках не склоняются: падеж берёт соседнее слово
(«{title} etkinliğinde», ««{name}» adlı katılımcının»), именительный падеж с послелогами *için*, *ile*, *arasında*,
страдательный залог («… çıkarılsın mı?») или двоеточие («Talebi üstlendi: <b>{author}</b>»).

## Слова подтверждения (`app.core.word.*`)

| Русский | Турецкий | Пояснение |
|---|---|---|
| ОТКРЫТЬ | AÇ | служебный просмотр; «ac» совпадает после свёртки диакритики |
| ВЫЙТИ | AYRIL | без İ; «ayril» и «ayrıl» совпадают и при простом `toUpperCase` |
| УДАЛИТЬ | KALDIR | «убрать»: без İ (у «SİL» строчное «sil» не совпало бы при простом `toUpperCase`) |
| СБРОС | SIFIRLA | без İ |
| ОТМЕНА | İPTAL | другого обычного слова нет; «iptal»/«IPTAL» совпадают только при свёртке `foldWord` (верхний регистр по `tr` + снятие диакритики) |

## Формы числа

`Intl.PluralRules('tr')`: `one`, `other`. Существительное после числа — в единственном числе («{n} katılımcı»), формы
обычно совпадают.
