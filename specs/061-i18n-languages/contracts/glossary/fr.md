# Глоссарий: французский (fr)

Французский (Франция), обращение на *tu*; блок поддержки проекта (`app.event.donate.*`) — на *vous*. Кавычки « … » с
пробелами внутри, пробел перед `:` `?` `!` `;`. Причастия к «ты» по возможности без рода («Tu ne fais plus partie…»
вместо «Tu as été retiré»).
