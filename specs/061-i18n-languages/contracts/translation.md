# Контракт 061: перевод словаря

Источник истины — русский словарь `src/i18n/ru/` (060). Словарь языка `<язык>` — `src/i18n/<язык>/`: тот же
`index.js` (те же `AREAS` и файлы) и файл на каждую область с теми же ключами. Проверка —
`node tests/support/i18n-lang-check.mjs <язык>` (то же проверяет `tests/i18n.test.mjs` для всех языков).

## 1. Формат

- Файл области: `export default { '<ключ>': <значение>, … };` — ключи и их порядок как в русском файле; комментарии —
  по-английски или без них; **ни одной кириллической буквы** во всём файле.
- Значение — того же вида, что у русского:
  - строка → строка (непустая, если русская непустая);
  - список (месяцы, дни недели) → список той же длины;
  - набор форм числа (у русского `{ one, few, many }`) → объект с формами **всех** категорий
    `new Intl.PluralRules('<язык>')` для целых 0…1000 **и** `other`; если у русских форм есть `{n}` — в каждой форме.
- Подстановки `{имя}` — те же имена, что у русского ключа (порядок в тексте любой); у `{owner.<форма>}` форма — одна из
  `nom`, `gen`, `dat`, `ins`, `nomCap` (это ключи `common.owner.*` и `common.botOwner.*` — их перевод подбирается так,
  чтобы предложения с ними были грамматически верны; где какая форма стоит — `grep -rn "owner\." src/i18n/ru`).
- Разметка в тексте (`<b>`, `<i>`, `<code>`, `<a href="…">`) — те же теги в том же числе; вне тегов нет `<`, `>`;
  `&` — только как `&amp;` и т. п., если есть у русского.
- Эмодзи в начале кнопок и заголовков — те же; переводы строк `\n` — по смыслу русского.

## 2. Язык

- Обращение к человеку — на «ты» (en *you*, es *tú*, pt-BR *você*, fr *tu*, de *du*, it *tu*, pl *ty*, tr *sen*, id
  *kamu*, zh 你); блок поддержки проекта (`app.event.donate.*`) — вежливая форма (es *usted*, pt *você*, fr *vous*, de *Sie*,
  it *Lei*, pl *Państwo*, tr *siz*, id *Anda*, zh 您).
- Португальский — бразильский; китайский — упрощённые иероглифы, пунктуация китайская (，。：！？（）).
- Естественный язык носителя, коротко, как в русском: кнопки — короткие (подписи на телефоне), подтверждения —
  ≤ 250 символов в худшем случае, тексты без канцелярита.
- Примеры в подсказках (бюджет, место, название события) можно приспособить к языку (валюта, праздник); смысл прежний.
- `app.core.locale` — код языка (`en`, `pt`, `zh` …) без региона.
- `common.date` и списки месяцев — по правилам языка (`{month} {day}` по-английски, `{month}{day}日` по-китайски и т. п.).

## 3. Слова подтверждения (`app.core.word.*`)

Одно слово без пробелов, в языках с регистром — ЗАГЛАВНЫМИ (`DELETE`, `OPEN`, `LEAVE`, `RESET`, `CANCEL` по-английски);
слово, которое человек легко наберёт на своей клавиатуре; без диакритики, если есть обычное слово без неё. Сервер
сравнивает без учёта регистра и диакритики.

## 4. Пределы Telegram

- `setup.command.*` — 1…256 символов, `setup.description` — ≤ 512, `setup.shortDescription` — ≤ 120,
  `setup.menuButton` — ≤ 20.
- Тексты, в которые вставляется текст человека (переписка, обращения, объявление, письмо), — не длиннее русских больше
  чем на 40 символов (сообщение с текстом 4000 символов должно уместиться в 4096).

## 5. Глоссарий

Одна сущность — одно слово во всём словаре языка. Переводчик записывает выбранные термины в
`specs/061-i18n-languages/contracts/glossary/<язык>.md` (таблица «русский — термин — пояснение»).
