# Data Model 061: бот на языке человека

Миграция `0022_languages.sql` (схема 22) — до выката кода, прежний код с ней работает (новые колонки не читает).

## users

| Колонка | Тип | Значение |
|---|---|---|
| `lang` (060) | TEXT NOT NULL DEFAULT `''` | язык, выбранный человеком: код из `LANGUAGES`; `''` — «как в Telegram» |
| `tg_lang` (новая) | TEXT NOT NULL DEFAULT `''` | последний известный язык Telegram, приведённый к языку бота (`telegramLanguage`); `''` — неизвестен |
| `menu_lang` (новая) | TEXT NOT NULL DEFAULT `''` | язык кнопки меню, поставленной чату; `''` — общая кнопка бота (русская) |

Язык человека: `lang` (если в `LANGUAGES`) → язык Telegram текущего обращения → `tg_lang` → `ru`.

Переходы:
- обращение с языком Telegram `X` (приведённым, не пустым), `X ≠ tg_lang` → `tg_lang = X`;
- новая запись человека → `tg_lang` = язык Telegram обращения;
- `lang.set` / кнопка `lang:<код>` → `lang = код`; `lang:auto` / `lang.set ''` → `lang = ''`;
- язык человека `L`, бот настроен: `L ≠ ru` и `menu_lang ≠ L` → кнопка чата на `L`, `menu_lang = L`; `L = ru` и
  `menu_lang ≠ ''` → общая кнопка, `menu_lang = ''`.

Перенос участия, сброс, удаление участника — колонки не трогают (свойства аккаунта; `REGISTRY` без изменений: колонки
не ссылаются на людей и события).

## audit

| Колонка | Тип | Значение |
|---|---|---|
| `details` | TEXT | прежний текст подробностей по-русски (≤ 500) — без изменений |
| `details_tx` (новая) | TEXT NOT NULL DEFAULT `''` | JSON отложенного текста подробностей (`tx`/`tdate`/`tjoin`/`$h`); `''` — нет (строка, пусто, JSON > 2000) |

Показ: `details_tx` есть и разбирается → собирается на языке смотрящего (≤ 500), иначе `details`.
