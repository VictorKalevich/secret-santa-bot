# Contract: значок у имени и открытка для письма (038)

## Набор (`src/looks.js`)

- `EMOJIS` — 40 эмодзи, без повторов, каждый — один символ для человека (одна графема).
- `POSTCARDS` — 15 `{ id, title }`: `snow` «Снегопад», `firs` «Ёлочки», `gingerbread` «Имбирное печенье», `night`
  «Звёздная ночь», `tartan` «Тёплый плед», `candy` «Леденец», `aurora` «Северное сияние», `fireplace` «У камина»,
  `snowman` «Снеговик», `tangerine` «Мандарины», `cocoa` «Какао с зефиром», `gift` «Подарок с лентой», `sparkle`
  «Золотые блёстки», `nordic` «Скандинавский узор», `airmail` «Авиапочта».
- `validEmoji(x)` / `validCard(x)` — значение из набора или `''`, иначе `null`.

## Действия

| Действие | Кто | Событие | В завершённом | Запрос | Ответ | Отказ | Журнал |
|---|---|---|---|---|---|---|---|
| `emoji.set` | USER | нет | — | `emoji` (`''` — без значка) | `{ emoji }` | 400 «Такого значка нет — выбери из списка.» | нет |
| `card.set` | MEMBER | да | нет — 400 «Событие завершено: письмо теперь только для чтения.» | `event`, `card` (`''` — без открытки) | `{ card }` | 400 «Такой открытки нет — выбери из списка.» | нет |

Сообщений нет; `wishlist_updated_at` не меняется.

## Поля ответов

- `me`: `me.emoji`; `looks: { emojis: EMOJIS, postcards: POSTCARDS }`.
- `event.get`: `member.card`; `roster.people[].emoji`, `roster.organizers[].emoji` (всегда, `''` — без значка).
- `ward.get`: `ward.emoji`, `ward.card`.
- `admin.state`: `users[].emoji`, `requests[].emoji`, `removed[].emoji`.
- `admin.wishlist`: `card`.
- `admin.users`: `users[].emoji`.
- Нет значка: `chat.get`, `message.send`, `support.*`, сообщения бота, журнал, служебный просмотр.

## Дизайн-система

- Токены: `--ds-postcard-frame|paper|ink|mark` (умолчание — без темы), по теме `--ds-postcard-<id>-frame|paper|ink`
  (сырые значения только здесь), размеры `--ds-postcard-frame-w`, `--ds-postcard-tilt`, `--ds-size-choice`,
  `--ds-size-choice-card`.
- `.ds-postcard` — рамка (`--ds-postcard-frame`), `::after` — наклейка (`--ds-postcard-mark`); `.ds-postcard__paper` —
  бумага и чернила; `.ds-postcard--<id>` — тема (переопределяет четыре свойства); `.ds-postcard--mini` — плитка выбора;
  поле ввода внутри бумаги — прозрачное, текст и каретка (`caret-color`) — цвет чернил: без явного цвета iOS рисует
  каретку по теме телефона, и в тёмной теме на светлой бумаге её не видно (найдено на iPhone после выката).
- `.ds-choices` — сетка выбора (`--cards` — для открыток), `.ds-choice` — плитка-кнопка, `--selected` — выбранная.
- Тест: набор `POSTCARDS` = классы тем в `components.css` = тройки токенов в `tokens.css` = темы в `preview.html` (в обе
  стороны); контраст `ink`/`paper` ≥ 4.5 : 1.

## Приложение

- Шапка события (`renderHero`, `04-event`): «‹» на главный экран — всегда (единственное событие участника по-прежнему
  открывается сразу, но «Профиль» и «Уведомления» теперь доступны и ему).
- `postcard(card, ...content)` (`02-core`): без открытки — содержимое как есть; иначе
  `ds-postcard ds-postcard--<card>` → `ds-postcard__paper` → содержимое.
- «Профиль» (`03-home`): «<значок> <имя>», кнопки «✏️ Изменить имя» и «😀 Значок у имени» → шторка «Значок у имени»:
  подсказка «Значок стоит перед твоим именем в списках участников и у организаторов. В переписке Санты и подопечного
  значков нет.», сетка 40 значков и «Без значка»; нажатие — `emoji.set`, шторка закрывается, сообщение «Значок
  сохранён» / «Значок убран».
- «Письмо» (`04-event`), пока письмо можно менять: в карточке письма — «🖼 Открытка: <название | без открытки>» → шторка
  «Открытка для письма»: подсказка «Санта увидит твоё письмо на этой открытке. Менять можно, пока событие идёт.», сетка
  «Без открытки» + 15 мини-открыток; нажатие — `card.set`, сообщение «Открытка выбрана» / «Открытка убрана», редактор —
  на открытке, несохранённый текст остаётся. Только чтение — письмо на открытке.
- «Подопечный»: значок — внутри `ds-ward-card__name` (скрыт вместе с именем); письмо и изменения — на открытке.
- Панель: `personTitle` — «<значок> имя  @username»; «👁 Открыть письмо» — письмо на открытке.
- Главный экран → «Администраторы»: значок перед именем.
