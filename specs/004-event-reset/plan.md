# Implementation Plan: Полный сброс события; удаление и перенос участников

**Branch**: `004-event-reset` | **Date**: 2026-11-12 | **Spec**: [spec.md](./spec.md)

## Summary

`admin.reset.full` (только владелец, `confirm: "СБРОС"`): одна транзакция D1 — очистить очередь, разослать удаляемым
уведомление, удалить всех, кроме владельца, очистить все таблицы игры и параметры, новый код приглашения.
`admin.transfer` (`from` → `to`): одна транзакция — переназначить `pairs`, `messages`, `history`, `exclusions` с `from` на `to`,
перенести роль и письмо, удалить `from`, уведомить `to`. В мини-приложении: меню участника «⋯» (шторка с действиями)
вместо ряда иконок, «Опасная зона» с полным сбросом для владельца. Решения — [research.md](./research.md).

## Technical Context

**Language/Version**: JavaScript ES2022, Cloudflare Workers · **Storage**: D1, без изменения схемы

**Testing**: e2e-сценарии сброса и переноса (проверка «пары остальных не изменились»), скриншоты меню участника

**Constraints**: ≤ 50 внешних запросов на вызов — сброс одной пачкой (`db.batch`), уведомления через `outbox`
