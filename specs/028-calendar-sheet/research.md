# Research: шторка календаря (028)

## R1. Вторая кнопка

**Decision**: `ui.btn(value ? 'Сбросить' : 'Закрыть', 'secondary', 'ds-btn--block')` — всегда; «Сбросить» → `onPick('')`,
«Закрыть» → только `closeSheet()`. «Нечего сбрасывать» — по дате поля при открытии.

**Rationale**: одна кнопка на одном месте; поведение «Сбросить» — как в 027.

## R2. Постоянная высота

**Decision**: `.ds-calendar__grid { grid-template-rows: auto repeat(6, var(--ds-size-control)) }` — строка дней недели и
шесть строк недель фиксированной высоты; пустые строки занимают место и без клеток.

**Rationale**: месяц при неделе с понедельника занимает 4–6 строк (февраль с понедельника — 4, 31 день с субботы — 6);
явные строки сетки фиксированной высоты дают одну высоту без пустых клеток в разметке. Остальное в шторке (заголовок,
подсказка, «Месяц ГГГГ», кнопки) — в одну строку и не зависит от месяца.

**Alternatives considered**: дописывать пустые клетки до 42 — строки из пустых `div` схлопнулись бы без заданной высоты.

## R3. Драгер

**Decision**: `sheetHandle(own)` в ядре рядом с `openCalendar`: у шторки, которую вернул `openSheet`, — класс
`ds-sheet--handle` и первая строка `ds-sheet__handle` (полоса во всю ширину, по центру полоска 36×5 — как у iOS,
`touch-action: none`). Pointer Events с захватом указателя: шторка едет за пальцем вниз (`transform` из JS, вверх — 0);
отпускание дальше четверти высоты или быстрее 0,5 px/мс (и дальше 30 px) — шторка уезжает вниз (`ds-sheet--settle`,
переход `--ds-duration-base`) и закрывается `requestCloseSheet()`; иначе возвращается на место. `pointercancel` —
возврат.

**Rationale**: Pointer Events есть в iOS 13+ и Chromium; захват указателя ведёт свайп и за пределами полосы. Сдвиг —
единственное динамическое значение (как высота поля в `autosize`); вид — классами дизайн-системы. `openSheet` не
меняется (просьба «кроме диалога ничего не меняй»): драгер навешивается на свою шторку.

## R4. Жест Telegram

**Decision**: при открытии календаря, если `tg.isVerticalSwipesEnabled` (Bot API 7.7), — `tg.disableVerticalSwipes()`;
в `onClose` шторки — `tg.enableVerticalSwipes()`, только если выключали мы.

**Rationale**: в Telegram для iOS свайп вниз по мини-приложению сворачивает само приложение; без выключения свайп
драгера мог бы свернуть Telegram-окно вместо шторки. Выключение — только на время календаря, остальное приложение как
прежде.
