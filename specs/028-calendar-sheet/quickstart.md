# Quickstart: проверка фичи 028

## Локально

```powershell
npm test                 # в т.ч. tests/app-tweaks.test.mjs (правила 3, 6, 7)
npm run test:e2e         # сервер не менялся
npm run screenshots      # checkTweaks: «Закрыть», постоянная высота, свайп за драгер; снимки 29-auto-draw-calendar
```

## Выкат

Миграций нет: `npx wrangler d1 migrations list secret-santa-db --remote` → «No migrations to apply», затем
`npx wrangler deployments list` (запомнить Version ID) и `npm run deploy`.

## Проверка на iPhone

1. «Параметры» → «Автожеребьёвка» (дата не задана): сверху шторки — серая полоска; под «Готово» — «Закрыть».
   «Закрыть» — шторка закрыта, поле «Не выбрана».
2. Откройте снова и листайте «›» через февраль и месяцы на 5–6 недель: шторка не меняет высоту, «Готово» на месте.
3. Потяните за полоску вниз чуть-чуть и отпустите — шторка вернулась. Потяните на полэкрана (или резко смахните) —
   шторка уехала вниз и закрылась; само мини-приложение не свернулось.
4. Выберите день → «Готово» → «Сохранить». Откройте снова: под «Готово» — «Сбросить».
5. Другие шторки (например, «🎄 Создать») — как раньше, без полоски.

## Откат

`npx wrangler rollback <Version ID> -m "откат 028"` — база не меняется.
