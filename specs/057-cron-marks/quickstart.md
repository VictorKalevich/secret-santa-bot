# Quickstart 057: проверка и выкат

## Локально

```powershell
npm test            # в т.ч. tests/cron-marks.test.mjs, cron-reads, migrations (0020), queries
npm run test:all    # перед слиянием: npm test и e2e
```

`tests/cron-marks.test.mjs` проверяет на «мире»: уведомление о письме и адресе — то же сообщение через задержку после
последней правки, одно на серию правок, режимы `off`/`silent`, правка во время обработки не теряется, до жеребьёвки и
черновик — без отметки, завершённое событие и участник без Санты — отметка снимается молча, сброс, перенос и слияние
участий; ежедневный шаг — проверенное событие не читается, сохранение параметров, жеребьёвка и сброс снимают отметку
(автожеребьёвка и автораскрытие — в следующую минуту), напоминание не повторяется; «от противного» — на каждое место,
где ставится и снимается отметка. `cron-reads` — планы всех операторов cron по новым индексам, обычная минута — 3
запроса. `migrations` — 0020 на базе с данными и сверка.

## Выкат (по команде владельца)

Миграция `0020` поднимает схему до 20 — её применяют **в обе базы до выката кода** (новый код без неё не запустится:
«схема не готова»; прежний код с ней работает). После выката — **сверка** (правки, принятые прежним кодом между миграцией
и выкатом). Порядок — как в CLAUDE.md, раздел «Боты»; «оба» — сначала второй.

1. Второй бот:
   - `npx wrangler deployments list --env second` — записать текущий Version ID (точка отката);
   - копия базы: `npx wrangler d1 export secret-santa-db-2 --env second --remote --output "backup-secret-santa-db-2-<дата>.sql"`;
   - `npx wrangler d1 migrations apply secret-santa-db-2 --env second --remote`;
   - `npx wrangler d1 execute secret-santa-db-2 --env second --remote --command "SELECT value FROM settings WHERE key = 'schema'"` → `20`;
   - `npm run deploy:second`; `/app` отвечает 200;
   - сверка: `npx wrangler d1 execute secret-santa-db-2 --env second --remote --file tools/notify-reconcile.sql`.
2. Первый бот — то же без `--env second` (`--env=""` в Bash), база `secret-santa-db`.

## После выката

- В логах (`npx wrangler tail <env>`) нет `cron step failed`.
- Через сутки: `npx wrangler d1 info <db> <env>` — `rows_read_24h`; для первого бота с одним событием на 10 человек
  ожидается ≈ 8–10 тыс. вместо ≈ 46 тыс. `npx wrangler d1 insights <db> <env> --sort-by reads --limit 10` — запрос
  уведомлений и ежедневного шага больше не в верхних строках (остаются очередь и версия схемы).
- Уведомление Санте приходит, как раньше: подопечный меняет письмо → через `NOTIFY_DELAY_MINUTES` сообщение.

## Откат

Код — `npx wrangler rollback <прежний Version ID> <env> -m "откат"` (база не меняется, прежний код новые колонки не
читает и уведомляет прежним запросом). Колонки и индексы удалять не нужно. При возврате нового кода — снова сверка
(`tools/notify-reconcile.sql`): правки, принятые прежним кодом, без неё остались бы без отметки.
