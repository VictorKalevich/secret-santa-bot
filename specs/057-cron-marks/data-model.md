# Модель данных 057

Миграция `migrations/0020_cron_marks.sql`, версия схемы 20 (`REQUIRED_SCHEMA`). Решения — `research.md` (R3–R10).

## `members.notify_at` — правка ждёт уведомления Санте

| | |
|---|---|
| Тип | `INTEGER NOT NULL DEFAULT 0` |
| Значение | время (мс) последней правки письма или адреса, о которой Санта ещё не уведомлён; `0` — ничего не ждёт |
| Индекс | `members_notify ON members (notify_at) WHERE notify_at > 0` |
| В `REGISTRY` | `REGISTRY.members.notify = 'notify_at'` — сброс обнуляет, слияние участий ставит |

Переходы:

| Событие | Новое значение | Где |
|---|---|---|
| публикация изменённого письма, смена адреса — у участника есть Санта | время правки | `saveWishlist`, `writeLetterDraft` (публикация), `saveDelivery` (`src/participant.js`) |
| то же без Санты | без изменений (обычно 0) | там же, `CASE WHEN EXISTS (пара)` |
| минутная проверка прочитала отметку, новой правки не было | 0 | `notifyWishlistChanges` (`src/cron.js`), `… AND notify_at = <прочитанное>` |
| новая правка после чтения | время новой правки (снятие не срабатывает) | — |
| полный сброс события | 0 | `eventDataDeleteStmts` (`keepMember`) |
| слияние участий | время последней правки объединённых письма и адреса | `mergeMembership` |
| перенос участия | переходит со строкой | `personTransferStmts` |
| уход, удаление участника, удаление события | строка удаляется | построители `REGISTRY` |
| миграция 0020, сверка | `MAX(wishlist_updated_at, delivery_updated_at)` у подопечных с неучтённой правкой в идущем событии | `0020_cron_marks.sql`, `tools/notify-reconcile.sql` |

Инвариант N1 (кроме пограничного случая «правка в момент жеребьёвки», `research.md` R4, и окна «миграция → выкат» до
сверки): у подопечного каждой пары идущего события, у которой `MAX(wishlist_updated_at, delivery_updated_at) >
notified_at`, есть отметка `notify_at > 0`.

## `events.checked_on` — на сегодня проверено

| | |
|---|---|
| Тип | `TEXT NOT NULL DEFAULT ''` |
| Значение | местная дата (`YYYY-MM-DD`), когда ежедневный шаг закончил с событием; `''` — не проверено |
| Индекс | `events_unchecked ON events (checked_on) WHERE status = 'active'` |
| Список колонок | служебная: `EVENT_STATE_RESET.checked_on = ''` (`src/event-params.js`) — сброс, `EVENT_FIELDS`, тест `server-shape` |

Переходы:

| Событие | Новое значение | Где |
|---|---|---|
| ежедневная часть сделана, автодействие не нужно | сегодня | `dailyStep` (тихие, снятие отметки 056, напоминание), `warnStale` |
| сохранение параметров (`admin.game`) | `''` | `saveEventSettings` |
| жеребьёвка (вручную и cron) | `''` | захват `runDraw` |
| полный сброс | `''` | `resetEvent` (`EVENT_STATE_RESET`) |
| новое событие | `''` | умолчание схемы |

Инвариант D1: если у идущего события `checked_on` = сегодня, то при последнем чтении автодействие ему не было нужно и с
тех пор не менялся ни один вход `dueAutoAction` (`research.md` R7) — значит, и сейчас не нужно.

Прежняя `events.last_daily` (ежедневная часть сделана сегодня — напоминание не повторяется) не меняется по смыслу; при
сохранении параметров не снимается.
