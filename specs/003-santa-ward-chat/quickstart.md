# Quickstart: проверка 003

```powershell
npm test
npm run test:e2e      # сценарий «003: переписка» + лимит 4000 символов
npm run screenshots   # 09-chat-*.png — переписка у Санты и у подопечного
```

Вручную после выката: Санта → «Подопечный» → «💬 Написать подопечному» → отправить. Подопечному приходит сообщение
с кнопками «↩️ Ответить» и «💬 Вся переписка»; ответ появляется у Санты в переписке в течение ~6 секунд.
