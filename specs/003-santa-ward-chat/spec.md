# Feature Specification: Переписка Санты и подопечного; лимит письма по символам Telegram

**Feature Branch**: `003-santa-ward-chat`

**Created**: 2026-11-12

**Status**: Implemented

**Input**: User description: "Поправь ограничение до 1000 слов на корректное ограничение по символам для Telegram. Если можно
создать вариант чата, в котором Санта и подопечный будут обмениваться письмами, его нужно создать: у подопечного кнопка
«Написать Санте», у Санты — «Написать подопечному», на случай если возникнут вопросы и нужно будет на них отвечать.
Уведомления тоже нужно присылать."

## User Scenarios & Testing *(mandatory)*

### User Story 1 — Санта и подопечный переписываются (Priority: P1)

После жеребьёвки у Санты во вкладке «Подопечный» есть кнопка «💬 Написать подопечному», у подопечного во вкладке «Письмо» —
«💬 Написать Санте». Кнопка открывает переписку: вся история сообщений, поле ввода, «Отправить». Санта для подопечного
остаётся анонимным («Тайный Санта»).

**Why this priority**: Главная просьба: задать вопрос и получить ответ, не раскрывая Санту.

**Independent Test**: Санта пишет «Какой размер?», подопечный открывает переписку и отвечает «M»; оба видят оба сообщения
в одной истории в правильном порядке.

**Acceptance Scenarios**:

1. **Given** пары распределены, **When** Санта открывает «💬 Написать подопечному» и отправляет сообщение, **Then** оно
   появляется в переписке справа (своё), подопечный видит его слева от «Тайного Санты».
2. **Given** подопечный получил сообщение, **When** он открывает «💬 Написать Санте» и отвечает, **Then** Санта видит ответ
   в той же переписке.
3. **Given** жеребьёвка не проведена, **When** участник смотрит вкладки, **Then** кнопок переписки нет.
4. **Given** у Санты сменился подопечный (замена после жеребьёвки), **When** он открывает переписку, **Then** видит новую
   пустую переписку — старая история недоступна ни ему, ни новому подопечному.

---

### User Story 2 — Уведомления о новых сообщениях (Priority: P1)

Получатель сообщения получает его в Telegram с кнопками «↩️ Ответить» (ответ прямо в чате с ботом) и «💬 Вся переписка»
(открывает переписку в приложении). Непрочитанные сообщения отмечены на кнопке переписки (число) и точкой на вкладке.

**Why this priority**: Без уведомления на вопрос никто не ответит.

**Independent Test**: Санта отправляет сообщение → подопечному приходит сообщение бота с текстом и двумя кнопками; в
приложении у подопечного на кнопке «Написать Санте» число 1; после открытия переписки — 0.

**Acceptance Scenarios**:

1. **Given** Санта отправил сообщение, **When** бот доставляет его, **Then** заголовок «💬 Твой Тайный Санта пишет:»,
   без имени Санты, с кнопками «↩️ Ответить» и «💬 Вся переписка».
2. **Given** подопечный ответил через «↩️ Ответить» в чате с ботом, **When** Санта открывает переписку в приложении,
   **Then** ответ там есть.
3. **Given** есть непрочитанные, **When** получатель открывает переписку, **Then** они помечаются прочитанными.

### User Story 3 — Лимит письма по символам Telegram (Priority: P1)

Письмо Санте и сообщения переписки ограничены 4000 символами — так любое из них помещается в одно сообщение Telegram
(лимит Telegram — 4096 символов, 96 оставлены под заголовок). Счётчик показывает «N / 4000 символов».

**Why this priority**: Лимит в словах не гарантировал, что текст поместится в сообщение Telegram.

**Independent Test**: Вставить 4001 символ — «Сохранить» недоступна, счётчик красный; сервер тоже отклоняет.

**Acceptance Scenarios**:

1. **Given** письмо из 4000 символов, **When** участник сохраняет, **Then** письмо сохранено.
2. **Given** 4001 символ, **When** участник пытается сохранить, **Then** сохранение невозможно, объяснение про лимит Telegram.
3. **Given** сообщение переписки длиннее 4000 символов, **When** его отправляют, **Then** отправка отклоняется с объяснением.

### Edge Cases

- Сообщение пустое или из одних пробелов → не отправляется.
- Получатель заблокировал бота → сообщение сохраняется в переписке, уведомление пропускается.
- Участника удалили → его переписка удаляется целиком.
- «Новая игра» → вся переписка удаляется (новые пары — новые разговоры).
- Переписка открыта долго → новые сообщения подгружаются сами (без перезапуска приложения).
- Отправка через бота текста длиннее 4000 символов → бот объясняет лимит и ничего не отправляет.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-301**: Система MUST хранить переписку отдельно для каждой пары «Санта → подопечный»; доступ к ней есть только у этих двоих.
- **FR-302**: Санта MUST иметь кнопку «💬 Написать подопечному», подопечный — «💬 Написать Санте»; обе открывают историю
  и поле ввода.
- **FR-303**: Отправитель-Санта MUST отображаться подопечному только как «Тайный Санта».
- **FR-304**: Каждое сообщение MUST доставляться получателю в Telegram с кнопками «↩️ Ответить» и «💬 Вся переписка»; бот
  не добавляет к тексту имён.
- **FR-305**: Ответ, отправленный через бота, MUST попадать в ту же переписку.
- **FR-306**: Система MUST показывать число непрочитанных сообщений на кнопке переписки и отметку на вкладке; открытие
  переписки помечает их прочитанными.
- **FR-307**: Открытая переписка MUST подгружать новые сообщения автоматически (не реже раза в 10 секунд).
- **FR-308**: При смене пары, удалении участника и «Новой игре» переписка прежних пар MUST удаляться.
- **FR-309**: Письмо Санте и сообщение переписки MUST быть не длиннее 4000 символов (считаются так же, как в Telegram);
  счётчик символов виден при вводе. Заменяет FR-007 (лимит 1000 слов).
- **FR-310**: Существующие функции «Анонимный вопрос подопечному» и «Написать своему Санте» MUST быть заменены перепиской.

### Key Entities *(include if feature involves data)*

- **Сообщение (Message)**: пара (Санта, подопечный), кто отправил (Санта/подопечный), текст ≤ 4000 символов, время,
  прочитано ли получателем.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-301**: Получатель видит уведомление о новом сообщении не позже чем через 1 минуту.
- **SC-302**: В открытой переписке новое сообщение собеседника появляется не позже чем через 10 секунд.
- **SC-303**: 100% проверок: ни одна сторона не видит переписку чужих пар; подопечный нигде не видит имени Санты.
- **SC-304**: Любое сохранённое письмо или сообщение помещается в одно сообщение Telegram.

## Assumptions

- Текст сообщения в уведомлении показывается (как в обычном мессенджере): это слова самих участников, бот ничего не
  добавляет. Принцип I Конституции касается имени подопечного и письма Санте — они в уведомлениях по-прежнему не появляются.
- Сообщения — только текст (без фото и файлов).
- Владелец ещё не выкатывал бота — миграция существующих писем длиннее 4000 символов не нужна; старые письма можно
  открыть и сократить.
