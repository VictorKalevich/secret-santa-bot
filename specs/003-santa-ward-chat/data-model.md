# Data Model: изменения в 003

## messages — переписка пары (новая таблица)

| Поле | Тип | Правила |
|---|---|---|
| `id` | INTEGER PK AUTOINCREMENT | порядок сообщений |
| `santa` | INTEGER | Санта пары |
| `ward` | INTEGER | подопечный пары |
| `sender` | TEXT | `santa` или `ward` |
| `text` | TEXT | 1–4000 символов, без пробелов по краям |
| `created_at` | INTEGER | Unix ms |
| `read_at` | INTEGER | 0 — не прочитано получателем |

Индекс `(santa, ward, id)`.

**Доступ**: участник читает только переписки пар, где он `santa` (собеседник — подопечный) или `ward` (собеседник —
«Тайный Санта»). В ответах API нет ID и имён собеседника.

**Жизненный цикл**: удаляется при удалении участника (`santa = id OR ward = id`), при исчезновении пары после замены
и при «Новой игре» (всё).
