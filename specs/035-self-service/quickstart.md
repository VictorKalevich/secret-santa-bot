# Quickstart: проверка 035

## Автотесты

```powershell
npm test            # self-service, atomic, data-registry, api-*, rights, app-ui — зелёные
npm run test:e2e    # прежний сквозной сценарий (без budget exceeded)
npm run screenshots # checkSelfService: «Профиль», шторка имени, выход со словом, «Инфо» после жеребьёвки
```

Ожидается: `tests/self-service.test.mjs` и новые проверки `atomic` падают на коде до 035 (действий нет), проходят после.

## Вручную (локально: `npm run dev` + бот, или на проде после выката)

1. **Имя.** Главный экран → «Профиль» → «✏️ Изменить имя» → «  Вера   Петрова » → «Сохранить». Приветствие — «Привет,
   Вера Петрова!»; у организатора в общем журнале — «верунчик → Вера Петрова»; сообщений организаторам нет. Ещё раз
   «Сохранить» с тем же именем — новой записи в журнале нет.
2. **Выход до жеребьёвки.** Участник → событие → «Инфо» → внизу «🚪 Выйти из события» → кнопка «🚪 Выйти» недоступна,
   пока не введено «выйти» (любой регистр) → «🚪 Выйти». Главный экран, событие пропало из «Мои события». Организаторам —
   сообщение со звуком «🚪 <имя> выходит из события «…»» с кнопкой «🛠 Открыть событие»; в журнале события — «выход из
   события». В панели организатора человека нет; отметки «удалён» нет.
3. **Возврат.** Тот же человек открывает пригласительную ссылку (регистрация открыта) — вступает без ввода имени.
4. **После жеребьёвки.** Провести жеребьёвку → участник → «Инфо»: кнопки выхода нет, подсказка «Жеребьёвка уже прошла —
   выйти можно только через организатора…» и «💬 Написать организатору» (открывает обращение).
5. **Завершённое событие.** Раздела «Выход из события» нет.
6. **Организатор-участник.** Админ-участник выходит через «Инфо» — остальные организаторы получают сообщение, сам он
   остаётся админом и видит событие в «Других событиях».

Проверка на iPhone (Telegram iOS): шторка со словом — поле ввода видно над клавиатурой, кнопка включается после ввода.
