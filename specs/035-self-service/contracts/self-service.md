# Контракт: имя и выход из события (035)

Сводное описание API — `docs/api.md` (разделы `name.set`, `event.leave`, код журнала `member.leave`); здесь — то, что
фича добавляет, и правила для приложения.

## API

### `name.set`

Кто: зарегистрированный. Событие: —.

- **Запрос**: `name`.
- **Ответ**: `name` — сохранённое имя (пробелы схлопнуты в один, по краям обрезаны).
- **Отказы**: 400 «Имя должно быть от 1 до 40 символов» (пустое после обрезки или длиннее 40).
- **Журнал**: `rename` (общий, «<старое имя> → <новое>», автор — сам человек) — только если имя изменилось; то же имя,
  повтор и второй из одновременных вызовов с тем же именем — успех без записи. Сообщений нет.

### `event.leave`

Кто: участник. Событие: да. В завершённом: нет — 400 «Событие завершено — выйти из него уже нельзя.» Без слова `ВЫЙТИ`
в поле `confirm` — 400 «Чтобы выйти, введи слово ВЫЙТИ.»

- **Запрос**: `event`, `confirm`.
- **Ответ**: пустой.
- **Отказы** (обработчик): 400 «Жеребьёвка уже прошла — выйти можно только через организатора: напиши ему.» (в том числе
  жеребьёвка записана одновременно с выходом раньше него); 400 «Событие завершено — выйти из него уже нельзя.» (завершено
  одновременно); 403 «Ты не участвуешь в этом событии.» — второй из двух одновременных выходов.
- **Журнал**: `member.leave` (журнал события, имя вышедшего). Сообщения: каждому админу и владельцу, кроме вышедшего, —
  со звуком, с кнопкой «🛠 Открыть событие». Данные участия удаляются по `REGISTRY` (`memberDataDeleteStmts`), отметка
  «удалён организатором» не ставится. Только пока человек участник, жеребьёвки нет и событие идёт — проверено в момент
  записи; строка участника — последней.

## Порядок в пакете выхода

1. Условие: `EXISTS (SELECT 1 FROM events WHERE id = ? AND draw_done = 0 AND status = 'active')` и
   `EXISTS (SELECT 1 FROM members WHERE event_id = ? AND user_id = ?)`.
2. Сообщения организаторам — по условию.
3. Запись журнала `member.leave` — по условию.
4. Данные участия (`memberDataDeleteStmts` с тем же условием); последний оператор — строка участника, он же захват.

## Приложение

- **Главный экран**, раздел «Профиль» (над «Уведомлениями»): строка с именем, кнопка «✏️ Изменить имя» → шторка «Твоё
  имя»: поле (текущее имя, `maxlength` 40), подсказка «Имя одно во всех событиях. Его видят организаторы и твой Санта, а
  при раскрытии — твой подопечный.», кнопка «Сохранить» (недоступна на время запроса). После ответа: шторка закрыта,
  «Имя сохранено», приветствие и «Профиль» — с новым именем (из ответа), без перезагрузки.
- **Вкладка «Инфо»**, последний раздел «Выход из события» — только участнику идущего события:
  - жеребьёвки нет: подсказка «Не получается участвовать? Выйти можно, пока не проведена жеребьёвка.» и кнопка «🚪 Выйти
    из события» (`danger`) → шторка «Выйти из события» (общий помощник шторки со словом): «Удалится без возможности
    восстановления:» — «твоё письмо Санте и адрес доставки;», «твои обращения к организатору в этом событии.»; строка
    «Организаторы получат сообщение, что ты выходишь. Вернуться можно по пригласительной ссылке, пока регистрация
    открыта.»; поле «Введи слово ВЫЙТИ»; кнопка «🚪 Выйти» (`danger`, недоступна без слова и на время запроса), второго
    окна нет. Успех: шторка закрыта, «Ты больше не участвуешь в событии «<название>»», главный экран.
  - жеребьёвка проведена: подсказка «Жеребьёвка уже прошла — выйти можно только через организатора: напиши ему, он уберёт
    тебя из события.» и, если организатору можно написать, кнопка «💬 Написать организатору» (шторка обращения).
- **Помощник шторки со словом** (`typedSheet`, ядро шторки `07-sheet-chat`) — один для «Опасной зоны» (с вторым окном
  «<заголовок>: точно? Это нельзя отменить.») и выхода (без него); своих копий поля слова нет.
- Только классы дизайн-системы; тексты — «событие»; кнопки — `busy` на время запроса.
