## Витрина

Откройте `design-system/preview.html` в браузере: в тёмной колонке раскройте список «Кто дарит…» — тёмный список,
светлый текст; календарь даты — тёмный. В светлой колонке — светлые.

## Вручную в Telegram (после `npm run deploy`)

1. Telegram Desktop, тёмная тема → бот → «🎁 Санта» → эвент → «Админ» → «Исключения»: раскрыть «Кто дарит…» и
   «…кому НЕ может дарить» — все пункты читаются без наведения. Проверить также «Новый эвент» (образец),
   «Админы» (кого назначить), «Пригласить из эвента», «⋯» участника → перенос, служебный просмотр (участник),
   даты в «Параметрах эвента».
2. Переключить Telegram на светлую тему — то же, светлые списки.
3. Владелец: «Админ» → «🔐 Открыть служебный просмотр» → крутить колесо над шторкой и над затемнённым фоном —
   страница под шторкой не двигается; длинное содержимое (журнал, все пары, переписка) прокручивается внутри.
4. Закрыть шторку (✕ / фон / «Назад») — страница снова прокручивается и стоит там же, где была.
5. Вкладка «Инфо» → «Как это работает» — ровно три пункта.
