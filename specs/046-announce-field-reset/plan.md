# План 046

Причина: поле объявления (`adminAnnounce`, `src/app/05-admin.js.txt`) после ответа сервера очищается присваиванием
`value`, а высоту пересчитывает `autosize` (`02-core`) только по событию `input`. Присваивание это событие не
посылает, и поле сохраняет высоту длинного текста.

Решение — тот же приём, что у «Восстановить прежний черновик» письма (`04-event`): после очистки послать полю
`input`. Его слушают `autosize` (высота — по пустому полю, как при открытии) и `annUpdate` (черновик `drafts.announce`
и кнопка). Очистка по-прежнему только если текст не менялся за время запроса; при ошибке `busy` не доходит до
очистки.

Проверка — тест в Chrome `tests/announce-field.ui.mjs` (как `tests/shipment.ui.mjs`): организатор вводит текст на
несколько строк, поле выросло, отправляет — высота равна исходной, поле пустое, кнопка недоступна; обе темы.

## Проверка Конституции

I, VII. Только вид поля в браузере организатора: данные, права и ответы сервера прежние.
II. Пустое поле выглядит как пустое — организатор не гадает, осталось ли что-то в нём.
III, VI. Сценарий и проверка в Chrome — до слияния.
IV. Высоту задаёт прежний `autosize`; классы и стили не меняются (тест `design-system`).
V. Без запросов к Worker и D1.

## Приёмка

`npm test`, `npm run test:e2e`, `node --test tests/announce-field.ui.mjs`.
